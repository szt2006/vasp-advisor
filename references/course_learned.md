## 0. 权威序、引用格式与阅读方法

### 0.1 权威序（冲突时按此顺序裁定）

```
references/official/（官方 wiki，逐页抓取，627 个页面）
        ↓ 官方没写
things to study/ 下的真实算例文件（INCAR/KPOINTS/POSCAR/OUTCAR/…）
        ↓ 算例没覆盖
讲义正文 L1–L4（references/raw/L*.txt）
        ↓
答疑稿 D1–D4（references/raw/D*.txt）
        ↓
精读报告自己的复算/推论（learn_L*.md 的「推论」）
```

**讲义与答疑都是二手**：本课程首页与尾页都写有讲师声明「不能保证所有授课内容的正确性和准确性」
[讲义] L1 P3 —— 这句声明**本身就是引用本课程一切数值时的默认前提**。

### 0.2 引号与标记（本文件的用法）

| 标记 | 在本文件里的确切含义 |
|---|---|
| `[官方]` | **本轮我本人读了** `references/official/pages/<X>.md` 并据此陈述；文中给出文件名 |
| `[官方·未抓取]` | 课程/精读报告引用了某个官方 wiki 页面，但该页面**不在** `references/official/pages/` 里（本轮未抓到，无法逐字复核）——例如官方 **DOSCAR** 页。用这个标记表示「有官方说法，但我没能亲自核」 |
| `[讲义]` | 引自精读报告转录的讲义原话，给页码（`L1 P28` 形式，页号一定在该讲实际页数内） |
| `[答疑]` | 引自精读报告转录的答疑原话，给段号（`D2-P14` 形式） |
| `[算例]` | 引自精读报告对 `things to study/` 真实文件的核对结果（报告给出了文件名与字段）；**本轮未逐字节复核**，要用到关键数值时请自行复核一次 |
| `[经验]` | 有适用范围的判据，不是硬规则；本文件一定写出「在什么条件下成立」与反例 |
| `[待核对]` | 单一来源，或由精读报告推出；**不得当作断言使用** |

页号范围：L1 ≤ 82、L2 ≤ 157、L3 ≤ 196、L4 ≤ 56。段号范围：D1 ≤ 60、D2 ≤ 82、D3 ≤ 48、D4 ≤ 67。

### 0.3 怎么用这份文件（给 AI 读者）

- **别顺序读**。先看 §1 的「主题 → 主要出处页」表定位，再跳到对应章节。
- 每章末尾都有 **「查更细的」** 段，写明该去 `decide.md` / `playbook.md` 的哪个主题、或 `references/official/pages/` 的哪个文件、或哪份 `learn_Ln.md` 的哪一节。

- **§11 是「不可引用清单」**：讲义里公式没抽出来、纯图片页、数值对不上的地方都列在那里。引用课程数值前先扫一眼。

## 2. 主题一：表面建模（切面、真空层、固定、钝化、超胞）

### 2.1 建模在整个课程里的分量（先理解「为什么这么多页在讲建模」）

- **结构性论断**：设计合理的催化模型是「后续能量和性质计算的基础，也是科研思路的关键」，因为「计算方法大家都是用一样的，但是计算的设计的套路就是文章的关键所在了」[讲义] L1 P6。这一条解释了为什么 L1 有一半篇幅在讲建模。
- **研究思路**：按实验数据（配位环境、键长、电镜、元素组成）搭模型 [讲义] L1 P4；该忽略的就忽略（讲义举例 SiO₂ 对催化没影响可以忽略）[讲义] L1 P5；
  **先做稳定性分析再谈其他**（同一晶面在不同环境组成不同，「只有稳定的体系才有后续研究的价值」）[讲义] L1 P7。
- **告诫（值得单独记住）**：建表面必须参考前人计算与实验文献，因为「好多计算的文章里截取的表面模型都是有问题的，自然界根本不存在的表面做催化计算」[讲义] L1 P56。

### 2.2 切面：四条原则与 terminal 选择

**切面四原则** [讲义] L1 P57：
1. 尽量保证化学计量比与 bulk 一致（例：Al : O = 2 : 3）；
2. 尽量保证表面能最小、暴露原子与实验一致；**氧化物优先让氧暴露**；
3. 是否加基团钝化不饱和原子，要看文献与实验经验（见 2.4）；
4. 尽量保证表面是对称的；不对称表面需加 `IDIPOL`/`LDIPOL` 消偶极。

- **原则 2 的松绑**：氧化物选 O 暴露「基本是这样的，但是也有很多特例，暴露金属表面都有可能」 [答疑] D1-P34；硫化物/硒化物/磷化物同理（基本选 S/Se/P 暴露，但特例很多）[答疑] D1-P34。
- **slab 有两个表面（最容易忘的一条）**：移动 Top 时上下表面同时变化；
  **无法在满足化学计量比的前提下让上下表面都是 O 暴露**；讲义的诊断实例是 O/Al = 21/12，而化学计量比要求 18/12 [讲义] L1 P54。
- **表面偶极**：上下不对称 → 产生偶极 → 讲义要求加 `IDIPOL`/`LDIPOL` [讲义] L1 P53、L1 P57；答疑的措辞是「按理说最好校正一下」[答疑] D1-P44。 ⚠️ **但精读核对发现 4/4 个 day1 算例（含下表面赝氢钝化、明显不对称的 GaN slab）都没开这两个参数** [算例] learn_L1 §4-C25。 → 说明课件的「要求」与讲师自己的实践之间有落差；开不开取决于你算的是**能量差**还是**功函数/静电势**（见 §4.6）。

### 2.3 固定原子：固定几层、怎么固定

- **课程经验规则**：一般固定下两层或三层；**让可弛豫的原子等于或多于被固定的层数** [讲义] L1 P15。 ⚠️ 讲义没定义「层」是原子层还是重复单元（bilayer）—— 精读报告标 [待核对]（GaN 算例固定了 4 个原子层 = 2 个 GaN 双层 + 赝氢，两种读法都能自圆）[算例] learn_L1 §4-C31。
- **具体数值**：Ni(100) 取 **6 个原子层**厚度即可 [讲义] L2 P59；表面优化固定下两层 [讲义] L2 P61、L2 P136、L2 P141。
- **二维材料不固定**：「二维材料不用固定，只有 slab 模型的材料要固定下面几层」[答疑] D4-P23、D4-P24。
- **下表面处理的一个偷懒但有效的办法**：「先把 slab 所有原子都优化一次，然后后续算的时候再固定下两层」 [答疑] D4-P61、D4-P62。
- **两种固定工具（vaspkit 402 vs 403）**：
  - `402`：按**层**固定。运行后程序打印若干 `Threshold: 0.3 layers: 5` 之类的候选，选一个阈值、再输入要固定的层数，输出 `POSCAR_fix`，检查无误后 `cp POSCAR_fix POSCAR` [讲义] L1 P17–P18。**限制：此方法只限于法矢量在 z 方向的 slab 模型** [讲义] L1 P18。
  - `403`：按 **z 坐标阈值**一刀切。做法是「找到要固定的原子中 z 坐标最大的那个，读出它的 z 坐标，固定所有 z 小于该值的原子」[讲义] L1 P19。L3 的频率练习就是用 `403` + `0 0.48` 只放开吸附的 O [讲义] L3 P29（算例核对：被固定的 Au 最大分数 z = 0.43488，O 的分数 z = 0.48812，阈值 0.48 恰好只放开 O）[算例] learn_L3 §3.8.1。
- **POSCAR 语法**：`Selective Dynamics` 必须插在 POSCAR **第 7 行与第 8 行之间**；「VASP 只认第一个字母，也就是 S 是必须的」；之后每行坐标尾部加 **3 个** T/F 对应 x/y/z [讲义] L1 P16。

### 2.4 钝化：什么时候用赝氢、什么时候用 OH、什么时候什么都不加

| 体系 | 课程口径 | 出处 |
|---|---|---|
| 共价晶体/半导体（Si、GaN、InSe、ZnSe） | 用**赝氢**饱和 | [讲义] L1 P57 |
| Al₂O₃、SiO₂ 等氧化物 | 可以考虑用 −OH 饱和 | [讲义] L1 P57 |
| 过渡金属化合物 | **一般不需要**添加额外基团 | [讲义] L1 P57 |
| 金属表面 | 不需要饱和（「只有共价键半导体需要饱和，Ni 是金属键结合的」） | [答疑] D2-P26 |
| 单层 MoS₂ 切 100 面 | **不需要**加赝氢 | [答疑] D1-P58 |
| 氧化物以 O 为终端 | 一般不需要钝化 | [答疑] D4-P3–D4-P6 |

- **赝氢的两条硬规则**：加在**原有化学键的中点**；**计算过程中固定** [讲义] L1 P58；答疑补充「赝氢不用优化，直接把下面几层固定住就可以了」[答疑] D1-P46。算例核对（GaN）：H 的 z 与 Ga–N 键中点仅差 0.0006 Å，且 H 的坐标行是 `F F F` [算例] learn_L1 §3.11。
- **赝氢家族**：讲义只列了 `H1.25`/`H1.5`/`H.5`，但答疑里学员问的是 `0.75H`，讲师答「赝势库里自带，有很多，价电子数不同」[讲义] L1 P25 + [答疑] D1-P24 → 讲义列举不全。
- **OH 饱和的电荷平衡细节**：OH 是 −1 价，为平衡电荷还需额外引入一个 H（相当于引入一个解离的 H₂O），这样得到的表面最符合常温大气条件下的 α-Al₂O₃(0001) [讲义] L1 P55。
- ⚠️ **赝氢钝化后的严重限制（最值钱的一条）**：下表面用赝氢钝化后
  **「没法算表面能。只能钝化前算，而且算出来的是上下表面的平均表面能」** [答疑] D1-P56；「算表面能干脆就不用赝 H，直接上下表面一起优化，得到的结果是上下表面的平均表面能」[答疑] D4-P17、D4-P18、D4-P57、D4-P58。

### 2.5 真空层

- 讲义只给方法不给数：「把 **c 矢量的长度增大 15 埃**」（建异质结真空层时）[讲义] L1 P76； L2 只说「上下各保持一定的真空距离」[讲义] L2 P62。
- **算例反推的事实标准 ≈ 15 Å**（Ag c=22.184 Å/4 层 → ≈15.0 Å；mos2ws2 c=18.41 Å → ≈15.3 Å； Au(111)+O c=24.591 Å → ≈12.5 Å）[算例] learn_L2 §3.9-A8。OER 算例 c = 15 Å [算例] learn_L4 K42。
- **答疑给的报数**：「一般 **10–15 Å** 就够了」[答疑] D4-P9、D4-P10 —— 单一来源，且是「够用」而非收敛测试结论 [待核对]。
- **两处必须做的检查**：vaspkit 算静电势时会提示「Check the Convergence of Vacuum-Level Versus Vacuum Thickness!」[讲义] L2 P137 —— 讲义没给判据 [待核对]。
- **真空层的作用被答疑澄清过（重要）**：「加真空层的目的是为了**得到真空能级**的，并不是为了避免和下表面的作用」 [答疑] D1-P48。

### 2.6 超胞、晶格矢量旋转与异质结

- **Wood 标记法**：`p` = primitive（不写默认就是 p）；`c` = center（表面 cell 中心有一个单元）； `c(2×2)` 与 `(√2×√2)R45°` 等价；`2` 是边长、`R` 是旋转、`45°` 是角度 [讲义] L1 P61。（PDF 抽取把根号丢了，原文写作 `( 2 × 2)𝑅45𝑜` —— 属排版现象 [讲义] L1 P61）
- **Redefine Lattice**：用矩阵乘法改变晶格矢量 [讲义] L1 P62。
- **根号表面实例**：Au(111)-(√3×√3)R30° 取 **A = a − b，B = 2a + b**，矩阵 `(1 −1 0; 2 1 0; 0 0 1)` [讲义] L1 P64–P65（精读报告验算：确实给出 √3×√3R30° 元胞）[算例] learn_L1 §3.11。
- **异质结匹配**：讲义例 g-C₃N₄/TiO₂(100) 的 mismatch 为 **a 矢量 8.88%、b 矢量 4.21%、角度 4.60%**，讲义自评「在异质结的构建里算是很大了」[讲义] L1 P75；答疑给的通用方法是「求最小公倍数扩包；夹角不一样先用 redefine lattice 转基矢；
  **不是所有的两个材料都能建立异质结的**」[答疑] D1-P26。横向相接的异质结「非常麻烦」[答疑] D1-P60。
- **扭转角**：`magicAngle.py` 脚本与 (m,1) 角度表 [讲义] L1 P69；精读报告用讲义自带脚本复算了 4 个点全部吻合 [算例] learn_L1 §3.12。 ⚠️ 表中「魔角」标注的位置与公认魔角（≈1.1°，对应 m ≈ 45–50）不符，疑为浮动标注错位 [待核对] learn_L1 §5.2-18。

### 2.7 固定基矢优化：OPTCELL（二维材料必用）

- **原理**：`ISIF = 3` 允许 9 个自由度自由弛豫；要固定其中几个自由度，

### 3.2 ENCUT

- 课程口径：`ENCUT = POTCAR 中 ENMAX 值(400)`；**晶胞优化/弹性 > 1.3 × ENMAX** [讲义] L1 P28。
  - 算例印证：Fe₂O₃（ISIF=3 晶胞优化）的 ENCUT 恰好 = 1.30 × O 的 ENMAX [算例] learn_L1 §3.3。
  - ⚠️ **1.3 这个倍数的官方对应见 §10-12**（它是官方**已弃用**的 `PREC=High` 档的行为，不是官方推荐）。
- 算例实际取值：520（Fe₂O₃、Ni-CO）、500（MoS₂/HSE、OER 套）、400（Ag/Al₂O₃/Au/C/MoS₂-WS₂/VASPsol 套） [算例] learn_L1 §3.4、learn_L2 §3.2、learn_L4 K41/K75。
- ⚠️ **L2 全篇没有讲 ENCUT 怎么定**（520 与 400 只是照抄）[算例] learn_L2 §3.9-A6；**所有算例都没有截断能收敛测试记录** [算例] learn_L4 §5-14。
- ⚠️ 红线：本文件**不写任何 ENMAX 数值**（那属于 POTCAR 内容）。要拿 ENMAX，请用 `parse_potcar_header` 读你自己的 POTCAR，或从你自己算例的 `OUTCAR` 回显里读 `ENMAX`。

### 3.3 k 点（课程有两套刻度，别混用）

**刻度 A：倒空间 k 点间距 R（vaspkit 的 KP-Resolved Value）**
- 一般用 `0.04`，精确计算用 `0.03` 或 `0.02` [讲义] L1 P20。
- 4/4 个 day1 算例、6 个 day2 算例、OER 套全部由 vaspkit 生成、Γ 居中：**0.040**（多数）、0.050（mos2ws2、OER） [算例] learn_L1 §3.2、learn_L2 §3.9-A7、learn_L4 K42。
- vaspkit 生成的 KPOINTS 注释行自带档位说明「Low=0.08~0.05, Medium=0.04~0.03, Fine=0.02~0.01」[算例] learn_L2 §3.9-A7。

**刻度 B：ka = 每个晶格矢量长度 × 该方向 k 点数**
- 建议：**d 区金属 ka ≈ 30 Å；普通金属 ≈ 25 Å；半导体 ≈ 20 Å；绝缘体 ≈ 15 Å**，并要求测试收敛性 [讲义] L1 P21。
- 正交晶系取基矢模的倒数得三方向密度比：例 `1/11.238 : 1/11.238 : 1/15.845 ≈ 1.4 : 1.4 : 1` → `3 3 2`、`4 4 3`、`6 6 4`、`7 7 5` 都可以 [讲义] L1 P22。
- **两套刻度的换算**（精读报告用 4 个样本反推，`N_i = max(1, round(1/(R·d_i)))`，故 `ka = 1/R`）： `R=0.04 ↔ ka=25 Å`；`0.03 ↔ 33.3 Å`；`0.02 ↔ 50 Å` [待核对] learn_L1 §3.2。 → 这条换算解释了为什么「0.04」只对得上 ka 表里的「普通金属 25 Å」；「半导体 20 Å / 绝缘体 15 Å」在 R 刻度里对应 0.05 / 0.067，**不在讲义的三个推荐值里** [待核对] learn_L1 §4-C30。
- **课程对严格性的松绑**：不必严格遵守 ka 表 —— 文献里仍有很粗的标准；原因是算力有限，且催化关心的是**相对能量**，只要保持精度一致，误差往往抵消 [讲义] L1 P21。
- **DOS 计算要加密 k 点**：讲义只给定性说法（「K 点数目要适当取得更大」）[讲义] L2 P46，
  **L2 全文没有任何数值判据** [算例] learn_L2 §3.9-A7。实操里「加密」就是 vaspkit 的 R 值取到 0.04（Medium 档）。

### 3.4 展宽（ISMEAR / SIGMA）

- 课程口径 [讲义] L1 P28：金属 `(1, 0.2)`；非金属 `(0, 0.05)`；分子 `(0, 0.01)`。
  - 算例：4/4 个 day1 算例都用 `0 / 0.05`；金属类算例（Ag/Au/Ni-CO）用 `1 / 0.2`；半导体/二维（C、MoS₂/WS₂）用 `0 / 0.05` [算例] learn_L1 §3.4、learn_L2 §3.2。
- **DOS 首选 `ISMEAR = -5`**（Blöchl 修正四面体法，「可以得到更为准确得 dos 图」，且程序不读 SIGMA） [讲义] L2 P36、L2 P46。
- **两条课程给的边界条件**：
  1. 模型很大、只用 Γ 点、或 **k 点数 ≤ 3 时不能用 -5**，会直接报错 `VERY BAD NEWS! internal error in subroutine IBZKPT: Tetrahedron method fails for NKPT<4.` [讲义] L2 P46；此时用 `0` 或 `1`，「定性上完全没有问题」[讲义] L2 P47。算例印证：两个 NKPTS = 3 的算例（C、MoS₂/WS₂）确实用 `ISMEAR=0` [算例] learn_L2 §3.8。
  2. **结构优化时不能用 -5**：「四面体方法不能很好地处理费米能级处的电子占据情况，导致算出来的力会有一定百分比的误差」[讲义] L2 P46。
- ⚠️ 这两条限制**在本地官方层里找不到对应表述**（我读了 `references/official/pages/ISMEAR.md` 全文 38 行与 `SIGMA.md` 全文 13 行）→ 见 §10-7。
- **官方层能确认的一点**：四面体法要求 **Γ 中心 k 网格**（`references/official/pages/ISMEAR.md`）[官方] —— 课程的 KPOINTS 全部 Γ 居中，做法一致。

### 3.8 泛函、DFT+U 与磁性

- **泛函写法** [讲义] L1 P34：LDA 不写 `GGA` 且 POTCAR 用 LDA 的； `GGA = 91 | PE | RE | RP | PS | AM`（PW91 / PBE / RPBE / revPBE / PBEsol / AM05）； `METAGGA = TPSS | RTPSS | M06L | MBJL | SCAN | MS0 | MS1 | MS2`。算例只证实了两个：`PE`（OUTCAR `LEXCH=8`）与 `ML`（vdW-DF2，`LEXCH=44`）[算例] learn_L1 §5.2-36。
- **杂化泛函 HSE06** [讲义] L1 P34–P35：`LHFCALC=.TRUE.` + `HFSCREEN=0.2` + `AEXX=0.25` + `ALGO=D`（P35 写 `ALGO=ALL #或Damped`）+ `TIME=0.4` + `LDIAG=.TRUE.` + `ISYM=3`； MoS₂ 的 HSE 模板里 `NSW=0` + `ISIF=3` 并置（属残留，见 §11）。 ⚠️ HSE 页脚提醒：**以上 INCAR 建议都是基于纯泛函的，杂化/GW/RPA 参数不同** [讲义] L1 P28。
- **DFT+U** [讲义] L1 P42–P43：起作用的是 `Ueff = U − J`；`Ueff` 越带隙越大、生成焓越正、过渡态能量越高；「+U 主要对电子结构、能量改善，**对原子几何、晶体结构的影响很有限**」；参数 `LDAU`/`LDAUTYPE`/`LDAUL`/`LDAUU`/`LDAUJ`/`LDAUPRINT`/`LMAXMIX`；
  **`LMAXMIX` 「DFT+U 计算一定要设置」**（示例 `LMAXMIX = 4`）。
- ⚠️ **U 值有两套写法，引用时必须说明是哪一套**：讲义与真实 Fe₂O₃ 算例是 `LDAUU=5.3 / LDAUJ=0.0`（Ueff = 5.3 eV）；而 `things to study/INCAR` 模板是 `LDAUU=4.6 / LDAUJ=0.4`（Ueff = **4.2 eV**）——**相差 1.1 eV** [算例] learn_L1 §3.8。官方对此有一条硬规则：**不同 U 和/或 J（Dudarev 下即 U−J）的算例之间的总能不可比** [官方] `references/official/pages/LDAUU.md` → 跨 U 值比能量等于白算。
- **官方对 `LMAXMIX` 的补充**：默认 2；DFT+U 常需增到 **4（d 电子）/ 6（f 元素）**；且**用 `ICHARG=11` 读入固定 CHGCAR 时结果不一定等于自洽计算，DFT+U 下偏差会很大**；「在 DFT+U 下算能带，**严格要求**把 `LMAXMIX` 增到 4（d）/ 6（f）」[官方] `references/official/pages/LMAXMIX.md`。
- **磁性** [讲义] L1 P44–P47：
  - 四分类：铁磁（Fe/Co/Ni）、顺磁、亚铁磁（Fe₃O₄/Co₃O₄）、以及讲义写作「反磁性」的 Fe₂O₃ ⚠️ **用词不当**：Fe₂O₃ 是反铁磁（AFM），而同讲义 P47 自己用的就是「反铁磁(AFM)」[算例] learn_L1 §4-C13。
  - `MAGMOM` 只在两种情况下被程序采用：**(1) 没读 CHGCAR 也没从 WAVECAR 算初始电荷；(2) 读了非自旋极化的 CHGCAR** [讲义] L1 P45。设置与 POSCAR 原子一一对应；默认 `MAGMOM = NIONS * 1.0`。
  - 手册建议「初始磁矩可以尽量设大（比如 5.0），程序会自动优化到最合理的磁矩」[讲义] L1 P45；实操是「先扩包，再在 VESTA 观察原子编号，按想要的磁性排列一点点写」[答疑] D1-P8。
  - 文献里给的、没说明 U/J 的那个数**往往是磁矩**，要在 OUTCAR 最后读 [答疑] D1-P30。
  - 讲义 P47 的 FM/AFM 对比里，**磁矩块与真实 `fe2o3/OUTCAR` 逐数字一致**，但**引的 OSZICAR 行与真实算例对不上** （讲义那行 `d E ≈ 0`，像是读入已收敛波函数的续算）[算例] learn_L1 §4-C14 → 见 §11。
  - 镧系（如 CeO₂）「基本必须加 U」，因为 f 轨道非常收缩、电子相关效应很强 [答疑] D1-P4。

## 4. 主题三：电子结构分析（DOS / 电荷 / 势 / ELF）

### 4.1 DOS 工作流（课程的标准三步）

1. **必须先优化结构**。理由：「结构优化得到的 DOS 不能直接用，因为是平均了结构优化过程中所有结构的 DOS」 [讲义] L2 P35；注意事项 6 再强调一次「自己随便搭了个模型不优化就计算 DOS 一般没有意义」[讲义] L2 P48。
2. **新建 `dos` 文件夹做单点**：`cp CONTCAR ./dos/POSCAR`； `cp INCAR KPOINTS POTCAR CHGCAR ./dos` [讲义] L2 P35、L2 P73。
3. **DOS 的 INCAR**：`NSW = 0`、`ICHARG = 1`（「用 11（非自洽）也是可以的」）、 `LORBIT = 11`（或 10）、`ISMEAR = -5`、`NEDOS = 1000` [讲义] L2 P36]； `ICHARG=1` 自洽单点与 `ICHARG=11` 非自洽「只要收敛到同样的电子态上，结果是一样的」[讲义] L2 P45。

- **算例反例（重要）**：`ni-co` 的 DOSCAR 出自一次**含离子弛豫（8 个离子步）**的运行，并非讲义 P62 要求的 `NSW = 0` 单点 [算例] learn_L2 §3.9-A3。 → 拿别人的算例做 DOS 分析前，先数 `OUTCAR` 里 `E-fermi` 出现几次。
- **官方对同一件事的说法**：弛豫计算的 `DOSCAR` 通常无用，`NSW>1` 时最终 DOS 是各离子步的平均 `[官方·未抓取]`（精读报告 L2 §4.4-F1 引了官方 DOSCAR 页原文；该页不在本地 `references/official/pages/` 内）→ **课程口径与官方一致**，这条可以放心用。

### 4.2 读 DOS / PDOS：判据与三条禁忌

- **工具**：p4vasp（`vasprun.xml` → DOS+bands → Local DOS control → export）[讲义] L2 P37–P39； vaspkit 主功能 11：`111` 总 DOS（`TDOS.dat`/`ITDOS.dat`）、`112` 指定原子、`113` 每种元素、 `114` 多原子加和、`115` 指定轨道 [讲义] L2 P41–P44。
- **费米能级必须移到 0**：直接取 `DOSCAR` 作图 Ef 不是 0；p4vasp/vaspkit/pymatgen 都会自动 shift； vaspkit 由 `~/.vaspkit` 的 `SET_FERMI_ENERGY_ZERO` 控制 [讲义] L2 P40。算例印证：`al2o3/PDOS_Al.dat` 首个能量 −20.772 = `EMIN − E_F` [算例] learn_L2 §3.8。
- **判据**：
  - 能带越密集/平缓 → DOS 越大；对 DOS 积分 = 电子数 [讲义] L2 P21。
  - **DOS 的展宽**判轨道作用强弱；**带心位置**影响与其他分子的相互作用 [讲义] L2 P22。
  - **DOS 重叠意味着共价键贡献**（可用重叠积分/COOP 量化）[讲义] L2 P71。
- ⚠️ **三条禁忌**：
  1. **PDOS 的和一定小于总 DOS**（球谐投影丢信息），所以**不能**用 PDOS 的积分讨论某个原子轨道的占据数 [讲义] L2 P48、L2 P49。（讲义 P24 把原因归给 RWIG 球形划分、P48 归给投影丢信息 —— 归因不一致，两说不互斥 [算例] learn_L2 §4.1-C1）
  2. **`LORBIT` 输出的 `total charge` 不能定量**：「根据 PROCAR 算出来的原子半径球内的电荷布居…… 定性可以做参考，一般无视就行了」[讲义] L2 P50。要定量原子电荷用 Bader / DDEC / NPA / Löwdin / Mulliken。
  3. **列语义随 ISPIN 变**：`ISPIN=1` 每行 3 个数（能量/DOS/积分 DOS）；`ISPIN=2` 每行 5 个（能量/DOS↑/DOS↓/积分↑/积分↓）[算例] learn_L2 §3.2 + `[官方·未抓取]` 官方 DOSCAR 页（精读报告 §4.2-D1 引原文；该页不在本地官方层）。 ⚠️ 答疑里「看第三列的数值是积分值」这句**只对 ISPIN=1 成立** [答疑] D2-P2。
- **参数**：`NEDOS` 默认 301、建议 1000（太大文件会很大）[讲义] L2 P33； `NBANDS` 建议默认（光学/COHP 才调大）[讲义] L2 P32；`EMAX`/`EMIN` 建议用默认值 [讲义] L2 P34。官方补充：`NEDOS` 还同时决定**介电函数**的频率点数；可用「积分 DOS 的每一步都该有峰出现」自查 NEDOS 是否够 [官方] `references/official/pages/NEDOS.md`。

### 4.2b 用 DOS 讲化学：四种轨道相互作用模型 + 表面特殊作用模型

> 这一小节是 L2 的「理论骨架」，很多人跳过它直接看案例，结果 DOS 会画不会讲。

- **四种轨道相互作用模型** [讲义] L2 P51–P53：
  | 组合 | 结果 |
  |---|---|
  | 空–占 | 按二阶微扰处理，**能量越接近分裂能 ΔE 越大**（这是吸附/配位成键的主项） |
  | 占–占 | 反键升高多于成键下降 → **体系能量上升**（讲义用 He₂ 不存在作例） |
  | 空–空 | 无电子占据，**对能量无贡献** |
  | （判断总原则） | 化学相互作用是否对体系稳定性有贡献，看能级相互作用 |
- **表面特殊作用模型** [讲义] L2 P54–P57]：表面相当于**电子蓄水池**，可以吞吐电子使费米能级变化；两个占据轨道作用时，电子会部分从 CO 的 σ 轨道转移到金属表面；
  **化学吸附能垒**的三个来源被拆成「核互斥 + 占据反键电子向表面转移 + 占据轨道相互排斥」；实验上 AFM 可检测物理吸附；DFT 算物理吸附需要色散校正（见 §8.2）。
- **讲义给的案例库（想练手就从这几页挑）**：电荷差分 + PDOS 研究相互作用 [讲义] L2 P26]；缺陷态 [讲义] L2 P27]；表面态与带边位置 [讲义] L2 P28]；新材料电子结构 [讲义] L2 P29]；吸附分子与载体相互作用 [讲义] L2 P30]；催化吸附的轨道相互作用 [讲义] L2 P31]； CH₄ 在 IrO₂(110) 上的活化 [讲义] L2 P79]；partial charge 与 STM 对应的两个例子（PtSe₂ 缺陷态、 2D 硼团簇）[讲义] L2 P113–P114]。 ⚠️ 案例编号从「案例三」直接跳到「案例五」（原文跳号，不是抽取问题）[算例] learn_L2 §4.1-C7。

### 4.3 d 带中心

- **原理与判据** [讲义] L2 P80–P83：分子轨道与金属 d 轨道作用导致能级分裂，
  **反键态高于费米能级 → 有利于吸附；低于 → 不利于吸附**；前过渡金属 d 带中心高、吸附能大；后过渡金属反过来。
- **调控三思路** [讲义] L2 P84–P87：配位数（配位数越高 → d 带越宽 → 中心越低 → 吸附能越小）、晶格应变、次表层合金原子比例。
- **算法**：「d 轨道的 pDOS 对能量做权重平均」[讲义] L2 P88。 ⚠️ 同页有一条模型代价提醒：「我们这里用的 bulk 的模型，算出来和表面体系会有一点差别」[讲义] L2 P88。
- **两条实现路径**：
  - vaspkit `503` → 直接输出所有原子与总的 d 带中心（`D_BAND_CENTER`），积分窗口可交互修改；工具自带警告「d-Band Center is Sensitive to the Number of Unoccupied Band. Anyway, the Trends are More Important than the Absolute Energies.」[讲义] L2 P92。
  - vaspkit `115` + 脚本：`115 – Ag – d – 0` 得 `PDOS_USER.dat`，再给一个能量上限（如 10 或 20 eV） [讲义] L2 P93。优点：可算 s/p/d/f、可指定若干原子、可设能量上限。
- ⚠️ **报 d 带中心必须同时报积分窗口**（否则不可复现）：讲义 Ag(111) = −3.75 eV（窗口 [−9.39, 17.20]），而算例 `Ag/D_BAND_CENTER` = −3.7771 eV（窗口 [−9.11, 10.04] = `[EMIN−E_F, EMAX−E_F]`）；**同一 PDOS 仅换积分上限就差 0.027 eV** [算例] learn_L2 §3.3、§3.9-A14。
- **适用边界（答疑补的，正文没有）**：单原子 / 过渡金属氧化物 / 单原子 FeN₄ 都能算 d 带中心，
  **但规律没有纯金属那么好**；决定单原子催化吸附能的还有价态、配位环境等 [答疑] D2-P15、D2-P18、D2-P20。

### 4.4 电荷分析：CHGCAR / Bader / 差分电荷

- **CHGCAR**：前几行与 CONTCAR 完全相同；`ISPIN=2` 时用 `chgsplit.pl CHGCAR` 分出 `CHGCAR_mag`（自旋密度）与 `CHGCAR_tot`；坐标后空一行接 `NGXF/NGYF/NGZF`，随后是 ρ(r)·Vcell 共 NGXF·NGYF·NGZF 个数 [讲义] L2 P97–P98。**不建议在 INCAR 里手写格点数**，「一般用 `PREC=Accurate` 产生的格点数量就足够了」[讲义] L2 P98。
- **Bader** [讲义] L2 P100–P101：先 `chgsum.pl AECCAR0 AECCAR2`，再 `bader CHGCAR -ref CHGCAR_sum`；需在 INCAR 加 `LAECHG = .TRUE.`；输出列依次是笛卡尔坐标 / 原子盆体积 / 核到盆边界最小距离 / 价电子数。官方确认 `LAECHG=.TRUE.` 会重建三个全电子密度：`AECCAR0`（芯）、`AECCAR1`（重叠原子价密度）、 `AECCAR2`（自洽价密度）[官方] `references/official/pages/LAECHG.md` → 课程只把 0 与 2 相加是对的（AECCAR1 不在求和链路里），但这属于「与官方文件定义一致」，属推论 [待核对]。 ⚠️ 讲义里 `-ref` 被排成了 en dash（`–ref`），实际命令要用 ASCII 连字符 [算例] learn_L2 §4.4-F7。原子电荷着色图用 `vaspkit 508` [讲义] L2 P101。
- **差分电荷两种定义** [讲义] L2 P102：片段差 `Δρ = ρ_AB − ρ_A − ρ_B`；变形电荷密度 `Δρ = ρ(AB SCF) − ρ(AB atomic)`。
  - 操作要点（硬要求）：两个片段「**结构从 CO/Ni(100) 直接截取，不要再结构优化！计算参数保持不变！**」 [讲义] L2 P103；`vaspkit 314` 依次输入三个 CHGCAR；`CHGDIFF.vasp` 用 VESTA 看（青色 = 电荷密度减小、黄色 = 增加）；改名成 `CHGCAR` 后用 `vaspkit 316` 得 z 方向平均 `CHGPAVG.dat` [讲义] L2 P103–P104。
  - ⚠️ **片段单点必须收敛**（正文没写、答疑补的）：「如果不收敛，减出来的电荷密度会非常难看，结果也不合理」 [答疑] D2-P24。
  - **三片段差分**的适用场景：「表面共吸附两个不同的分子，可能就用三个减」[答疑] D2-P80；但答疑没给三片段的式子 [待核对]。

### 4.5 Partial charge（band-decomposed charge density）与 STM

- **概念**：计算特定 k 点与能带所对应本征波函数的平方（= 电荷密度）[讲义] L2 P107；最常见的用途是 VBM、CBM、表面态、局域态的电荷密度 [讲义] L2 P107–P108。
- **流程**：先自洽得到收敛的 WAVECAR → 新建一次运算从 WAVECAR 提取（「把 VASP 当作一个脚本来运行，并没有做新的 SCF 运算」）[讲义] L2 P115]。官方对同一件事的表述：`LPARD` 是后处理步骤，**要求 WAVECAR 来自先前收敛的计算** [官方] `references/official/pages/LPARD.md`。
- **关键词（课程版）** [讲义] L2 P115–P119：
  | 关键词 | 课程给的用法 |
  |---|---|
  | `LPARD` | `.TRUE.` 时读入收敛 WAVECAR 做计算 |
  | `IBAND` | 按 **EIGENVAL 的顺序**指定能带，如 `IBAND = 20 21 22 23` |
  | `NBMOD` | `>0` = IBAND 的能带数量（设了 IBAND 会自动定，不用手设）；`0` = 所有轨道（含非占据）；`-1` = 正常算 CHGCAR；`-2` = EINT 能量范围（参考 EIGENVAL）；`-3` = 同 −2 但以费米能级为 0 参考 |
  | `KPUSE` | 指定 k 点**在 KPOINTS 里的序号**；Γ 点则 `KPUSE = 1` |
  | `EINT` | 两个实数 → `NBMOD=-2`；**只给一个数** → 「从 EINT 到费米能级」，`NBMOD=-3` |
  | `LSEPB`/`LSEPK` | `.TRUE.` 按每个能带/每个 k 点分别写 `PARCHG.$.$`；`.FALSE.` 合并写 |
- **三种用法模板** [讲义] L2 P120–P121：① 指定能带 + 指定 k 点（VBM/CBM 常用，输出 `PARCHG.0020.0001.vasp`，
  **要手动加 `.vasp` 后缀，因为 VESTA 不识别 `.0001`**）；② 只给能量范围；③ 给相对费米能级的范围。
- ⚠️ **最实用的一条判读经验**：**简并轨道必须合并输出** —— 单独输出 288 号「电荷不完整，对称性不好」， 287+288（VBM）、289+290（CBM）才正确 [讲义] L2 P124。算例印证：`mos2ws2/EIGENVAL` 的 287/288 占据数 1.0、289/290 为 0.0，与讲义判断一致 [算例] learn_L2 §3.4。
- **官方补了课程漏掉的一种写法（重要）**：`NBMOD = -3` **也接受两个值**，两个值都会被加到费米能级上 —— 官方例子：`EINT = -0.1 0.5` 配 `ε_f = 2.43` → 实际区间 2.33–2.93 eV [官方] `references/official/pages/NBMOD.md`。 → 所以「跨费米能级的双侧区间」应写 `NBMOD = -3` + `EINT = -2 2`：**讲义只讲了单值写法**，两种写法并存这一点见 §10-14（该缺口是精读报告明确标出的「真实的方法缺口」）。官方另有两条便利规则：若只写 `EINT` 不写 `NBMOD`，程序内部按 `NBMOD=-2`（绝对能量）处理； `EINT` 两个值写反了程序会自动交换 [官方] `references/official/pages/EINT.md`。
- **STM 模拟** [讲义] L2 P125–P129：恒高模式下压电陶瓷管在 z 方向保持恒定，把隧穿电流在 xy 平面作二维图； `NBMOD = -3` + `EINT = 2.0` 表示显示费米能级以上 2 eV 的态（取负则显示费米能级以下）； ⚠️ **「EINT 和实验上所施加的偏压绝对数值并不直接对应，需要自己测试对比图像」** [讲义] L2 P126；作图在 p4vasp 里选 STM 自动、读入 PARCHG、调恒定高度 [讲义] L2 P128。

### 4.6 静电势与功函数

- **静电势**：近核为负、真空中为 0；「**VASP 算得真空能级不为 0，需要把真空能级位置 shift 到 0，静电势绝对值才有意义**」[讲义] L2 P131–P132。
- **功函数**：`Φ = Evac − EF` [讲义] L2 P134]；讲义强调「**功函数不是材料体相的本征性质，更准确的说法应为材料表面的性质**（比如表面暴露晶面情况和受污染程度）」[讲义] L2 P133]；程序把 VBM 当费米能级，与实验有差别 [讲义] L2 P134。
- **INCAR 关键项**：`LVHAR = .TRUE.` 输出 `LOCPOT`（给纯静电势：离子势 + Hartree 势）；「如果设置 `LVTOT = .TRUE.`、`LVHAR = .FALSE.`，则输出的 `LOCPOT` 是包含静电势和交换相关势能的总势能」 [讲义] L2 P135]。官方确认并补了一条**优先级**：「Setting `LVHAR=True` will set `LVTOT=False`」（写 `LVHAR=.TRUE.` 会强制把 `LVTOT` 置为 F）[官方] `references/official/pages/LVHAR.md`、`LVTOT.md` → **两个都写 `.TRUE.` 时你拿到的是纯静电势，不是总势** —— 这正是「不报错但结果不是你要的量」的典型。
- **算法与数值** [讲义] L2 P136–P142]：优化 Au 晶胞 → 建 Au(111)-p(2×2)、固定最下两层 → `LVHAR=.TRUE.` / `ENCUT=400` / `ISMEAR=1` / `SIGMA=0.2` / `ISIF=2` / `NSW=300` → 用 vaspkit 对 z 方向积分，自动判断真空能级并输出 `POTPAVG.dat`（回显 `Vacuum-Level (eV): 6.673`）→ `grep fermi OUTCAR` 得 `Efermi = 1.6561 eV` → `Φ = 6.673 − 1.6561 = 5.02 eV`（讲义自评与实验比较准确）。 O/Au(111)：`Evac = 7.196`、`Efermi = 1.5863`、`Φ = 5.6097 eV`。另一条路是用 p4vasp 对 LOCPOT 在 xy 平面求和（取三条线里 **average** 那条）[讲义] L2 P140]。
- **规律（值得直接引用）** [讲义] L2 P142]：「吸附氧原子以后，功函数增大」；「**吸附带负电物种（O）功函增大；吸附带正电物种（K）功函减小**」；上下不对称时真空层里会出现明显偶极矫正，使上下表面所对应的真空能级位置不同。
- **用功函预测电子流向** [讲义] L2 P143–P145]：由异质结两侧 Φ 高低判断电子流向（讲义给 `Φ = 5.22 eV` 与 `Φ = 6.43 eV` 两个数，但文本无法确定哪个属于哪个材料 [待核对]）；结论是 TiO₂/g-C₃N₄ 形成时部分电子从 g-C₃N₄ 转移到 TiO₂ → **电子由功函较低的一侧流向较高的一侧**。

### 4.7 分子范德华表面静电势与 ELF

- **分子范德华表面**的定义与换算 [讲义] L2 P146]：气相分子 `0.001 a.u. = 0.00675 e/Å³`；凝聚相 `0.002 a.u. = 0.0135 e/Å³`；`1 a.u. = 1 e/Bohr³ = 6.748 e/Å³`。

## 5. 主题四：热力学与表面能

### 5.1 吸附：定义、位点、覆盖度

- **三种吸附模式** [讲义] L3 P3–P4]：化学吸附、物理吸附、解离吸附。物理吸附的势能曲线例（Ar/Cu(111)）落在 **−0.5 eV < Eads < 0 eV** [讲义] L3 P6]；解离吸附（H₂/Cu(111) → 2H）「一定存在能垒」[讲义] L3 P8]。
- **吸附能定义** [讲义] L3 P5]：`Eads = Em/slab − Em(g) − Eslab`； H 原子吸附的特殊写法 `Eads = EH/slab − ½EH2 − Eslab` [讲义] L3 P10]。
- **位点**：top / bridge / hollow，且「**并非所有位点都真实存在**」[讲义] L3 P9]； hollow 分 HCP 与 FCC 两种 [讲义] L3 P13]；例：top 位的 O 会迁到 hollow；FCC 比 HCP 稳约 **0.27 eV** [讲义] L3 P17]。找全位点的方法：手动摆放 / AIMD 退火 [讲义] L3 P12]。
- **注意事项** [讲义] L3 P14]：算吸附时可用 `ISYM = 0` 打破对称性；小能垒极难算。
- **覆盖度**：定义 `θ = N/N₀` 与平均吸附能 [讲义] L3 P19]；吸附物种之间的相互作用要以「2Eads」为参照 [讲义] L3 P18]。
- **轨迹可视化**：Jmol / VESTA / `vaspkit 405` + VMD [讲义] L3 P16]。

### 5.2 频率 → 热力学量：自由能校正怎么算

- **为什么必须做**：「DFT 算出来的是 0K 下的能量，还要做自由能校正，才能得到真实反应条件下的能量」[讲义] L1 P9]；校正的意义是把温度、压力、pH、电极电势引进来 [讲义] L3 P39]。
- **能拆成四项**：振动 / 平动 / 转动 / 电子激发，只适用于气态分子与吸附物 [讲义] L3 P40]； `εtot = εtrans + εrot + εvib + εele`，配分函数是乘积 [讲义] L3 P47–P48]。
- **吸附体系的特殊处理（关键）**：吸附后平动转动 6 个自由度转为振动，「由于难以计算平动能和转动能，所以可以近似的认为分子平动转动的贡献耦合到了这 6 个振动中，故可以按照 **3N** 计算分子的振动能量」[讲义] L3 P24、L3 P50]。
- **ZPE 与熵**：`ZPE = ½ Σᵢ hνᵢ` [讲义] L3 P52]；「计算出的能量不是体系在 0K 下的能量，而是体系在 0K 下并且忽略 ZPE 的能量」[讲义] L3 P52]；频率越大对 ZPE 贡献越大（H₂ 伸缩振动 4395 cm⁻¹，所以含 H₂ 的反应 ZPE 校正非常大）[讲义] L3 P53]。 `G(0) = H(0) = U(0) = εele + ZPE` [讲义] L3 P61]。
- ⚠️ **低频模式是热力学数据最困难之处**：吸附后平动转动被限制转为振动，很可能出现很小的振动频率，使校正出的自由能异常低 → 「有的文献建议做表面吸附分子的自由能校正的时候，
  **把频率在 50 cm⁻¹ 以下的贡献都算成是 50 cm⁻¹**」[讲义] L3 P55]；另一处写「把频率过小的熵当作 **50 cm⁻¹ 或 60 cm⁻¹** 计算」[讲义] L3 P64]。
  **适用范围：只用于表面吸附分子的自由能校正**，不要拿去算气相分子。
- **工具**：`vaspkit 501`（输出 `E_ZPE`、`U(T)`、`H(T)`、`G(T)`、`S`）[讲义] L3 P63–P64]； `vaspkit 502`（气态分子）[讲义] L3 P73]；查表法 JANAF-NIST [讲义] L3 P67–P70]；Gaussian 法 [讲义] L3 P67]。
- **数值锚点**：O₂ 的自由能校正与实验值 **−0.45 eV** 相符 [讲义] L3 P73]；
  298.15 K 与 800 K 的数据表 [讲义] L3 P65]，结论是「常温可忽略自由能校正，高温影响大」[讲义] L3 P66]。
- ⚠️ **两个算例层面的坑**：讲义 P64 的 vaspkit 输出与 P65 的汇总表**三项都不相等**（ZPE/ΔH/ΔG）[待核对]；讲义 P98 的回显与 P99 表里同温度的值差 0.0224 eV [待核对] learn_L3 §4.1-C4、C-5。 → 用讲义里的热力学数字前，最好自己用 `vaspkit 501/502` 复算一遍。
- **电催化里的 ZPE/熵**（L4 侧）：算例的「校正列」= ΔZPE − TΔS，且 ΔZPE 就是按吸附物自身振动模的 `½Σhν` 算的（精读报告反推，数值吻合到 meV）[算例] learn_L4 K21 —— 属推论 [待核对]。

### 5.3 覆盖度与化学平衡（Langmuir 一脉）

- **吸附平衡**：`rads = rdes` → Langmuir 吸附等温式的推导与前提假设 [讲义] L3 P78–P80]。
- **熵变的影响**：Nørskov 估算吸附熵约 **−0.002 eV/K** [讲义] L3 P81]。
- **覆盖度对温度**：400–600 K 内覆盖度从 1 变到 0（TPD 可表征）[讲义] L3 P82]；
  **对压力** [讲义] L3 P83]；**对吸附能**：敏感区间约 **−0.7 ~ −0.5 eV** [讲义] L3 P84]。
- **多组分竞争**：多组分 Langmuir 形式 [讲义] L3 P85]；
  **吸附能差 ±0.1 eV 即可使覆盖度完全反转** [讲义] L3 P86]。
- **经典实例**：CO 毒化 Pt 电极燃料电池（`Eads(H₂) = −0.7`、`Eads(CO) = −1.2 eV`）[讲义] L3 P87]； 1 ppm CO 即使 CO 覆盖度接近 100% [讲义] L3 P88]；抗 CO 毒化实例 Pt₁/α-MoC [讲义] L3 P89]。

### 5.4 表面能与化学势相图（L3 的后半讲）

- **表面能公式**：`γ(T,p)` 与环境化学势基准 [讲义] L3 P92]（引 Phys. Rev. B 2001, 65, 035406）[讲义] L3 P91]。
- **标准流程**：列出候选表面 → 算各表面的能量 → 用化学势把结果接到温度/压力。 RuO₂(110) 的候选表面（Obridge / Otop / Ru）[讲义] L3 P93]； bulk 自由能用 phonopy 算、slab 校正可抵消 [讲义] L3 P94]；
  **μO 有上下限（富氧/缺氧）** [讲义] L3 P95]；结论：O-rich 时 Otop 最稳、O-poor 时 Obridge 最稳 [讲义] L3 P96]。
- **温压影响**：μO(T,p) 用 VASPKIT 算 [讲义] L3 P97–P100]（100 K 示例回显 `Thermal correction to G(T): -1.207 kcal/mol`）[讲义] L3 P98]； μO 随温度（0–1500 K）与压力（log P = 0 ~ −14）的数值表 [讲义] L3 P99]；μO–γ 相图 [讲义] L3 P100]。
- **扩展**：缺陷表面同样处理（只要算清每种表面的 NRu 与 NO）[讲义] L3 P101]； Rh 在 TiO₂(110) 上 support/dope 的稳定性随 μO 变化 [讲义] L3 P102]；吸附物种共存时表面能变成多自变量函数（例：CO 与 O 共存，得 `ΔμO − ΔμCO > −0.15 eV`）[讲义] L3 P103–P107]；金属表面覆盖度与 O 化学势（Ag）[讲义] L3 P108–P109]； Ostwald ripening 的化学势分析与 Gibbs–Thomson 关系 [讲义] L3 P110–P111]；方法学总结：表面热力学 → 动力学 → TOF → BEP/火山曲线 [讲义] L3 P112]。
- **表面能的一条硬约束**：**用了赝氢钝化就没法算表面能**，只能算上下表面的**平均**表面能 [答疑] D1-P56、D4-P17/P18/P57/P58]（见 §2.4）。

## 6. 主题五：过渡态与频率（L3 的重点）

### 6.1 频率：为什么必须算、怎么算、怎么读

- **为什么必须算**：「结构优化和过渡态搜索任务只能保证得到的结构是驻点，即能量的一阶导数（原子受力）为零，还要进一步计算频率来确定虚频的个数」[讲义] L3 P25]。
- **必须同级别**：「优化和振动分析必须在相同级别下进行」（格点精度、溶剂模型、泛函、vdW 校正等都要一致），否则「相当于振动分析不是在势能面的极小点位置进行，结果没有意义」[讲义] L3 P26]。
- **`EDIFF`**：结构优化 1E-5 ~ 1E-7 皆可；**频率计算 1E-7** [讲义] L3 P26、L3 P30]。官方口径一致：「对有限差分计算（例如声子），甚至可能需要 `EDIFF = 1E-7`」[官方] `references/official/pages/EDIFF.md`。
- **有限位移法** [讲义] L3 P28]：每个自由度位移两次（`NFREE=2`）或四次（`NFREE=4`）；
  **单独 VASP 只算 Γ 点振动频率，声子谱必须结合 phonopy**；表面吸附体系若不关心 slab 原子，**可以把 slab 全固定、只允许吸附原子振动**。官方对 `NFREE=2` 的语义：中心差分（每方向 ±POTIM）；并明确「**强烈建议避免 `NFREE = 1`**」[官方] `references/official/pages/NFREE.md`。
- **频率的 INCAR（课程模板）** [讲义] L3 P30]：`EDIFF=1E-7`、`IBRION=5`、`NFREE=2`、`POTIM=0.015`、 `NSW=300`、`ISIF=2` + `ENCUT=400`、`ISMEAR=1`、`SIGMA=0.2`、`LREAL=Auto`、`LDIPOL=.TRUE.`、`IDIPOL=3`、`ISYM=0`、`PREC` 未设。 ⚠️ 同页文字说「`NSW` 和 `EDIFFG` 都不用设置或取任意值。`NSW` 不能取 0」，但同一页的 INCAR 又写了 `EDIFFG = -0.01` 与 `NSW = 300` —— 文字与示例自相矛盾 [讲义] L3 P30]。精读报告的核对：`ts/OUTCAR` 回显 `NSW = 289`（INCAR 写 300），说明 **VASP 在 `IBRION=5` 下确实会改写 `NSW`** [算例] learn_L3 §3.8.2-X17。
- **离子步数是固定的**：「频率计算的离子步数是固定的，= **6×[放开的原子数] + 1**」[讲义] L3 P31]。 ⚠️ 同页把输出里的 `Degree of freedom: 1/3` 解释为「体系中的自由度 3N」，但该例是 21 个原子、只放开 1 个 O，3N = 63 —— **真正的含义是 `3 × 放开原子数`** （精读报告用两个算例核对：21 原子放开 1 个显示 `3/3`；2 原子全放开显示 `6/6`）[算例] learn_L3 §3.5。 → 通用式：**实际离子步数 = 3 × 放开原子数 × NFREE + 1**。
- **怎么读输出** [讲义] L3 P32–P33]：`OUTCAR` 最后一部分是对角化力常数矩阵的本征值与本征矢（共 3N 个）；每行形如 `1 f  =   12.609563 THz    79.228223 2PiTHz  420.609746 cm-1    52.148981 meV`；
  **「最后这个 52.148981 meV 是 hν 的值，hν/2 是零点振动能 ZPE，求 zpe 可以直接读这个能量除以 2」**；查虚频用 `grep cm OUTCAR`；**`f/i` 代表虚频**；
  **「一般过渡态的虚频都 > ~100 cm⁻¹，如果虚频太小，则过渡态可能找的不对，需要看振动方向检查一下」**（经验值，无出处 [待核对]）；振动方向可用 Jmol 打开 `OUTCAR` 看。
- **几个虚频才算对**：极小点（IS/FS）**没有虚频**；过渡态**恰好一个虚频**； 0 个或两个以上都算失败 [讲义] L3 P33、P140、P157]。气态分子例外：「VASP 算出的分子的频率有 3N 个，其中 6 个属于平动转动在振动自由度上的投影，这最小的 6 个频率中可能出现虚频，**这些频率可以直接无视**」[讲义] L3 P36]。
- ⚠️ **ZPE 求和口径有个坑**：讲义 P61 写「取最后一**排** meV 的能量和，再除以 2000」，但讲义 P71 算 O₂ 时只取第一个频率（`ZPE = 194.29/2000 = 0.097145 eV`）；把 O₂ 的 6 行全加起来会得 0.10836 eV（≠ 讲义的 0.097145）[讲义] L3 P61 vs L3 P71]。
  **判断：只对真实的 3N−6（或 3N−5）个振动模式求和，虚频不计入**；P61 的写法只对「列出的频率全是真实振动模式」时成立 [待核对]。
- ⚠️ **别用「前 3N−6 个」当通用规则**：VASP 5.4.4 打印顺序是「实频由大到小在前，`f/i` 虚频排在最后」（精读报告由三个实例归纳），所以该说法只在特定例子里碰巧成立；**稳妥做法是逐行看 `f/i` 标记** [待核对] learn_L3 §4.1-C-6。
- **前置处理实例**：新建 `freq` 目录、复制 TS 的最终结构作 `POSCAR`，用 `vaspkit 403` 输入 `0 0.48` 固定吸附的 O 以下的原子 [讲义] L3 P29]。
- **讲义的三个频率实例（可作对照基准）**：
  - Au–O 体系：IS / TS / FS 的实频汇总表（cm⁻¹ 与 meV 两套单位）[讲义] L3 P35]， TS 的虚频 132 cm⁻¹ 就是判定「这是一个真过渡态」的依据 [讲义] L3 P33]；
  - H₂O 分子：输出的 3N 个频率里最小的 6 个会出现虚频、**可以直接无视** [讲义] L3 P36–P37]；
  - O₂ 分子：3N−5 = 1 个真实振动模式，算 ZPE 时只取第一个频率 [讲义] L3 P71]。 → 这三例构成「表面吸附物 / 分子 / 双原子分子」三种典型情形的读法样板。
- ⚠️ **`OUTCAR` 里 `NFREE` 的说明文字会误导人**：`IBRION=5` 时回显的是 `NFREE = 2  steps in history (QN), initial steepest desc. (CG)` —— 那是给 `IBRION=2` 用的说明文案，程序复用了同一个标签名 [算例] learn_L3 §3.8.2-X18。

### 6.2 过渡态：方法选型

- **定义**：目标是**一阶鞍点** ——「仅在沿着反应路径上是能量极大点，而在（与）之正交的其他所有方向上都是能量极小点」 [讲义] L3 P114–P115]。
- **没有过渡态的过程（讲义列出）** [讲义] L3 P116]：离子键断裂成阴阳离子；共价键断裂成两个自由基（如 CH₃CH₃ → 2·CH₃）；一些表面吸附/脱附过程；以及「一些吸附/脱附过程静态计算不出过渡态，但模拟自由能势能面存在过渡态 —— 这是熵效应的影响」。
- **按所需初猜分四类** [讲义] L3 P117]：① 单个初猜（**DIMER**）；② 反应物 + 产物（**CI-NEB**）； ③ 基于反应物；④ 势能面扫描。**VASP(VTST) 最好用的两种就是 DIMER 与 CI-NEB**； VTST 是插件，**编译 VASP 时要导入**。
- **选型判断** [讲义] L3 P133、P164–P168]：

| 情形 | 建议 |
|---|---|
| 简单扩散、路径近似直线 | CI-NEB 效率高 |
| 初猜结构好 | Dimer 效率很高 |
| 初猜不好 | Dimer 经常失败 |
| 复杂催化反应 | **先 CINEB/NEB 粗搜 → 取能量最高的结构作 Dimer 初猜 → Dimer 精修** |
| 只要一个初猜、可以不要 IS/FS | Dimer 可以不需要 IS/FS，但「这个早晚要算的」 |

### 6.3 CI-NEB：原理、代价、输入、流程

- **原理** [讲义] L3 P118–P124]：在反应物到产物之间插入 **P−1 个**点，反应物编号 0、产物编号 P，首末固定，其余点受「势能面的力 + chain 方向弹簧力」；
  **nudge 过程**把弹簧力的垂直分量投影掉、把势能力沿路径的分量投影掉；
  **CI-NEB** 让能量最高的点**不再受弹簧力**并把沿路径的势能力分量**符号反转**，使它爬到鞍点。
- **代价与插点数（讲师明确反对「越多越好」）**：「CI-NEB 只需要很少的点，包含初末态总共 **5 个甚至 3 个点**就能准确定位过渡态」；「在网上看到一些说法 CI-NEB 插点越多越好，**这是错误的结论**！…… 大多数时候插 **3 到 4 个点**已经完全能应付正常的过渡态计算需要」[讲义] L3 P124]；「（好多人被网上的有毒的教程误导，认为插一个点不对，这其实完全没有问题，这里只插一个点和插三个点的结果完全一样。）」[讲义] L3 P126]。经验规则：**插点数目 ≈ `dist.pl` 返回值 / 0.8** [讲义] L3 P126]（⚠️ 同页例子 dist = 1.7392 → 公式给 2.17，但讲义只插 1 个 → 这只是量级经验，不是硬约束 [算例] learn_L3 §4.1-C-9）。
- **完整步骤（课程版 12 步）** [讲义] L3 P125–P136]：

| 步 | 动作 |
|---|---|
| 1 | 优化初态（IS）与末态（FS） |
| 2 | `dist.pl ini/CONTCAR fin/CONTCAR` 检查相似程度；**返回值 < 5 Å 一般可继续**；数值很大要检查初末态**原子顺序**是否一一对应 |
| 3 | `nebmake.pl ../is/CONTCAR ../fs/CONTCAR 1` 插点，成功提示 `OK, ALL SETUP HERE`，生成 `./00 ./01 ./02` |
| 4 | `cp ../is/OUTCAR ./00/`、`cp ../fs/OUTCAR ./02/` |
| 5 | `nebmovie.pl 0` 检查插点合理性（可跳过） |
| 6 | 准备 INCAR（见下） |
| 7 | `POTCAR` 与 `KPOINTS` 直接复制结构优化的 |
| 8 | 提交；**核数必须整除插点数量**（节点数最好等于插点数） |
| 9 | `nebef.pl`（或 `nebefs.pl`）跟踪收敛，后三列为最大原子受力 / 能量 / 相对初态的能量 |
| 10 | 收敛判据：**所有插点的最大原子受力都 < abs(EDIFFG)** |
| 11 | 频率计算验证虚频（只需对能量最高的 image 做，见下） |
| 12 | `nebresults.pl` 总结 |

- **CI-NEB 的 INCAR** [讲义] L3 P129、L3 P131]：
  ```
  EDIFFG = -0.03
  IBRION = 3
  POTIM  = 0
  NSW    = 300
  ISIF   = 2
  ICHAIN = 0        # 开启 NEB
  LCLIMB = .TRUE.   # 爬坡 = CI-NEB
  IOPT   = 1
  IMAGES = 1        # 插点个数
  SPRING = -5       # 弹簧常数，用默认即可
  ```
  逐条理由（讲义原话）：`EDIFF = 1E-7`「**这个参数非常关键！**过渡态对力计算精度要求极高……
  **好多过渡态计算不收敛原因都是因为力的精度不够**」； `EDIFFG = -0.03`「过渡态可以适当放宽结构优化收敛精度到 −0.03，非常复杂难收敛的可放宽到 −0.05」； `IBRION = 3` + `POTIM = 0`「这是 VTST 识别并启动 VTST 优化算法的标致（标志）」； `IOPT` 推荐 7、2、1，「0 意味着启用 VASP 自带的优化算法」。
- **`IOPT` 语义** [讲义] L3 P130]：`IOPT = 1、2` 适合精收敛；`IOPT = 7` 适合粗收敛。 ⚠️ 答疑补充：「如果正常计算结束，没有影响。**IOPT 只会影响过渡态结构是不是容易找到。只要找得到，用啥 IOPT 参数都没影响。**」[答疑] D4-P41、D4-P42]。
- **`IMAGES` 的语义**：指两个固定端点之间的像数，**总点数 = IMAGES + 2** [讲义] L3 P131]。官方口径：`IMAGES` 指定的是「独立 VASP 计算的目录数」（`01, 02, 03…`），且「只设 `IMAGES` 而不设其它 tag 时，执行的是一条弹性带计算，默认就是推荐的 NEB 方法」[官方] `references/official/pages/IMAGES.md`。
- **后处理** [讲义] L3 P134–P136]：`nebresults.pl` 依次跑 `nebbarrier.pl`、`nebspline.pl`、`nebef.pl`、 `nebmovie.pl`、`nebjmovie.pl`、`nebconverge.pl`，并把各目录 OUTCAR 打包成 `.gz`（`gunzip 0*/OUTCAR.gz` 可解开）；产物有 `mep.eps`（横坐标是 `dist.pl` 距离）、`vaspgr/` 各插点收敛图、`movie.xyz`。 ⚠️ `nebspline.pl` 拟合出的极值点**不一定是真实存在的**，需要自己判断并做频率验证；「实际上一般我们只关注能量最高的 image 能量（用 `nebef.pl` 获取）」[讲义] L3 P162–P163]。
- **只对能量最高的点算频率**（正文没写、答疑补的）：「频率只算能量最高的点即可」；「能量出现下降是不对的」[答疑] D3-P33、D3-P34]。

### 6.4 DIMER：原理、输入、输出怎么读

- **原理** [讲义] L3 P137–P140]：Dimer 由两点组成，间距 2ΔR，**通常 2ΔR ~ 0.01 Å**；因为间距极小，**对力精度要求非常高（`EDIFF = 1E-7`）**；每一步包括**旋转**（保持中点不变，转到能量最小 = 曲率最小方向）与**平移**两步；曲率 `C > 0` 时尽快离开该区域，`C < 0`（过渡态/高阶鞍点区域）时把平行分量符号反转；
  **收敛判据：力 `F(R) < abs(EDIFFG)` 且曲率 `C < 0`**。
- **历史与版本** [讲义] L3 P141]：Henkelman 1999 / Heyden 2005（improved dimer）/ Kästner 2008（收敛性），「这些改进都加入最新 VTST；**5.4.4 的 VASP 里也把改进的 Dimer 方法加入了**」。
- **初猜技巧（最需要技巧的地方）** [讲义] L3 P142–P143]：「初猜要尽量接近过渡态」；**最基本的技巧：保证没有过短的键**（过短的键会导致强排斥，让结构在前几个离子步崩掉）；例子：O 扩散时在 bridge 位（过渡态）**O 的 z 坐标会更高一点**。
- **MODECAR** [讲义] L3 P144–P145]：定义**初始 dimer 方向**；没有它程序自己随机初猜一个方向（**强烈建议设置**）；用 `modemake.pl ../is/CONTCAR ../fs/CONTCAR`（或用 `is/CONTCAR` 与 `./POSCAR`，但要把 `CONTCAR` 尾部的速度部分删掉以保持行数一致）生成；内容格式是**每个原子一行、每行 3 个数**（dx dy dz）；「MODECAR 就是 dimer 的方向，也就是我们期待的**虚频的振动方向**」，计算过程中每个旋转步会更新 `NEWMODECAR`。
- **DIMER 的 INCAR** [讲义] L3 P146–P147]：`ICHAIN = 2`、`IOPT = 2`、`IBRION = 3`、`POTIM = 0`、 `EDIFF = 1E-7`、`EDIFFG = -0.03`（讲义模板；真实算例写 −0.01，见 §3.5）； `DdR`/`DRotMax`/`DFNMin`/`DFNMax` 在讲义里是**注释状态**，没有展开讲取值含义。
- **`DIMCAR` 六列怎么读** [讲义] L3 P149–P151]：

| 列 | 含义与判据 |
|---|---|
| `Step` | 平移 Dimer 的步数；每个平移里可含数个旋转 |
| `Force` | Dimer 在任意自由度上的最大受力；**这个 Force < abs(EDIFFG) 不是判断收敛的标准** |
| `Torque` | 扭矩；**当 Torque < 1 时进入下一个平移步**；旋转过程中应不断下降，**不降就用更小的 EDIFF、`PREC=Accurate`，或提高 `DdR`** |
| `Energy` | Dimer中点的能量；**不能用作最终过渡态能量** —— 「过渡态能量取 OSZICAR 最后一个 E0」 |
| `Curvature` | 每个平移步里应逐渐下降；**接近过渡态的标志是 Force 变小且 Curvature 为负**；不是负值说明离过渡态还远 |
| `Angle` | 旋转角度，每个平移步里也应逐渐下降 |

- **收敛确认三条命令** [讲义] L3 P153]：`grep converged OUTCAR`（应出现 `OPT: skip step - force has converged`）、 `grep RMS OUTCAR`（看 `FORCES: max atom, RMS` 行，最后一个受力 < abs(EDIFFG)）、 `tail -1 OSZICAR`（取最后一个 `E0` 作过渡态能量）。讲义算例：**207 个离子步、总用时 9620 秒**；并明确说「我们设置的 EDIFFG = −0.01，发现 DIMCAR 里的 Force 没有到 0.01 就收敛了，**这是正常的**」。
- **动画与跟踪** [讲义] L3 P152]：每步输出 `CENTCAR`（格式同 POSCAR）与 `NEWMODECAR`（格式同 MODECAR）； `dimmode.pl CENTCAR NEWMODECAR 32 0.5` 生成 `dimmode.xyz` 动画（Jmol/VMD 打开）； ⚠️ 该脚本要求 **CENTCAR 第一行是元素组成**。
- ⚠️ 讲义给的 `DdR` 有两个值：INCAR 注释里是 `5E-3`，调参处方里说「提高 `DdR=0.01`」—— 两者语境不同（默认 vs 处方），但**真实算例里 `DdR` 都是注释状态，没有实算取值** [待核对] [算例] learn_L3 §4.1-C-7。
- ⚠️ `neb2dim.pl` 那一段讲义给的参数是 CINEB 的参数（`ICHAIN=0/LCLIMB/IOPT=1/IMAGES=1/SPRING=-5`），与 Dimer 实际需要的 `ICHAIN=2/IOPT=2` 冲突 [讲义] L3 P166]；真实算例里 CINEB 段整块被注释掉、生效的是 `ICHAIN=2` + `IOPT=2` [算例] learn_L3 §4.1-C-10 → **以 Dimer 的 INCAR 为准，别照抄 P166**。

### 6.5 插点方法：nebmake.pl（线性）vs IDPP

- **线性插值的两个缺点** [讲义] L3 P168]：初始结构远离真实反应路径；可能出现非常不合理的键长/键角甚至原子重叠。
  **适用范围：近乎直线的原子扩散问题**。
- **实例（讲义的核心对比）**：反应 `*C6H11 + *H → C6H10 + H2`；用 `nebmake.pl` 插点时 **(03) image 的 C–H 键只有 0.59 Å**，会使初始受力极大、一个离子步后就偏离路径；用 **IDPP** 插点是 **1.09 Å** [讲义] L3 P169、L3 P171]。算例逐像复核：`c6h12-nebmake/03` = 0.5916 Å；`c6h12-idpp/03` = 1.0879 Å [算例] learn_L3 §3.8.1。
- **IDPP**：J. Chem. Phys. 140, 214106 (2014)；思路是先线性插值、再定义原子距离的插值、构造虚拟势能面做简单 NEB 优化，**主要目的是避免某些原子相距太近** [讲义] L3 P170]。实现：ASE、pymatgen-diffusion；讲义的 `idpp.py`（许楠博士）用法与 `nebmake.pl` 相同 [讲义] L3 P172]： `python3 ~/bin/idpp.py POSCARis POSCARfs 4` → 得到 `00 ~ 05` 共 6 个文件夹 [讲义] L3 P173]。疑难体系可 `... 1`（只插 1 个点）[讲义] L3 P155]。 ⚠️ 脚本里的 solver 参数是写死的（`sort_tol=1.0`、`maxiter=5000`、`tol=1e-5`、`gtol=1e-3`、 `step_size=0.05`、`max_disp=0.05`、`spring_const=5.0`）[算例] `things to study/idpp.py`。
- ⚠️ **算例归档的两个陷阱**（要用这些目录做教程时务必注意）： `day3/idpp/nebmake/` 目录名虽叫 nebmake，**内容其实是 IDPP 的结果**（与 `c6h12-idpp` 的 02–05 逐字节相同）；而 `c6h12-nebmake/` 才是线性插值 [算例] learn_L3 §3.8.2-X8、X-9。

### 6.6 五类常见失败模式与讲师处方（L3 P154–P158）

| # | 现象 | 处方 |
|---|---|---|
| 1 | CINEB 的**中间点能量比初末态都低** | ① IS 与 FS 之间还有极小点；② **初态/末态本就不是极小点** → 用更严格的精度重算初末态 |
| 2 | CINEB 一开始就有**极大原子受力（>10 eV/Å）** | 原因肯定是初始结构不合理 → 改用**非线性插点**（`idpp.py`），或把不合理的 POSCAR 下载下来人工调整 |
| 3 | 已接近收敛但力长期不达标 | ① 力精度不够 → `PREC=Accurate`、`EDIFF=1E-7`；② 算法不合适 → 试 `IOPT=7` 或 `IOPT=0`；③ 也可能收敛标准过严 |
| 4 | 收敛了但**没有虚频或有两个以上虚频** | 没有虚频 → 计算肯定错，最可能是力精度不够；多个虚频 → `EDIFF=1E-7`，**或换 Dimer** |
| 5 | `nebmake.pl` 插点结构非常混乱 | 检查初末态的**原子顺序**是否一一对应；「计算初末态的时候就要注意不要打乱相应的原子顺序」 |

补充处方：Dimer 旋转中 Torque 不降 → 更小的 EDIFF、`PREC=Accurate`、或提高 `DdR` [讲义] L3 P151]；
Curvature 不是负值 → 离过渡态还较远，耐心等 [讲义] L3 P151]；
结构严重偏离 → 杀掉任务重新调整初始构型 [讲义] L3 P148]。

### 6.7 反应动力学与机理（L3 末段，了解范围即可）

- **动力学** [讲义] L3 P174–P183]：单/双分子基元反应速率（三分子几乎不存在）； Arrhenius 方程与速率常数计算；过渡态理论 TST 公式与 `k.py` 小脚本；半衰期与 ΔGa 对照表；谐振过渡态理论 HTST；隧穿效应与 Wigner 透热系数 `κ(T) = 1 + 1/24 [1.44 × ν≠/T]²`。
- **机理** [讲义] L3 P185–P195]：表面催化三类基元步骤与三大机理
  **LH（Langmuir-Hinshelwood）/ ER（Eley-Rideal）/ MvK（Mars-Van Krevelen）**及各自最简形式的速率式；经典实例：合成氨（LH）、Volmer-Heyrovsky HER（ER）、CO 氧化（MvK）；催化循环的两个要点：**催化剂必须复原**；**催化剂不改变总反应的能量变化**。

## 7. 主题六：电催化（L4）

### 7.1 方法论的边界（先记住讲师自己声明的适用范围）

- 做法：电催化计算思路与热催化类似，文献最常见的是**台阶图**方法 ——
  **不用考虑过渡态，只算中间体能量，额外多考虑 `eU` 的贡献** [讲义] L4 P3]。
- ⚠️ **前提被明确写出**：这是基于 Nørskov 的经典方法，**忽略了静电势和溶剂化作用**；「实际电极反应是个极复杂的过程，精确考虑静电势、溶剂化作用、双电层结构、传质速率等是前沿课题」[讲义] L4 P3]。 → 这一句决定了：**纯热力学台阶图本身就是「不加溶剂化」的近似**，不是遗漏。
- 总纲（该页只有一行）：「电催化计算最基本的就是计算过电势：Norskov 模型」[讲义] L4 P20]。

### 7.2 过电势与决速步

- **定义**：`η = 实际电极电势 U − 理论平衡电势 Ueq` [讲义] L4 P5、L4 P6]。示例：OER 理想 1.23 V(SHE)、实际 1.53 V(SHE) → η = 0.3 V [讲义] L4 P5]。
- **OER 的 U 取法**：**U = 能量上升最高的一步的能量 / e** [讲义] L4 P6]；
  **ORR 相反**：`U = 能量下降最小的一步的能量 / e` [讲义] L4 P14]。
- **决速步判据**：`G_OER = Max(ΔG1, ΔG2, ΔG3, ΔG4)` [讲义] L4 P11]。讲义例子：第三步吸热 2.04 eV、第四步 0.42 eV（1.23+1.23+2.04+0.42 = 4.92 自洽），加 1.23 V 后第三步仍吸热 2.04 − 1.23 = **0.81 eV** →「这 0.81 V 就是过电势」。
- **OER 四步 ΔG 的显式表达式** [讲义] L4 P8]（原文上下标被打散，已按语义还原）：
  ```
  ΔG1 = G(*OH)  + ½G(H2) + eU − G(*)    − G(H2O)
  ΔG2 = G(*O)   + ½G(H2) + eU − G(*OH)
  ΔG3 = G(*OOH) + ½G(H2) + eU − G(*O)   − G(H2O)
  ΔG4 = G(O2)   + G(*)   + ½G(H2) + eU − G(*OOH)
  ```
  其中 `e = -1`，`U` 是 vs SHE 的电极电势；`U = 1.23 V` 时 `eU = −1.23 eV`。 → 每一步都含一个 `eU`，所以把 U 从 0 抬到 1.23 V 会让第 n 步的累积自由能整体下移 n × 1.23 eV [算例] learn_L4 K27（推论）。
- **总自由能变化**：OER 总变化 **4.92 eV**、4 步、理想每步 4.92/4 = **1.23 eV** [讲义] L4 P10]。

### 7.3 CHE 参考态：O₂ 与液态水这两条硬规矩

- **两个参考态约定** [讲义] L4 P9]：
  1. 「在 pH = 0、U = 0 V (SHE) 条件下，**G(H₂)/2 = G(H⁺) + G(e⁻)**」（把 H⁺+e⁻ 整体替换成 ½G(H₂)）；
  2. 「G(H₂O) 是液态水的能量，等于**饱和蒸气压下的水蒸汽能量（常温下 ~0.035 bar）**」。
- **⚠️ 坑 1：O₂ 的能量不能直接算**。「需要用 `2G(H2O) − 2G(H2) − G(O2) = −4.92 eV`，先计算出 G(H2O) 和 G(H2)，再算出 G(O2)，**以保证总包的反应能量**（同理 CO、N₂ 也需要能量反推）」[讲义] L4 P9]。答疑把原因说得很清楚：「ΔG 校正值吻合得很好。**但是 O₂ 的 DFT 计算出来的电子能量不准确，所以才要用热力学数据减。**」 [答疑] D4-P19、D4-P20] → **错的不是热力学校正项，而是 DFT 电子能本身**。
- **⚠️ 坑 2：液态水不能当气相水算**（要显式带温度与压力；讲义给的写法是 `vaspkit-502-298.15-0.035-1`）[讲义] L4 P9]。
- 讲义给的三条参考数据（Pressure/bar | Temperature/K | E(DFT)/eV | DG/eV | G/eV）[讲义] L4 P9]： O₂(g) 1 / 298.15 / — / — / **−9.91**；H₂(g) 1 / 298.15 / −6.76 / −0.045 / **−6.80**； H₂O(l) 0.035 / 298.15 / −14.22 / −0.001 / **−14.22**。 ⚠️ O₂ 的 `−9.91` 与配套 `oer.xlsx` 的 `−9.92` 差 0.01 eV（差异来自 H₂ 自由能取 −6.805 还是 −6.80）[算例] learn_L4 C9；该表是**手填 + 取整**的汇总表，用于量级与流程，不要当高精度数据源 [算例] learn_L4 C10。

### 7.5 pH、酸碱与标度关系

- **pH 只通过 H⁺/OH⁻ 的化学势进入**：`E(H⁺) = ½E(H₂) − 0.0592 pH` [讲义] L4 P15]； ΔG 的推导 `ΔG = 2G(H2O) − 4×(½G(H2) − 0.0592·pH) + G(O2)`； pH=0 → −4.92 eV，pH=14 → **−1.605 eV**；`0.0592` 来源于 `ΔG = ΔG° − kT·ln(1/[H⁺])` [讲义] L4 P17]。
- 酸性（pH=0）标准电极电势 1.23 V（该页表格写 **+1.229 V**）、碱性（pH=14）**0.401 V**；「实际上，这两个反应从热力学角度看是等价的，H⁺ + OH⁻ ⇌ H₂O，可以直接把 OH⁻ 换成 H⁺ 计算。酸性和碱性条件下计算方式是一样的」[讲义] L4 P16]。答疑补充：「如果只考虑热力学，没有区别，但是反应过程参与的物种可能不同。H₃O⁺，H₂O」[答疑] D4-P25、D4-P26]。
- **标度关系与火山曲线** [讲义] L4 P25–P31]：`ΔG_OOH = ΔG_OH + 3.2`、`ΔG_O = 2ΔG_OH`（ABO₃ 氧化物 / 金属）；由这两条得四条线 `G4 = 1.72 − ΔG_OH`、`G3 = 3.2 − ΔG_OH`、`G2 = G1 = ΔG_OH`；
  **ORR 取四条线的最小值、OER 取最大值**；火山顶点：**ORR ≈ 0.9 V**、**OER ≈ 1.5 V**，限制因素是「*OH 吸附过强 / *OOH 吸附过弱」；二维火山图（三者取二为自变量）的顶点是 `ΔG_O = 2.46、ΔG_OH = 1.23、ΔG_OOH = 3.69 → η = 0 V`。 ⚠️ **这两处不能同时成立**：若 `ΔG_OOH = ΔG_OH + 3.2`，则 ΔG_OH = 1.23 时 ΔG_OOH 应为 4.43，四步变成 1.23/1.23/1.97/0.49 → **η ≈ 0.74 V**。要让 η = 0 成立，必须 `ΔG_OOH − ΔG_OH = 2.46`。两处引的是不同文献（P25 引 Chem. Rev. 2018，P29 引 Science 2017），**不裁定哪个对** [算例] learn_L4 C3。
- **NRR / CO₂RR 补充** [讲义] L4 P22–P24、P28、P30]：NRR `N₂ + 6H⁺ + 6e⁻ → 2NH₃`，标准电极电势 0.057 V，「−0.17 eV 每 NH₃（**大多数文献都算错了**）」；CO₂RR `CO₂ + 2H⁺ + 2e⁻ → CO + H₂O`，U = −0.11 V； Cu 上 CO 可深度还原或 C–C 偶联。配套算例里**没有** NRR/CO₂RR 目录 [算例] learn_L4 K77。
- **两条判定「是不是电化学基元步骤」的答疑判据（很好用）**：
  - `O₂ + * → *O₂`：「**这一步不是电化学基元步骤**，不涉及 H⁺ + e 产生的过程，可以加到台阶图里，**但是这一步不会随着 U 的变化而变化**」[答疑] D4-P45、D4-P46]；
  - N₂ 解离或 H₂ 解离：「**这种步骤不是电化学基元步骤，在电化学计算里没有 eU 这一项**，不会受电势 U 的影响改变台阶的能量」[答疑] D4-P15、D4-P16]。 → **判据一句话：这一步里有没有 H⁺ + e⁻ 参与；没有就不含 `eU`、不随 U 平移。**

### 7.6 传统模型的两条缺陷、溶剂模型与 VASPsol

- **两条缺陷（判「什么时候必须加更高级处理」的来源）** [讲义] L4 P32]： ① 吸附分子在溶剂中的行为与真空不同；② 任何两相接触都会产生界面电势差（双电层），电极电势会影响静电势 φ。参考书：Bard《电化学原理》第 13 章。
- **双电层部分可执行内容极少** [讲义] L4 P33–P38]：Helmholtz(1879) 平行板模型 → 实验上 Cd 是变量（Hg/NaF 的 V 型曲线、浓度依赖）→ 引入扩散层（Gouy–Chapman）→ Poisson–Boltzmann → 再引入离子尺寸与溶剂化离子；引入了**零电荷电势 PZC** 概念。 ⚠️ **除概念外没有任何可直接写进 INCAR 的参数** [算例] learn_L4 K81。
- **显式溶剂模型** [讲义] L4 P39–P44]：溶剂分子真的出现在体系里、与 slab 等价处理；计算量大幅增加、往往需要构象平均（结合 AIMD 取点）。恒电势路线：**SHE 相对真空的绝对电位取 4.44 V**；「通过模拟固液体系的功函（真空能级和固液体系的差值），可以得到当前体系算出的能量相当于在什么 constant potential 发生的」；流程是「①建模、优化结构、AIMD 预平衡；②跑 20 ps 的 AIMD，每 1 ps 取出一个结构计算单点拿到功函，把 20 个功函做平均」；示例换算 2.40 V(vs Vacuum) ↔ −2.04 V(vs SHE)、3.81 V ↔ −0.63 V [讲义] L4 P41–P42]。
  **三个已知问题**：① AIMD 模拟水/空气界面不能保持；② 静电势依靠添加离子改变、不能连续调节； ③ 反应前后的静电势不等 → 对策「通过扩包逼近 constant potential 状态」[讲义] L4 P44]。
- **隐式溶剂模型** [讲义] L4 P46–P48]：把溶剂当成具有一定介电常数 ε 的连续介质；处理方便、计算量小；**缺点是无法描述氢键等强相互作用对反应机理的影响**； PCM 用孔洞形状描述分子、用孔洞表面的表观表面电荷（ASC）描述溶剂对溶质的静电场 [讲义] L4 P48]。
- **VASPsol** [讲义] L4 P49、L4 P54]：Cornell 的 Hennig + Arias 开发，修改 VASP 实现
  **linearPCM (GLSSA13)**；基于 **VASP 5.4.4** 编译两步：① makefile 的 `CPP_OPTIONS` 加 `-Dsol_compat`， ② 把 `VASPsol/src/solvation.F` 复制到 `./src`；官网 `http://vaspsol.mse.cornell.edu/`。用法：「需要打开 `LSOL = T`（默认水溶液）。把离子步关掉 `NSW = 0`」；四个溶剂参数 `EB_K = 78.400000`（bulk 溶剂相对介电常数，可查表）、`SIGMA_K = 0.600000`（dielectric cavity 宽度）、 `NC_K = 0.002500`（cutoff charge density）、`TAU = 0.000525`（cavity surface tension）；打印 bound charge 用 `LRHOB = .TRUE.`；「其他参数不能直接查表得到，需要拟合，但是 VASPsol 程序并没公开其他溶剂的参数，
  **所以目前只能改变介电常数近似代表其他溶剂**」。
- **⚠️ 讲师真实做法（逐条 diff 两组算例 INCAR 的结果）** [算例] learn_L4 K37、K73]：
  **加 VASPsol = 加 `LSOL`（`.TRUE.` 或 `T`）+ 把 `NSW` 改成 `0`；**
  **`LRHOB` 只在要打印 bound charge 时才需要；**
  **`EB_K`/`SIGMA_K`/`NC_K`/`TAU` 不写就是默认水（78.4 / 0.6 / 0.0025 / 0.000525）** —— 两组算例一个都没写这四个参数，却仍能跑出 `SOL:` 行 → 走的是程序默认值 [待核对]（没读 VASPsol 源码）。 → **要换溶剂必须显式写 `EB_K`**；只写 `LSOL=T` 得到的就是 78.4 的水。
- **溶剂化对能量的量级** [算例] learn_L4 K26]：H₂O 分子单点 ΔE = **−0.3128 eV（−7.21 kcal/mol）**；同一次运行 `OSZICAR` 里还打印了 `SOL: 6 -0.44079E+00 …`，其第一项与总能量差不一致，含义未能分解 [待核对]。
- **溶解自由能的标准态校正**：讲义给 **+1.89 kcal/mol**（= 0.08196 eV）[讲义] L4 P52]；答疑只给了一个外链，没讲清「加在哪个量上、加几次」[答疑] D4-P51、D4-P52] → 信息不完整 [待核对]。
- **频率与溶剂化的一致性（答疑给的处方）**：「最好用 vaspsol 下做频率校正，如果算不动，可以用没有 vaspsol 情况算也行」[答疑] D4-P31、D4-P32]。显式溶剂下：「把所有溶剂和 slab 都固定住算频率，再用 vaspkit 计算自由能校正」[答疑] D4-P39、D4-P40]。
- **什么时候必须加溶剂化/更高级处理**（讲义给的都是定性）[讲义] L4 P3、P24、P21]：需要**能垒**时（Nørskov 04 方法不能算能垒，可能需要引入溶剂分子）；需要**静电势/双电层的连续调节**时；碱性下的 **Volmer（H₂O 解离）**过渡态。相对地，**纯热力学台阶图 + CHE 是不需要溶剂化的**。

### 8.2 vdW 校正：两族方法

| 方法 | 关键词 | 课程的取舍说明 |
|---|---|---|
| DFT-D3 | `IVDW = 11`（zero-damping）/ `IVDW = 12`（Becke-Johnson damping） | 几乎不增加计算量，参数提前拟合；VASP 对常见泛函已设好默认参数，PBE/RPBE/revPBE/PBEsol 不需额外指定 |
| vdW-DF（非局域泛函） | `LUSE_VDW = .TRUE.` + `GGA = …` + `AGGAC`/`LASPH` 等 | 能体现弱相互作用对**电子结构**的影响、不需元素经验参数、可用于任何元素；**计算量大**（rVV10 较小）；需 `vdw_kernel.bindat` |
| TS | `IVDW = 20` | 精度一般不如 DFT-D3/rVV10/vdW-DF2；**仅支持前六周期不含镧系**；**不支持 `ADDGRID=.TRUE.`**；建议 `PREC=Accurate` |
| MBD@rsSCS | `IVDW = 202` | 在 TS 上改进、引入多体色散校正，「精度基本是最好的」 |

出处：[讲义] L1 P36–P39]。

- **官方层的确认（可把课程写法升级为有官方依据）** [官方] `references/official/pages/IVDW.md`： `IVDW=1|10` = DFT-D2、`11` = DFT-D3 zero-damping、`12` = DFT-D3 BJ damping、`2|20` = TS、 `202` = MBD@rsSCS —— 与课程一一对应。官方还补了一条**很重要的适用范围**：这些色散校正会加到能量、**原子受力与应力张量**上，所以色散校正下的**弛豫、MD、有限差分振动分析都可以做**；但**「这些方案目前不能用于基于 DFPT 的声子计算」** → 想用 `IBRION=7/8` 算声子时不要指望 vdW 校正生效。

### 9.1 程序不报错、但结果是错的（最危险的一类）

| # | 症状 | 原因 | 怎么办 / 自查动作 |
|---|---|---|---|
| 1 | DOS 曲线能用，但它来自**含离子步**的运行 | `NSW>1` 时 DOSCAR 是各离子步的平均（官方 DOSCAR 页明文，`[官方·未抓取]`） | 数 `OUTCAR` 里 `E-fermi` 出现几次；>1 就重做 `NSW=0` 单点 [算例] learn_L2 §3.9-A3 |

| 3 | 忘写 `EDIFFG`，优化「收敛得很快」 | 官方默认 `EDIFFG = EDIFF × 10`（正值 = 能量判据）[官方] `EDIFFG.md` | 显式写负值（如 −0.01 ~ −0.03），并检查 `OUTCAR` 的力收敛串 |
| 4 | `OPTCELL` 好像没生效 | 它**不在 OUTCAR 里回显** [算例] learn_L1 §3.15 | 比对 `POSCAR` 与 `CONTCAR` 的三个晶格矢量：冻结方向的数值必须逐位相同 |

| 6 | 用 DFT+U 做非自洽（`ICHARG=11`）或算能带，结果异常 | 官方：`ICHARG=11` 固定 CHGCAR 时结果未必等于自洽，**DFT+U 下偏差很大**；DFT+U 算能带**严格要求** `LMAXMIX=4`（d）/ 6（f）[官方] `LMAXMIX.md` | DFT+U 一定设 `LMAXMIX`（d=4、f=6）；能带/态密度尽量走自洽 |

| 10 | 差分电荷图「非常难看」 | 片段单点没收敛 [答疑] D2-P24] | 三个片段的单点都必须 SCF 收敛，且参数与吸附态完全一致、结构直接截取不再优化 [讲义] L2 P103 |

### 9.3 讲师的硬规则（照做即可，别问为什么）

1. **DOS/能带必须在优化之后另起单点算** [讲义] L2 P35、L2 P48]。
2. **频率与结构优化必须同级别**（泛函、格点精度、溶剂模型、vdW 校正一致）[讲义] L3 P26]。
3. **过渡态与频率一定要 `EDIFF = 1E-7`**（「好多过渡态计算不收敛原因都是因为力的精度不够」）[讲义] L3 P129]。
4. **过渡态恰好一个虚频；极小点没有虚频** [讲义] L3 P33、P140、P157]。
5. **CI-NEB 插点不要多**（3–4 个点足够，5 个甚至 3 个也行）[讲义] L3 P124]。
6. **Dimer 一定要写 `MODECAR`**（否则程序随机猜方向）[讲义] L3 P144]。
7. **用 VTST 的方法必须用编译了 VTST 的 VASP**（否则 `IBRION=3`+`POTIM=0` 关掉了结构优化模块）[讲义] L3 P148]。
8. **`LMAXMIX` 在 DFT+U 下必须设**（d = 4）[讲义] L1 P43；[官方] `LMAXMIX.md` 补充 f = 6。
9. **赝氢加在键中点且计算中固定** [讲义] L1 P58]。
10. **CI-NEB 的核数必须整除插点数量** [讲义] L3 P132]。
11. **台阶图只算中间体能量、不涉及过渡态**；要能垒就必须上更高级模型 [讲义] L4 P3、L4 P24]。
12. **电催化里的非电化学基元步骤不含 `eU`、不随 U 变化**（判据：有没有 H⁺ + e⁻）[答疑] D4-P15/P16、D4-P45/P46]。

**查更细的**：`playbook.md`（本节的每条都应有对应的四要素条目）；`decide.md`（阈值与选型）。
