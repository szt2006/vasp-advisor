# 报告模板 —— 方法学与结果的可复核记录

> **这是什么**：一份**填空结构**，用来保证你报告里的每个数字**都能被复核**。
>
> ⚠️⚠️ **本模板只给「该写什么」，不给「填什么」。**
> 里面**没有任何建议数值** —— 数值依你的体系、版本、集群而定，
> **填错了比不填更糟**（它看起来像是被核对过的）。
>
> 数值从哪来：`references/_SYSTEMS.md`（真实算例画像，**不是建议值**）、
> `references/decide.md`（取舍）、你的**收敛测试**。
>
> 用法：复制到你的项目目录（**不要改本文件**），逐项填。

---

## 一、方法学（**缺一项，别人就无法判断可比性**）

| 项 | 你要填的 | 从哪读 |
|---|---|---|
| 程序与版本 | `<<<例：vasp.5.4.4>>>` | `OUTCAR` **第一行**（`grep -m1 vasp OUTCAR`） |
| 泛函 / 色散修正 | `<<<例：PBE / IVDW=11>>>` | 你的 `INCAR` |
| `ENCUT`（eV） | `<<<>>>` | `INCAR`；**并注明是收敛测试选的还是照抄的** |
| 赝势（POTCAR 类型 + 版本） | `<<<例：PAW_PBE，potpaw_PBE.54>>>` | 你的 `POTCAR` 头部（⚠️ **不要把 `POTCAR` 内容或路径写进公开材料**） |
| k 点网格 / 密度 | `<<<例：Γ 居中 9×9×1，R=0.03>>>` | 你的 `KPOINTS`；**若用了 `KSPACING`，直接说** |
| 展宽 `ISMEAR` / `SIGMA` | `<<<>>>` | 你的 `INCAR` |
| 收敛判据 | `<<<电子：EDIFF=…；离子：EDIFFG=…>>>` | 你的 `INCAR` |
| +U / 杂化参数（若用） | `<<<LDAUL/LDAUU/J 或 AEXX/HFSCREEN>>>` | 你的 `INCAR` |
| 真空层厚度（若 slab/2D） | `<<<Å，以及是哪个方向>>>` | `POSCAR` |
| 并行配置 | `<<<核数 / NCORE / KPAR>>>` | **你的作业脚本**（⚠️ 见下节） |
| 隐式溶剂 / 其他修正（若用） | `<<<>>>` | 你的 `INCAR` |

> ⚠️ **并行配置也要写**。理由见 `references/playbook.md` §4b 的 AM-1：
> **不带并行配置的资源数字没有意义**；而且同一套 `INCAR` 在不同 `NCORE` 下
> 的行为**可能完全不同**（包括能不能跑起来）。

## 二、**每一步做了什么**（可复核的链条）

对每个算例，写一行：

| 算例目录 | 目的 | 是否正常收尾 | 关键结果 | 备注 |
|---|---|---|---|---|
| `<<<路径>>>` | `<<<例：体相弛豫>>>` | `<<<有 General timing / 无>>>` | `<<<能量 eV>>>` | `<<<>>>` |

⚠️ **"是否正常收尾"这一列不是形式主义** ——
`OUTCAR` 里没有 `General timing` 就意味着那次计算**不是正常结束的**
（墙钟 / 被 kill / 崩溃）。如果结果仍可用，**必须说明为什么**。

```bash
# 快速判：正常收尾的算例有哪些
for d in */; do printf "%-40s " "$d"; grep -c "General timing" "$d/OUTCAR" 2>/dev/null || echo 0; done
```

## 三、⭐ **本次没检查的项**（**这一节最容易被省，也最该写**）

> **为什么必须有**：本 skill 的核心价值主张是「**错了能被发现**」。
> 一份只写"我做了什么"的报告，读者**无法知道边界在哪**。

- [ ] 我**没有**做 `ENCUT` 收敛测试（`<<<如果做了，写做到多少 eV 收敛>>>`）
- [ ] 我**没有**做 k 点收敛测试
- [ ] 我**没有**做 `ISMEAR`/`SIGMA` 的金属性检查（`entropy T*S`）
- [ ] 我**没有**验证磁态（`<<<是否检查过收敛到的是期望的磁态？>>>`）

- [ ] 其它：`<<<>>>`

⇒ **把不适用的划掉，把真没做的留着。** 这份清单会被审稿人/合作者看到。

## 五、自检命令（**交出去之前跑一遍**）

```bash
python scripts/compare.py <你的算例目录>      # 自洽性：能量/原子数/ENCUT/力平衡
python scripts/validate.py <你的算例目录>     # 输入还合规吗
python scripts/diagnose.py <你的算例目录>     # 有没有本 skill 认得的症状
```

⚠️ 三个都 `OK` **不等于结论对** ——
它们的 `OK` 只意味着「**我检查过的那些项**没发现问题」
（见 `AGENTS.md` 的「诚实的能力边界」）。
