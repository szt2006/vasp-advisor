Description: Number of slabs perpendicular to the temperature gradient in the Müller-Plathe method.

-----

{{TAG|FMP_SNUMBER}} defines the number of slabs perpendicular to the lattice vector \mathbf{a}_i along which the gradient \partial T/\partial \mathbf{a}_i  is created during the reverse nonequilibrium molecular dynamics run using the Müller-Plathe method.
