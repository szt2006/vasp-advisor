Description: The tag {{TAG|BPARAM}} specifies the value of the parameter b in the kernel of the nonlocal rVV10 correlation functional.
----
{{TAG|BPARAM}} should be set to 6.3, 15.7, 10, or 11.95 for the rVV10,{{cite|sabatini:prb:2013}}  SCAN+rVV10,{{cite|peng:prx:2016}} PBE+rVV10L,{{cite|peng:prb:2017}} and r^2SCAN+rVV10 {{cite|ning:prb:2022}} functionals, respectively.
