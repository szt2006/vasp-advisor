The {{FILE|NMRCAR.magres}} file is writte when calculating the chemical shieldings or calculating the electric field gradient if {{TAG|LNMRCAR|T}} (default). The file format followes the Magres format (https://www.ccpnc.ac.uk/docs/magres) in order to allow easy analysis using e.g. magresview (https://ccp-nc.github.io/magresview-2/) or the Python package Soprano (https://ccp-nc.github.io/soprano/intro.html) {{cite|liborio:jcp:2018}}. Mind that, while the Magres format does not clearly state if the macroscopic susceptibility should be included, here it is included in the chemical shielding.
