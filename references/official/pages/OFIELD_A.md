Description: The tag {{TAG|OFIELD_A}} sets the desired order parameter Q_6 in the Interface pinning method. 
----
The bias potential in the Interface pinning method is written as
::U_\text{bias}(\mathbf{R}) = \frac\kappa2 \left(Q_6(\mathbf{R}) - A\right)^2 .
The tag {{TAG|OFIELD_A}} sets the desired value of the order parameter A.
