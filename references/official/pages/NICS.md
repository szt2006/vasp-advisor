The {{FILE|NICS}} file contains the NMR nucleus-independent chemical shielding (NICS) in ppm. It is written if {{TAG|NUCIND}} = .TRUE. is set and no {{FILE|POSNICS}} is present. The format is the same as {{FILE|CHGCAR}} with a header to define the grid and then 9 blocks that correspond to the indices of the chemical shielding tensor \sigma_{ij}: \sigma_{xx}, \sigma_{xy}, \sigma_{xz}, \sigma_{yx}, \sigma_{yy}, \sigma_{yz}, \sigma_{zx}, \sigma_{zy}, and \sigma_{zz}.
