## §3 知识条目

### 3.0 本讲的骨架（我的概括）

L2 是"电子结构计算"两讲：**第（1）讲 = 态密度**（L2 P2–P95），**第（2）讲 = 电荷密度/波函数/势**（L2 P96–P156）。第（1）讲走"能带 → DOS → PDOS → d带中心"一条线；第（2）讲走"CHGCAR → Bader → 差分电荷 → partial charge / STM → 静电势/功函数 → ELF"一条线。两讲都以"Ni(100)-CO""N₂/Fe₃-Al₂O₃""MoS₂/WS₂""Au(111)/O-Au(111)"四个算例贯穿。

---

### 3.1 DOS / PDOS：怎么算、怎么读、数值怎么判

**怎么算（流程）**
1. **必须先优化结构**。L2 P35 明确"结构优化得到的 DOS 不能直接用，因为是平均了结构优化过程中的所有结构的 DOS"；L2 P48（注意事项6）再次强调"DOS 和能带计算一定是在优化结构之后做的，自己随便搭了个模型不优化就计算 DOS 一般没有意义"。→ 这条与 VASP 官方 DOSCAR 文档一致（官方原话大意：弛豫的 DOSCAR 通常无用，NSW>1 时最终 DOS 是所有离子步的平均；应把 CONTCAR 拷为 POSCAR 再做 NSW=0 的静态计算）[官方 DOSCAR 页](https://vasp.at/wiki/index.php/DOSCAR)。
2. **新建 `dos` 文件夹做单点**。L2 P35 给出文件准备：`cp CONTCAR ./dos/POSCAR`；`cp INCAR KPOINTS POTCAR CHGCAR ./dos`（P73 的练习三同法）。
3. **DOS 的 INCAR**（L2 P36 原样）：`NSW = 0`；`ICHARG = 1`（"这里用11(非自洽计算)也是可以的"）；`LORBIT = 11`（或 10）；`ISMEAR = -5`；`NEDOS = 1000`；`# NBANDS =`；`# EMAX = -20`；`# EMIN = 15`。
4. **自洽 vs 非自洽等价**。L2 P45（注意事项1）："可以用之前的 CHGCAR，做非自洽计算（ICHARG = 11）；也可以直接开始一个自洽单点计算（ICHARG = 1），只要收敛到同样的电子态上，结果是一样的。"
5. **k 点要加密**。L2 P46（注意事项2）："K点数目要适当取得更大，与结构优化相比，算 DOS 的时候需要用到更多的 K 点数目，这是因为 K 点越多，画出来的 DOS 图质量越高，曲线也会更平滑。"（讲义**未给任何数值判据**，见 §5）

**怎么读（文件与工具）**
- 产物是 `DOSCAR` 和 `vasprun.xml`（L2 P36）。三条读取路径：
  - **p4vasp**（L2 P37–39）：下载 vasprun.xml → 选 DOS+bands 看总 DOS → `Electronic-Local DOS+bands control` 选原子/元素/不同轨道 → export 到 origin。注意 L2 P39 提醒 p4vasp 导出的多条线会挤在一列里，需按能量范围手动拆分。
  - **vaspkit**（L2 P41–44）：主功能 11；`111` 总 DOS → `ITDOS.dat`/`TDOS.dat`（"一个是总 DOS，另一个是积分的 DOS，积分的 DOS 可以用来判断电子占据的具体数值"，L2 P43）；`112` 指定原子序号 → `PDOS_A10.dat`/`IPDOS_A10.dat`；`113` 每种元素 → `PDOS_O.dat`/`IPDOS_O.dat`/`PDOS_Al.dat`/`IPDOS_Al.dat`；`114` 多原子加和 → `PDOS_SUM.dat`/`IPDOS_SUM.dat`；`115` 指定轨道 → `PDOS_USER.dat`（依次输入 `O`↵`p`↵`Al`↵`p`↵）。
  - **ENERGY 对齐**（L2 P40）："如果我们直接截取 DOSCAR 里的数据作图，我们发现 Ef 的能量不是 0。一般我们都会把 Ef 移动的 0 eV 的位置，这就需要把横坐标都减去 Ef。P4vasp、vaspkit 和 pymatgen 取出的 DOS 数据都会自动 shift。" vaspkit 由 `~/.vaspkit` 中 `SET_FERMI_ENERGY_ZERO .TRUE.` 控制；费米能级用 `grep E-fermi OUTCAR` 取。
  - **ESMEAR 的边界条件**（L2 P46 注意事项3 + P47 注意事项4）："如果计算模型很大，只用了一个 gamma 点，或者 K 点的数目小于等于 3 的时候，使用 ISMEAR = -5 会导致计算出错"；原文给出的报错是 `VERY BAD NEWS! internal error in subroutine IBZKPT: Tetrahedron method fails for NKPT<4. NKPT = 1`；"当 K 点小于 3 个时候，ISMEAR 可以取 0 或 1 来算 DOS。（手册上建议用 -5，其实用 0 或 1，定性上完全没有问题）"。另一条代价："结构优化的时候不能使用 ISMEAR=-5，是因为四面体方法不能很好地处理费米能级处的电子占据情况，导致算出来的力会有一定百分比的误差。"

**数值怎么判**
- **DOSCAR 的列**：L2 没有直接讲列语义（答疑稿 D2-P2 讲了，见 §4.2-D1）。我用真实算例核对：`al2o3`（ISPIN=1）每行 3 个数值 = 能量 / DOS / **积分 DOS**；`Ag`（ISPIN=2）每行 5 个数值 = 能量 / DOS(up) / DOS(dn) / **积分 DOS(up)** / **积分 DOS(dn)**。→ "第 3 列是积分值"只在自旋非极化时成立。（此结论有官方 DOSCAR 文档依据）
- **DOS 的高度与宽度**：能带越密集/平缓处 DOS 越大（L2 P21）；"对 DOS 积分就能得到电子数目"（L2 P21）。
- **展宽判作用强弱**：L2 P22（PtH₄²⁻ 例）"根据 DOS 的展宽就能判断原子轨道之间的作用强弱程度，带心位置能影响体系和其他分子的相互作用"。
- **DOS 重叠判共价**：L2 P71"一般 DOS 的重叠意味着共价键的贡献，可以体现在轨道的重叠积分中，我们之后要讲的 COOP 就是由于相互产生的重叠积分计算而来的。"
- **PDOS 的和一定小于总 DOS**，并且**不能**用它谈占据数：L2 P48（注意事项7）给了英文解释"To obtain PDOS, a projection on spherical harmonics is done. In this procedure, you lose part of the information. So, the sum of the parts is lower than the whole DOS…"；L2 P49 明确"PDOS 的加和不重合总 DOS。所以对 PDOS 的占据轨道积分不能讨论某个原子轨道的占据数。"
- **LORBIT 附带的 total charge 不可用**：L2 P50"设置了 LORBIT 以后，OUTCAR 文件的末尾会输出一个 total charge。这里的电荷是根据 PROCAR 算出来的原子半径球内的电荷布居，不能定量，定性可以做参考，一般无视就行了。"→ 要定量原子电荷，讲义给的正路是"最常用的 Bader charge，还有 DDEC，NPA 电荷，用 lobster 分析能得到 Löwdin 和 Mulliken 电荷"。
- **LORBIT=10 与 11 的分工**（L2 P36）："10 只区分 s p d f 角量子数，11 区分磁量子数"。（官方称 11 为 lm-decomposed；用词问题见 §4.3-E9）真实算例 `PDOS_Ag_UP.dat` 的列头是 `#Energy s py pz px dxy dyz dz2 dxz dx2 tot`，与官方 lm 分解列序一致 ✓。

### 3.3 d 带中心：怎么算、怎么读、数值怎么判

**原理（L2 P80–P83）**
- 吸附分子靠近金属表面时，分子轨道与金属的 s、d 轨道都作用；其中"（分子轨道）−（金属 d 轨道）作用会导致能级分裂，生成的反键轨道的位置对体系的稳定性非常重要"（P80）。
- **判据**（P81）："反键态高于费米能级则有利于吸附，反键态低于费米能级则不利于吸附。"
- **趋势**（P82）："前过渡金属：D-band center 高，吸附能大；后过渡金属：D-band center 低，吸附能小。"
- **d–p 作用的定性解释**（P83）："O 原子在金属 Ag 和 Au 上吸附非常弱，是因为 O 的能级要高于 Au/Ag 的 d 轨道能级。在 d-p 相互作用以后，O 的 p 轨道能量上升（在形成的反键轨道上也占据电子），导致体系能量上升。而在 Fe, Ru 这样的金属上，d-p 相互作用以后反键 p 轨道的能级高于费米能级，所以 Ru 上 O 的吸附更强。"
- **调控逻辑**（P84）："同种元素 d-band center 改变，往往 d 轨道的宽度会随之改变。当带宽变窄（Wd），费米能级不变，则 d-band center 一定上升。"三条落地思路：配位数（P85：配位数越高→d 轨道越宽→d-band center 越低→吸附能越小）、晶格应变（P86）、次表层合金原子比例（P87）。
- **算法**（P88）："d 轨道的 pDOS 对能量做权重平均"；出处指向 Norskov 的书 119 页与"大师兄教程第 40、41 章"。同页有一条重要的模型代价提醒："一般来讲，我们做表面催化的计算，都要对表面体系做 DOS 计算，再算 band center，我们这里用的 bulk 的模型，算出来和表面体系会有一点差别。"（P88）

**怎么算（三条路，L2 P89–P93）**
1. 流程（P89–P90）：优化金属最密堆积表面 → 每个体系新建 `dos` 文件夹算单点 → "修改 INCAR，并适当提高 K 点精度" → `vaspkit 113` 生成 `PDOS_M_UP.dat` → 导入 origin，**对 5 个 d 轨道求和**。
2. **方法一：vaspkit 503**（P92）直接输出所有原子与总的 d 带中心，生成 `D_BAND_CENTER`。原文回显："The default energy window of integration is [-9.39 17.20]，Do you want to change the change (Y/N)?"；"这里输入 y，可以指定积分权重平均的能量范围"；文件表头为 `# Atom ID  d-Band-Center (UP)  d-Band-Center (DOWN)  d-Band-Center (Average) (in eV)`。同页工具自带警告："d-Band Center is Sensitive to the Number of Unoccupied Band. Anyway, the Trends are More Important than the Absolute Energies."
3. **方法二：vaspkit 115 + 自备脚本**（P93）：`115 – Ag – d – 0` 得 `PDOS_USER.dat`，再运行脚本并给一个能量上限（原文 `Python3 ~/bin/d-bandC.py PDOS_USER.dat 20`，"其中 20 是能量的上限范围"）。该方法的三个优点原文写明：可算 s/p/d/f 中心；可指定某几个原子；"因为高能的轨道(空轨道)计算误差非常大，且不参与成键，所以有的时候需要设置一个能量上限，比如 10 eV"。

**数值怎么判**
- 趋势 > 绝对值（P92 工具警告）；对非占据能带数目敏感。
- 讲义给的数：**Ag(111) = −3.75 eV，Ru(0001) = −1.74 eV**（L2 P91，并配 P92 的 vaspkit 回显 `Total: -3.7502 -3.7502 -3.7502`）。
- 与催化性质的关联（P94）："HER – H 原子的吸附能，d-band center 成近似的线性关系"；P95 给了文献的元素周期表 d 带中心数值（只有图，无数据表）。
- **真实算例核对（重要）**：`day2/Ag/D_BAND_CENTER` 实测 `Total: -3.7792(UP) -3.7750(DOWN) -3.7771(Average)`，积分窗口 `[-9.11 10.04]`。
  - 我核对了窗口来源：该文件的窗口 = `[EMIN−E_F, EMAX−E_F]`。`Ag/DOSCAR` 头给出 EMAX=11.00348932、EMIN=−8.15061128、E_F=0.96133580；−8.15061−0.96134 = **−9.11** ✓，11.00349−0.96134 = **10.04** ✓。
  - 推论：讲义 P92 的 −3.7502 与 P93 的 −3.7501883 是**把能量上限定到 20 eV** 算的（P93 命令行第 3 个参数就是 20），而算例文件用的是默认上限 10.04 eV，两者差 0.027 eV。**同一体系、同一 PDOS，仅积分窗口不同就改变了 d 带中心的绝对值**——这正好印证 P92 的"Trends are More Important than the Absolute Energies"。**做决策库时必须同时记录积分窗口。**
  - 另注：讲义 P92 回显里 UP=DOWN=Average（说明那次是非自旋极化）；算例 `Ag/INCAR` 是 `ISPIN = 2`，所以 UP≠DOWN（−3.7792 vs −3.7750）。这是两次不同设置的运行，属正常。

### 3.4 电荷密度、Bader、差分电荷、partial charge、STM

**CHGCAR 怎么读（L2 P97–P98）**
- "CHGCAR 是包含电子密度信息的格点文件，对于自旋极化体系计算还包含自旋电子密度。可以用 VESTA，Jmol 等程序打开。"
- 结构："最前面几行和 CONTCAR 是完全一样的"；`ISPIN=2` 时用 `chgsplit.pl CHGCAR` 可分出 `CHGCAR_mag`（自旋密度）与 `CHGCAR_tot`（电荷密度）。
- 格点段：坐标信息后**空一行**，然后输出 `NGXF, NGYF, NGZF`（`grep NGXF OUTCAR` 可查），**"这个数值可以在 INCAR 中指定，但是不建议这么做，一般用 PREC=Accurate 产生的格点数量就足够了"**；随后是 `ρ(r) * Vcell`，共 `NGXF*NGYF*NGZF` 个数。
- 实测核对：`Ag/OUTCAR` = `NGXF=80 NGYF=80 NGZF=300`；`al2o3/OUTCAR` = `60 60 56`；`ni-co/OUTCAR` = `56 56 280`。讲义 P98 展示的示例是 `100 100 96`（另一体系）。

**Bader（L2 P100–P101）**
- 两条命令：`chgsum.pl AECCAR0 AECCAR2`，然后 `bader CHGCAR –ref CHGCAR_sum`；"需要在 INCAR 里加上 `LAECHG=.TRUE.` 关键词"。
- 输出列的含义（讲义以图注给出）：笛卡尔坐标 / 原子盆体积 / 原子核到原子盆边界的最小距离 / 价电子数。
- 原子电荷着色图用 `vaspkit 508`（L2 P101）。
- **数值怎么判**：讲义正文没给"电荷转移多少算显著"的阈值。可用的锚点是两个案例数：Fe₃ 活性中心"low charge state (0.59 |e|)"（L2 P31）；N₂ 吸附后"Bader 电荷从 0 降低到 −1.13 |e|"（L2 P77）。

**差分电荷（L2 P102–P104）**
- 两种定义（P102）：（1）**片段差**：`Δρ = ρ_AB − ρ_A − ρ_B`；（2）**变形电荷密度**：`Δρ = ρ(AB_self-consistent) − ρ(AB_atomic)`（SCF 收敛后的密度减去各原子自由状态下球对称密度）。
- 操作（P103）：先优化吸附构型（"可选步，如果想要提高格点精度，比如 PREC=Accurate，则需要再算一步单点"）→ **分别算两个片段的单点**，且"结构从 CO/Ni(100) 直接截取，不要再结构优化！计算参数保持不变！"→ `vaspkit 314` 依次输入三个片段的 CHGCAR（`./CHGCAR ./co/CHGCAR ./slab/CHGCAR`）。
- **怎么读**（P104）："得到的 CHGDIFF.vasp 用 vesta 打开，isosurface 青色部分电荷密度减小，黄色密度电荷密度增加。"并把 `CHGDIFF.vasp` 改名为 `CHGCAR` 后用 `vaspkit 316` 得 `CHGPAVG.dat`，导入 origin 后"把 X-Y 坐标反转一下"（平面上平均的差分电荷随 z 的分布）。
- 答疑稿的两条补充（L2 正文没有）：**片段单点必须收敛**——"要求收敛，如果不收敛，减出来的电荷密度会非常难看，结果也不合理"（D2-P24）；**"有些特殊体系需要，比如：表面共吸附两个不同的分子，可能就用三个减"**（D2-P80，回应 D2-P79 的三片段差分）。

**实空间波函数（L2 P105–P106）**
- "VASP 计算得到的波函数信息都保存在 WAVECAR 文件里，这个文件是二进制文件，且波函数都是倒易空间的 G = n1b1+n2b2+n3b3，无法直接提取得到实空间的波函数。"→ Feenstra & Widom 的脚本 → "vaspkit 在此基础上改进，功能 511 可以直接指定 k 点和轨道序号，得到实空间的轨道波函数。功能 515 得到实空间的轨道电荷密度。"
- EIGENVAL（P106）：给出"能级 / 占据数÷2"，用于把 CO 的峰标成 3σ、4σ*、1π、5σ、2π*。

**Band decomposed charge density / partial charge（L2 P107–P124）**
- 概念（P107）："计算特定的某个(或某些) k 点和能带所对应的本征波函数的平方(也就是电荷密度)"；文献中也叫 Partial Charge Density（一般指一定能量范围内的电荷密度）。最常见应用是 VBM、CBM、表面态或局域态对应的 partial charge。
- 灵活性（P108）：可做单个轨道、一定能量范围、包含多个 k 点的总 partial charge。
- **流程**（P115）：先做自洽得到收敛的 WAVECAR；再新建一次运算直接从 WAVECAR 提取（"这一步可以理解成把 VASP 当作一个脚本来运行，并没有做新的 SCF 运算"）。
- **关键词（L2 P115–P119，逐个参数原文要点）**
  | 关键词 | 默认 | 讲义说明的用法与取值 |
  |---|---|---|
  | `LPARD` | `.FALSE.` | `.TRUE.` 时读入自洽收敛的 WAVECAR 并做 Band decomposed charge density 计算 |
  | `IBAND` | 无 | 控制算哪些能带，按 **EIGENVAL 的顺序**；如 `IBAND = 20 21 22 23` |
  | `NBMOD` | `-1` | `>0`：IBAND 中能带的数量（设了 IBAND 后会自动调整，不需手动设）；`0`：包含所有轨道（含非占据）；`-1`：正常算 CHGCAR；`-2`：算 EINT 能量范围内的 partial charge；`-3`：同 −2，但能量范围以费米能级为 0 参考 |
  | `KPUSE` | 无（所有 k 点） | 指定要算的 k 点，取值是这些 k 点**在 KPOINTS 中的序号**；算 Γ 点则 `KPUSE = 1` |
  | `EINT` | 无 | 两个实数 → `NBMOD=-2`，能量参考 **EIGENVAL 文件**（例：`EINT= 4.00 5.00`）；只给一个数 → 表示"从 EINT 到费米能级"，`NBMOD=-3`，能量参考**费米能级**（例：`EINT= -2.00` 表示 −2.0 ~ 0 eV） |
  | `LSEPB` / `LSEPK` | `.FALSE.`（合并） | `.TRUE.` 时按每个能带 / 每个 k 点分别写到 `PARCHG.$.$`；`.FALSE.` 时合并写到 `PARCHG.ALLB.*` 或 `PARCHG` |
- **三种用法模板（L2 P120–P121）**
  1. 指定能带 + 指定 k 点（研究 VBM/CBM 常用）：`ISTART=1 / LPARD=.TRUE. / IBAND=20 21 22 23 / KPUSE=1 / LSEPB=.TRUE. / LSEPK=.TRUE.` → 输出 `PARCHG.0020.0001.vasp` 等，**"手动添加 .vasp 后缀，因为 VESTA 不识别 .0001 后缀"**。
  2. 只指定能量范围 `[-10.0, -5.0]`、不指定 k 点：`NBMOD=-2 / EINT=-10.0 -5.0 / LSEPB=.FALSE. / LSEPK=.FALSE.` → 输出 `PARCHG`。
  3. 指定相对费米能级的范围 `[Efermi−1.0, Efermi]`：`NBMOD=-3 / EINT=-1.0` → 输出 `PARCHG`。
- **怎么读（关键判据，L2 P124）**：简并轨道**必须合并输出**。原例：288 号单独输出"电荷不完整，对称性不好"，287+288（VBM）、289+290（CBM）才正确。这是本讲最实用的一条 partial charge 判读经验。
- **真实算例核对**：`mos2ws2/EIGENVAL` 第 3 个 k 点块给出 `287 −2.799036 occ=1.000000`、`288 −2.799017 occ=1.000000`、`289 −0.201564 occ=0.000000`、`290 −0.201561 occ=0.000000`；讲义 P122 写的是 `287 −2.799024`、`288 −2.799005`、`289 −0.201544`、`290 −0.201541`。**数值到 10⁻⁵ eV 级别一致，占据数完全一致** → 讲义 P122 的 VBM=287/288、CBM=289/290 判断在算例中成立 ✓。`mos2ws2` 目录里也确有 `WF_SQUARED_B0287_K0001.vasp`（band 287、k 点 1）✓ 与 `IBAND=287 288 / KPUSE=1 / LSEPK=.TRUE.` 一致。
- 体系核对：`mos2ws2/POSCAR` = S64 + W16 + Mo16 = 96 原子，`EIGENVAL` 头 `96 96 300 1`（NBANDS=300），c=18.41 Å 真空；与讲义 P122"优化单层 (MoS₂)₁₆/(WS₂)₁₆ 异质结"、P127 回显"bands inside the range … 289 … 300"完全对应 ✓。

**STM 模拟（L2 P125–P129）**
- 原理（P125）：恒高模式下压电陶瓷管在 z 方向保持恒定，把隧穿电流值在 xy 空间作二维图。
- 参数（P126）：`NBMOD = -3` + `EINT = 2.0` 表示"施加的针尖偏压，即显示费米能级以上 2 eV 的态"；`EINT` 取负则显示费米能级以下的态（P129 用 `EINT = -0.1`）。
- **重要限制（P126）**："EINT 和实验上所施加的偏压绝对数值并不直接对应，需要自己测试对比图像。"两个关键值是"针尖偏压"与"恒定高度"。
- 检查（P127）：`OUTCAR` 最后会列出 partial charge 包含了哪些能带（每个 k 点一段），据此确认窗口是否合理。
- 作图（P128）：把 `PARCHG` 和 `vasprun.xml` 放进 p4vasp 文件夹，打开 vasprun.xml，点左侧 STM → 选 STM 自动 → 读入 PARCHG → 显示结构 → 超胞 → 调整恒定高度 → 恒高/恒流模式。
- 应用案例（P113–P114）：PtSe₂ 两个 Pt 缺陷的 STM 模拟图与费米能级附近缺陷态 PCD 对应；2D 硼团簇的 PCD 与模拟 STM 图像。

### 3.5 静电势与功函数

**静电势（L2 P131–P132、P146–P149）**
- 定义（P131）："衡量 r 处的单位点电荷与体系的静电相互作用势。第一性原理计算中，接近原子核的位置是负值，在远离原子核的真空中为 0。"
- **必须 shift（P132）**："VASP 算得真空能级不为 0，需要把真空能级位置 shift 到 0，静电势绝对值才有意义。"
- 分子范德华表面（P146）：气相分子 `r = 0.001 a.u. = 0.00675 e/Å³`；凝聚相 `r = 0.002 a.u. = 0.0135 e/Å³`；`1 a.u. = 1 e/Bohr³ = 6.748 e/Å³`。VESTA 里 N₂ 用 `0.001 e/Bohr³`。
- **数值怎么判（P149）**："越红的地方静电势更低，越容易受到亲电试剂的进攻。越蓝的地方静电势更高，越容易受到亲核试剂的进攻。"（P149 在 Properties-Isosurface 中把电荷密度表面数值调为 `0.002 e/Bohr³`）
- 作图（P148）：VESTA 中先导入 CHGCAR → `Edit-Lattice Planes` → 再在 `surface coloring` 里导入 LOCPOT。

**功函数（L2 P133–P135、P136–P142）**
- 定义（P133）："要使一粒电子立即从固体表面中逸出，所必须提供的最小能量（通常以 eV 为单位）"；**"功函数不是材料体相的本征性质，更准确的说法应为材料表面的性质（比如表面暴露晶面情况和受污染程度）"**。
- 计算定义（P134）：`Φ = Evac − EF`；"在第一性原理程序里都把 VBM 当作费米能级，和实验有些许不同，所以功函算出来也会有一点差别。"
- 输出（P135）：功函 = 静电势在 slab 法向上的分布（z 方向分布）；INCAR 设 `LVHAR = .TRUE.` 输出 `LOCPOT`，格式与 CHGCAR 完全一样；**"如果设置 LVTOT = .TRUE.，LVHAR = .FALSE. 则输出的 LOCPOT 文件是包含静电势和交换相关势能的总势能。"**
- 怎么算（P136–P138）：优化 Au 晶胞 → 建 Au(111)-p(2×2)，固定最下两层 → INCAR（`LVHAR=.TRUE.`、`ENCUT=400`、`ISMEAR=1`、`SIGMA=0.2`、`ISIF=2`、`NSW=300` 等）→ vaspkit 准备 POTCAR/KPOINTS → 用 vaspkit 对 z 方向积分，自动判断真空能级位置并输出 `POTPAVG.dat`，回显 `Vacuum-Level (eV): 6.673`；工具还提示"Check the Convergence of Vacuum-Level Versus Vacuum Thickness!"（**讲义没有给出真空层厚度的收敛判据，见 §5**）。
- 另一种做法（P140）：p4vasp 对 LOCPOT 在 xy 平面求和 —— `File-load system` 导入 LOCPOT → `Electronic – Local potential` → `Show, Z-direction` → "会出现三条线，我们要用的是中间那条，average 的线" → `Graph – export`。
- **数值怎么判（P139、P142）**
  - Au(111)-p(2×2)：`grep fermi OUTCAR` 得 `Efermi = 1.6561 eV`；`Φ = 6.673 − 1.6561 = 5.02 eV`（算术核对无误 ✓）。
  - O/Au(111)-p(2×2)：`Evac = 7.196 eV`、`Efermi = 1.5863 eV`、`Work function = 5.6097 eV`（算术核对无误 ✓）。
  - **规律（P142）**："吸附氧原子以后，功函数增大"；"由于上下表面不对称，在真空层中有明显偶极矫正，使得上下表面所对应的真空能级的位置不同"；"吸附带负电物种(ex: O)，功函增大；吸附带正电物种(ex: K)，功函减小"。
- **预测电子流向（P143–P145）**：用异质结两侧的 Φ 高低预测电子流向（P143 给出 `Φ = 5.22 eV` 与 `Φ = 6.43 eV`）；P144 说"静电势得计算结果和电荷差分的结果一致，当 TiO₂/g-C₃N₄ 异质结形成的时候部分电子会从 g-C₃N₄ 转移到 TiO₂ 上"；P145 用静电势分析表面负载团簇的电子流向。
  - 推论：由 P143+P144 可读出规则是**电子由功函较低的一侧流向较高的一侧**（故 g-C₃N₄ 侧功函较低）。但 5.22 / 6.43 分别属于哪个材料，文本无法确定，见 §5。

### 3.6 电子定域化函数 ELF（L2 P150–P156）

- **参数（P150）**：`LELF = .TRUE.`；`PREC = Accurate` 或 `High`；**去掉 NPAR、NCORE 参数**。理由原文："ELF 计算对格点精度要求很高，使用默认的网格精度（即 PREC = Normal 不能满足要求）"。输出 `ELFCAR`，格式与 CHGCAR 完全一样，可直接用 VESTA 打开。
- **怎么读**：讲义给的判据只有定性两极——"电子定域程度高 / 电子定域程度低"，具体案例：
  - 过渡态（P151，ACS Catal. 2018）：H₂ 异裂，"O-H 之间共价键成分高，Ce-H 则有更强的离子成分"。
  - 二维材料（P152）：FeB₆ 中"中间的三个 B 之间更红，可能有三中心键存在。Fe-B 之间有蓝色成分，Fe 可能呈现离子状态"。
  - 电子化合物（P153）：Na₂He 中"电子对在晶体中可以不依赖于原子核孤立存在，形成定域化程度很高的区域"。
  - 缺陷态（P154）：ZrO₂/HfO₂/ThO₂ 表面氧缺陷使电子对局域在空穴位置。
  - 分子团簇（P155）：B₁₃⁺ 外围 B-B 强共价键，中心 3 个 B 之间可能存在三中心键。
  - 吸附体系（P156）：CO/Ni(100) 的孤对电子与配位键。
- 讲义没有给 ELF 的数值分级（如 ELF=0.5 对应自由电子气），见 §5。

### 3.7 方法选择的理由与代价（讲义明说 or 可核对的取舍）

| 选择 | 理由 | 代价 / 限制 | 页码 |
|---|---|---|---|
| DOS 用 `ISMEAR=-5`（四面体法） | "可以得到更为准确得 dos 图" | NKPT<4 直接报错；结构优化阶段不能用（力有误差）；此时不读 SIGMA | L2 P36、P46、P47 |

| DOS 用 `ICHARG=1` 或 `11` | 收敛到同一电子态结果相同 | 11 需已有收敛 CHGCAR | L2 P45 |
| `NEDOS` 从 301 提到 1000 | 提高分辨率 | 太大了 DOSCAR/vasprun.xml 过大，不利于下载与保存 | L2 P33 |
| DOS 加密 k 点 | k 点多则曲线更平滑、质量更高 | 计算量上升 | L2 P46 |
| 用 PDOS 分析成键 | 能分解到元素/原子/轨道 | PDOS 和 < 总 DOS，**不能**用它积分谈占据数 | L2 P24、P48、P49 |
| 用 LORBIT 的 total charge 谈电荷 | 方便 | "不能定量…一般无视就行了"；要定量需 Bader/DDEC/NPA/Löwdin/Mulliken | L2 P50 |

| STM 的 EINT | 控制显示费米能级上下多少 eV 的态 | "和实验上所施加的偏压绝对数值并不直接对应，需要自己测试对比图像" | L2 P126 |
| 功函数用 `LVHAR` 而非 `LVTOT` | LVHAR 给纯静电势；LVTOT 给含交换相关势的总势 | 用错会得到不是静电势的曲线 | L2 P135 |
| O/Au(111) 用 `ISPIN=1` | "这个体系我已经测试过没有磁性，无单电子，所以为了节省时间" | 需先验证；不确定时必须用 2 | L2 P141 |
| ELF 用 `PREC=Accurate/High` 且去掉 NPAR/NCORE | ELF 对格点精度要求很高 | 计算量与内存上升 | L2 P150 |
| 金属表面不做 H 钝化 | "只有共价键半导体需要饱和，Ni 是金属键结合的"（答疑 D2-P26） | 半导体/共价体系必须饱和 | D2-P26 |
| 催化体系不做能带 | "催化体系计算不需要研究能带" | 需能带/带边时才做 | L2 P19 |

### 3.9 【不一致单列】讲义说的 vs 算例实际写的

> 本节只列**不一致**项；一致项见 §3.8。全部为可复核的硬事实。

**A1｜NEDOS：讲义建议 1000，`Ag` 算例用的是默认 301**
- 讲义（L2 P33）："建议取 NEDOS=1000 就可以了"；L2 P36 的 DOS 模板也写 `NEDOS = 1000`。
- 算例：`Ag/INCAR` **没有 NEDOS 这一行**；`Ag/OUTCAR` 实测 `number of dos NEDOS = 301`；`Ag/DOSCAR` 头第 6 行第 3 个数为 `301`；`Ag/PDOS_Ag_UP.dat` 恰为 302 行（301 个点 + 1 行表头）。
- 判断：`Ag` 这个算例是"DOS 步"，但没按 P33/P36 提高 NEDOS。不影响定性结论，但说明"建议值"在实操中被跳过。

**A2｜ISMEAR：讲义说 DOS 首选 −5，6 个算例里只有 1 个用了 −5**
- 讲义（L2 P36、P46）：DOS 用 `ISMEAR = -5`。
- 算例：`al2o3` = −5（NKPTS=115）；`Ag`/`au111-opt`/`ni-co` = **1**（SIGMA=0.2）；`c`/`mos2ws2` = **0**（SIGMA=0.05）。
- 判断：`c`/`mos2ws2` 的 NKPTS 都是 3，用 0 是正确的（符合 P46 的例外）；但 `Ag`（NKPTS=13）、`au111-opt`（13）、`ni-co`（5）本可用 −5，却都用了 1。推论：这些 INCAR 是"优化步的 INCAR 直接复用"，只补了 `LORBIT`/`NEDOS`。

**A3｜Ni(100)-CO 的 DOS 步：讲义说要 `NSW=0`，算例是 `NSW=300` 且确实跑了 8 个离子步**
- 讲义（L2 P62）："第四步：计算 Ni(100)-CO 态密度；INCAR 参数修改 LORBIT = 11；NEDOS = 2000；**NSW = 0**；（ISMEAR = -5；并增大 K 点）"
- 另见 L2 P35："结构优化得到的 DOS 不能直接用，因为是平均了结构优化过程中的所有结构的 DOS"。
- 算例：`ni-co/INCAR` 为 `NSW = 300`、`ISMEAR = 1`、KPOINTS 3×3×1；`ni-co/OUTCAR` 中 `E-fermi` 共出现 **8 次**（line 3840/7945/11748/14876/18106/21234/23664/25898，最后一次 1.8135 与 `DOSCAR` 头一致），即该目录的 DOSCAR 出自一次**含离子弛豫**的计算。
- 官方 DOSCAR 文档明确："Mind: For relaxations, the DOSCAR is usually useless… Mind that for NSW>1 the final DOS is averaged of all ionic steps."（[VASP Wiki DOSCAR](https://vasp.at/wiki/index.php/DOSCAR)）
- 判断：**该目录里的 DOS 数据没有按讲义 P62 的 `NSW=0` 单点得到**，属于讲义自己点名要避免的做法。（该目录也许只是把优化步的完整输出归档，DOS 步的输出在别处；工作区内未提供该步的独立目录，见 §5。）

**A4｜O/Au(111) 的 INCAR：讲义说"和优化 Au 表面一样"，算例多出偶极矫正**
- 讲义 L2 P141："步骤二：准备 INCAR 文件（**和优化 Au 表面一样**）。准备 POTCAR，KPOINTS 文件。"
- 讲义 L2 P136 给的 Au(111) 清洁 slab 模板里**没有** `LDIPOL` / `IDIPOL` 行。
- 算例：`au111-opt/INCAR`（即 O/Au(111)）**有** `LDIPOL = .TRUE.` 与 `IDIPOL = 3`。
- 而讲义 L2 P142 正是用"上下表面不对称，在真空层中有明显偶极矫正"来解释结果。
- 判断：讲义"和优化 Au 表面一样"的说法与它自己的解释（P142）以及算例实际写法不一致。算例的做法物理上更正确（不对称 slab 需要偶极矫正），讲义此处表述不严谨。

**A5｜`al2o3` 的 ISIF=3 与 NSW=0 并存**
- 讲义 L2 P89："做晶胞优化(ISIF = 3)。然后切割表面，进行表面优化(ISIF = 2)"；L2 P36 的 DOS 模板未写 ISIF。
- 算例：`al2o3/INCAR` 既是 `ISIF = 3`（晶胞优化）又是 `NSW = 0`；且 `SYSTEM = Al2O3 Cell opt`。其 `CONTCAR` 与 `POSCAR` 的晶格矢量完全相同 → 晶胞没有动过。
- 判断：`ISIF=3` 在 `NSW=0` 下不产生任何离子步，属**遗留设置**（推论）。不影响 DOS 结果，但会误导读者以为这是晶胞优化。

**A6｜ENCUT 的取值没有判据，且两套值**
- 讲义：`ENCUT = 520`（L2 P61，Ni(100)-CO）；`ENCUT = 400`（L2 P72/P73 与 P136）。
- 算例：`ni-co` = 520 ✓；`Ag`/`al2o3`/`au111-opt`/`c`/`mos2ws2` = 400 ✓。

**A7｜k 点密度：讲义只有定性描述，数值判据在算例的 KPOINTS 头里**

**A13｜讲义 P40 的 `E-fermi` 与算例不完全一致**
- 讲义 L2 P40 的 OUTCAR 回显：`E-fermi : 5.4412  XC(G=0): -11.0891  alpha+bet :-15.2081`

- 判断：`XC(G=0)` 与 `alpha+bet` **完全相同**（这两个量由结构+赝势决定），说明是同一体系、同一赝势；`E-fermi` 在 5.4270 / 5.4353 / 5.4412 之间漂移约 0.014 eV。**同结构不同次计算的费米能级会有小幅漂移**——这正是讲义反复强调"要把 E_F shift 到 0 再比"的实际理由。

**A14｜d 带中心：讲义 −3.7502 vs 算例文件 −3.7771（差异来自积分窗口）**
- 讲义 L2 P91/P92：Ag(111) = **−3.75 eV**（回显 `Total: -3.7502 -3.7502 -3.7502`，窗口 `[-9.39 17.20]`）；L2 P93 用脚本（上限 20 eV）得 `-3.7501883008710406`。
- 算例 `day2/Ag/D_BAND_CENTER`：`Total: -3.7792(UP) -3.7750(DOWN) -3.7771(Average)`，窗口 `[-9.11 10.04]`。
- 我核对：`[-9.11 10.04]` 正是 `[EMIN − E_F, EMAX − E_F]`（`Ag/DOSCAR`：EMAX=11.00348932、EMIN=−8.15061128、E_F=0.96133580）。

- 操作结论：**报 d 带中心必须同时报积分窗口**，否则数值不可复现。

### 4.3 PDF 抽取 / 排版造成的错乱（按化学语义还原，原文排版如此）

**E1｜希腊字母 σ / π 系统性退化成拉丁字母 s / p（本讲义最危险的一类问题）**
- `L2 P30`（行 329）："导致 CO 的 **s** 轨道能量降低，**p\*** 轨道能量上升。这是 **s** 配位和反馈 **p** 键共同作用的结果。" → 语义应为：**σ** 轨道能量降低、**π\*** 轨道能量上升、**σ** 配位与反馈 **π** 键。
- `L2 P67`（行 841–842）："对于 CO 分子，**s** 键的成分是 **s** 和 pz，**p** 键的成分是 px 和 py。" → 前一个 s/p 是 **σ/π**，后一个 s 与 px/py/pz 才是真轨道。**同一句话里同一个字母两种含义**，直接读会读错。
- `L2 P69`（行 858、862）："CO 的 **5s** 轨道和 Ni 的占据 **D** 轨道…" → 应为 **5σ**；"占据 D 轨道"应为小写 d。
- `L2 P76`（行 988）："在吸附之后 **s 形**的轨道都没有发生明显变化" → 应为 **σ 型**。
