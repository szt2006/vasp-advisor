> `seg_L*.tsv` 是主题分段表。

## 1. 抽取铁律

> **抽取结果逐字保留、只统一换行为 LF、绝不加头注/尾注。**

一旦插入任何行，`L2.txt:第 N 行` 与 `D1-P14` 这类**引用体系就整体失效**。

溯源信息（原始文件名 / 页数 / 段数 / 行数 / sha256）**登记在本文件**，
**不要写进 `L*.txt` / `D*.txt` 本身**。

## 6. 为什么这一层要"逐字保留"

CP2K skill 上真实发生过的连锁错误：

> 录屏笔记是**在 ASR 转写之上又做了一层"语境修正"**。
> 一个 ASR 错字（把"二氧化钛"转成"二氧化碳"）被笔记作者用
> "课程里确实有另一个体系"去圆，最终把一个 **TiO₂** 的案例
> 系统性写成了 **CeO₂**，并连锁污染了另外 3 处。
> 而且**两个方向都会错**：实测有 3 例是"作者把对的改错"，
> 还有 1 例 **ASR 本来是对的、作者改错了**。

⇒ **引用优先级（本项目照此执行）**：

```
官方原文 > 真实交付文件（输入/输出）> 讲义文本（非语音）> 答疑 > 上层的综合与笔记
```

**"是什么"类的陈述（元素/载体/晶面/分子数……）一律按这个优先级降级使用**，
**不要用"是笔记还是原文"来判对错** —— 两个方向都会错。

冲突时的处理：**在消费层写更正记录并说明理由，不要改原文层。**

## 7. 引用怎么写（会被 `_audit_citations.py` 核对）

| 写法 | 含义 |
|---|---|
| `L1 P28` | `L1.txt` 里的第 28 页（共 82 页） |
| `L1 P28-30` | 第 28 到 30 页 |
| `D2-P14` | `D2.txt` 里的第 14 段（共 82 段） |
| `references/raw/learn_L3.md` | 精读报告 |
| `scripts/validate.py:120` | 文件 + 行号（行号必须 ≤ 实际行数） |

**举例说明"坏写法"时，页号写成 `L1 P##` 占位形式** ——
审计的正则只认 `L` 后跟数字，`##` 会被天然跳过，不会误报。

## 8. 复现这批抽取

```bash
# 讲义（需要 pypdf）
python references/raw/extract_lectures.py --src "<000课件 目录>" --list
python references/raw/extract_lectures.py --src "<000课件 目录>"

# 答疑（需要 python-docx）
python references/raw/extract_qa.py --src "<答疑 docx 所在目录>"

# 验证抽取没破坏行号体系：行数应与上表一致
```

⚠️ 这两个脚本**不属于面向用户的零依赖工具链** ——
它们只在"新增/更新资料"时手工跑一次，允许用第三方库。
缺依赖时会给友好提示 + `exit 3`，**不抛 traceback**。

**源文件不在仓库里**（讲义有版权声明、算例目录含 `POTCAR` 与大文件）。
`things to study/` 已在 `.gitignore` 里。
