### 3.1 计算氢电极（CHE）模型与自由能台阶图框架

**K1** `L4 P3` 电催化计算的思路和热催化类似，文献中最常见的是**台阶图**方法：不用考虑过渡态，只需要计算中间体的能量即可，只需要多考虑 `eU` 的贡献即可。

**K2** `L4 P3` 讲义明确申明这是**基于 Nørskov 的经典电催化计算方法**，其前提是「忽略静电势和溶剂化作用」；并说明「实际电极反应是个极复杂的过程，精确考虑静电势、溶剂化作用、双电层结构、传质速率等是前沿课题」。→ 这条是后面 P32–P54 全部内容的伏笔，也是判断「什么时候必须加更高级处理」的出发点。

**K3** `L4 P5`、`L4 P6` 评价电催化材料最直接的指标是过电势：**η = 实际电极电势 U − 理论平衡电势 U_eq**（原文写作「过电势降（η）」，公式行：「过电势降（η）= 实际电极电势(U) - 理论平衡电势(Ueq)」）。示例：OER 理想只需 1.23 V(SHE)、实际需 1.53 V(SHE)，则 η = 0.3 V。

**K4** `L4 P6` OER 的「实际电极电势」取法：**U = 能量上升最高的一步的能量 / e**。（ORR 对应 `L4 P14`：**U = 能量下降最小的一步的能量 / e**。）

**K5** `L4 P8` OER 四步的 ΔG 显式表达式（原文排版把下标与 `*` 打散成 `G ∗ OH`、`G H2 /2`、`G ∗` 这种形式，此处已按化学语义还原为 G(*OH)、G(H2)、G(*)）：
```
ΔG1 = G(*OH) + ½G(H2) + eU − G(*) − G(H2O)
ΔG2 = G(*O)  + ½G(H2) + eU − G(*OH)
ΔG3 = G(*OOH)+ ½G(H2) + eU − G(*O) − G(H2O)
ΔG4 = G(O2) + G(*) + ½G(H2) + eU − G(*OOH)
```
其中 `e = -1`，`U` 是外加的电极电势(SHE)；`U = 1.23 V` 时 `eU = −1.23 eV`。

**K6** `L4 P10` OER 总自由能变化 **4.92 eV**，共 4 步还原反应、每步 1 个 e；理想情况下每一步变化 4.92/4 = **1.23 eV**。P10 的图给出 U=0 与 U=1.23 V 两条台阶，总落差 4.92 eV。

**K7** `L4 P11` **决速步判据**：`G_OER = Max(ΔG1, ΔG2, ΔG3, ΔG4)`。举例：若第三步吸热 2.04 eV、第四步 0.42 eV（1.23+1.23+2.04+0.42 = 4.92，与总变化自洽），只加 1.23 V 后第三步仍吸热 2.04 − 1.23 = **0.81 eV**，「这个时候需要额外加 0.81 V，这 0.81 V 就是过电势」。

**K8** `L4 P14` ORR 过程和 OER 正好相反。ORR 是原电池反应，所能提供的理论最高电极电势是 1.23 V；示例中当 U = 0.785 V 时所有电化学基元步骤都放热，所以 η = 1.23 − 0.785 = **0.445 V**。

**K9** `L4 P13`、`L4 P26` 一个真实 OER 台阶图的数值（五个态依次为 `* + 2H2O` → `*OH + H+ + H2O` → `*O + 2H+ + H2O` → `*OOH + 3H+` → `O2 + 4H+`）：U = 0 V 下累积 **0.976 / 2.692 / 3.993 / 4.920 eV**；U = 1.23 V 下累积 **−0.254 / 0.232 / 0.303 / 0.000 eV**。→ 这组数字在 `oer.xlsx` 里可逐位复核（见 3.9）。

### 3.2 ΔG = ΔE + ΔZPE − TΔS：各项怎么算、从哪来

**K10** `L4 P9` CHE 的两个参考态约定：
- 「在 pH = 0, U = 0 V (SHE) 条件下，G(H2)/2 = G(H+) + G(e−)」——即把 (H+ + e−) 整体替换成 ½G(H2)。
- 「G(H2O) 是液态水分子的能量，等于饱和蒸气压下的水蒸汽能量（常温下 ~0.035 bar）」。→ **液态水不直接用液态 DFT 能量，而是用对应饱和蒸气压下的气相水分子能量**。

**K11** `L4 P9` 具体计算工具与写法（原文照抄）：用 `vaspkit-502-298.15-0.035-1` 计算。→ **推论：**这套写法把温度 298.15 K、压力 0.035 bar 直接写在命令里，说明 ZPE/熵校正是由 vaspkit 按「温度 + 压力」两个状态变量算出来的，而不是手算。

**K12** `L4 P9` 讲义给出的三条参考数据表（原文照抄，表头为 `Pressure /bar | Temperature /K | E(DFT) /eV | DG /eV | G /eV`）：

| 物种 | Pressure/bar | Temperature/K | E(DFT)/eV | DG/eV | G/eV |
|---|---|---|---|---|---|
| O2(g) | 1 | 298.15 | （未给） | （未给） | **−9.91** |
| H2(g) | 1 | 298.15 | −6.76 | −0.045 | **−6.80** |
| H2O(l) | 0.035 | 298.15 | −14.22 | −0.001 | **−14.22** |

→ 读法：`G = E(DFT) + DG`（该列即 **ΔZPE − TΔS 热力学校正**）。O2 的 E(DFT) 与 DG 两格为空，只有一个 G，正是因为它不能直接算（见 K13）。O2 行那个孤立的 −9.91 属哪一列见 §4-C9。

**K13** `L4 P9` **O2 的能量不能直接算**：「G(O2) 不能直接算，需要用 2G(H2O) − 2G(H2) − G(O2) = −4.92 eV，先计算出 G(H2O) 和 G(H2)，再算出 G(O2)，以保证总包的反应能量。（同理 CO，N2 也需要能量反推）」。
→ 我按上式复核（用于一致性检查，不是新结论）：2×(−14.22) − 2×(−6.80) − (−9.92) = −4.92 ✓ 自洽。

**K14** `D4-P19`、`D4-P20` 学员追问「O2 通过 vaspkit 热力学校正之后吉布斯自由能和文献值吻合得很好了，还是不能用计算出来的吉布斯自由能吗？」讲师答：「**ΔG 校正值吻合的很好。但是 O2 的 DFT 计算出来的电子能量不准确，所以才要用热力学数据减。**」→ **错的不是热力学校正项，而是 DFT 电子能本身**。

**K15** `L4 P17` pH 进入 ΔG 的完整推导（原文把 ½ 与 `[H+]` 打散成多行，按语义还原）：
```
ΔG = 2G(H2O) − 4G(H+) + 4G(e−) + G(O2)
   = 2G(H2O) − 4×(½G(H2) − kT·ln[H+]) + G(O2)
   = 2G(H2O) − 4×(½G(H2) − 0.0592·pH) + G(O2)
```
「当 pH=0，ΔG = −4.92 eV，当 pH=14 时，ΔG = −1.605 eV」；「0.0592 来源于 ΔG = ΔG° − kT·ln(1/[H+]) = ΔG° − 0.0592 pH」。
→ 我的自洽性复核：−4.92 + 4 × 0.0592 × 14 = **−1.6048 ≈ −1.605** ✓。

**K16** `L4 P15` 「一般文章都直接取 1.23V 作为平衡电极电势。」碱性条件下算 H+ 的能量时：由 `H2 ↔ 2H+ + 2e−` 得 `E(H+) = ½E(H2) − 0.0592 pH`。

**K17** `L4 P16` 酸性(pH = 0)标准电极电势 1.23 V（该页表格写 **+1.229 V**）、碱性(pH = 14)为 **0.401 V**；「实际上，这两个反应从热力学角度看是等价的，H+ + OH− ⇌ H2O，可以直接把 OH− 换成 H+ 计算。酸性和碱性条件下计算方式是一样的。」该页并给出酸碱两套四步基元反应与 E° 表（碱性用 OH−、酸性用 H+）。

**K18** `D4-P25`、`D4-P26` 学员问「在酸性或者碱性条件下的建模是有区别吗？」讲师答：「**如果只考虑热力学，没有区别，但是反应过程参与的物种可能不同。H3O+，H2O**」。

### 3.4 U 与 pH 怎么进公式（汇总）

**K27** `L4 P8` 电势以 `eU` 的形式**逐项加在每个电化学基元步骤**上；`e = −1`、`U` 是 vs SHE 的电极电势；`U = 1.23 V → eU = −1.23 eV`。
**推论：**4 步各含一个 `eU`，所以把 U 从 0 抬到 1.23 V 会使第 n 步的累积自由能整体下移 n×1.23 eV——这正是 `oer.xlsx` 里 U=0 V 与 U=1.23 V 两列的换算关系（见 3.9 的 K41）。

**K28** `L4 P15`、`L4 P16`、`L4 P17`、`L4 P9` pH 只通过 **H+/OH− 的化学势**进入：CHE 下 `G(H+) + G(e−) = ½G(H2) − 0.0592·pH`（`L4 P15`、`L4 P17`）；pH=0 与 pH=14 的平衡电势差 0.8288 V（讲义写 1.23 V vs 0.401 V）。`L4 P16` 强调酸碱可互换（把 OH− 换成 H+）后「计算方式是一样的」。

### 3.5 Solvation 校正（VASPsol）

**K29** `L4 P32` 传统 Nørskov 04/05 方法的**两条缺陷**（也是「什么时候必须加溶剂化」的判据来源）：①吸附分子和溶剂作用和在真空中的行为不同；②任何两个不同物相接触都会在两相间产生电势（电荷分离→双电层），界面处的静电势 φ 差受电极电势影响。

**K30** `L4 P39` 显式溶剂模型：直接让溶剂分子出现在体系里、和 slab 等价处理；**计算量大幅增加，而且往往需要考虑很多的构象平均（结合 AIMD 取点），处理起来比较麻烦**。

**K31** `L4 P41`、`L4 P42` 显式溶剂 + 恒电势路线的做法：标准氢电极 SHE 相对真空的绝对电位取 **4.44 V**；「通过模拟固液体系的功函（真空能级和固液体系的差值），可以得到当前体系算出的能量相当于在什么 constant potential 发生的」；流程是「①建模、优化结构、AIMD 预平衡；②跑 20 ps 的 AIMD，每 1 ps 取出一个结构计算单点，拿到功函，把 20 个功函做平均，即得到当前组分的平均功函」。示例换算：2.40 V(vs Vacuum) ↔ −2.04 V(vs SHE)；3.81 V ↔ −0.63 V。
→ 我的换算核对：2.40 − 4.44 = −2.04 ✓；3.81 − 4.44 = −0.63 ✓（说明 4.44 V 这个零点就是他们用的约定；与配套 PDF 的 4.6 V 不同，见 §4-C5）。

**K32** `L4 P44` 这条路线的**三个已知问题**：「①AIMD模拟水/空气界面不能保持。②静电势依靠添加离子改变，不能连续调节。③反应前后的静电势(电极电势)不等。」对策：「通过扩包逼近 constant potential 状态」。

**K33** `L4 P46` 隐式溶剂模型：不直接计算溶剂分子的实际结构，而是把溶剂分子当成具有一定介电常数 ε 的连续介质；处理方便、计算量小，量子化学领域已广泛应用；**缺点是无法描述氢键等强相互作用对反应机理的影响**。

**K34** `L4 P49` VASPsol 的来历与编译（基于 **VASP 5.4.4**）：由 Cornell University 的 Hennig 和 Arias 两个课题组共同开发，通过修改 VASP 代码实现 **linearPCM (GLSSA13)** 溶剂化模型；编译两步：①「在 makefile 里的 `CPP_OPTIONS` 选项中加入 `-Dsol_compat`」，②「把 github 中的 `VASPsol/src/solvation.F` 文件复制到 `./src` 中」。官方站点 http://vaspsol.mse.cornell.edu/ 。

**K35** `L4 P54` VASPsol 的用法与参数（原文照抄）：
- 「相比于真空中计算，VASPsol 计算需要打开：`LSOL = T`，默认水溶液。把离子步关掉 `NSW = 0`。」
- 四个控制溶剂种类的参数：
```
EB_K    = 78.400000   relative permittivity of the bulk solvent
SIGMA_K =  0.600000   width of the dielectric cavity
NC_K    =  0.002500   cutoff charge density
TAU     =  0.000525   cavity surface tension
```
- 「其中 EB_K 为介电常数，查表可知其他溶剂的介电常数。其他参数不能直接查表得到，需要拟合，但是 VASPsol 程序并没公开其他溶剂的参数，所以目前只能改变介电常数近似代表其他溶剂。」
- 打印 bound charge（「由于电子转移和溶剂极化产生的溶剂电荷密度」）用 `LRHOB = .TRUE.`。

**K36** 【配套 PDF 交叉核对】`VASPsol原理.pdf`（6 页）实际是 **Mathew & Hennig, arXiv:1601.03346v1（2016-01-13）**「Implicit self-consistent description of electrolyte in plane-wave density-functional theory」。文中公式可与讲义 P54 的四个参数一一对上：
- 形状函数 `S(n) = ½ erfc{ log(n/n_c) / (σ√2) }` → `NC_K = n_c`、`SIGMA_K = σ`
- `ε(n) = 1 + (ε_b − 1)·S(n)` → `EB_K = ε_b`
- 空腔能 `A_cav = τ ∫|∇S| d³r` → `TAU = τ`
- PDF 明确给出算例参数：ε_b = **78.4**（与讲义 EB_K 完全一致）、1 M 电解质德拜长度 3 Å、由 PZC 拟合得 `V_SHE = 4.6 V`（对比文献值 4.7 V）、Pt(111) 在 1 M 下的双电层电容 **15 µF/cm²**（文献计算 14、实验 20 µF/cm²）；基准算例用 `ENCUT = 800 eV`、`8×8×1` k 点、PBE + PAW。

**K37** 【**讲师真实做法：VASPsol 与非 VASPsol 的 INCAR 逐条差异**】我把两组算例的普通 `INCAR` 与 `vaspsol/INCAR` 做了逐行 diff，**全部差异只有下面这些**：

**K38** 【算例】溶剂化对能量的影响量级（实测）：H2O 分子单点 ΔE = **−0.3128 eV（−7.21 kcal/mol）**（K26）。GaN 只有 VASPsol 一组的 `E0 = −94.277375 eV`，该目录**没有非溶剂化的 OSZICAR**，因此 GaN 的 ΔE 算不出来，标 `[来源待核对]`。

**K39** `L4 P3`、`L4 P24`、`D4-P45`、`D4-P46` **什么时候必须加溶剂化/更高级处理**（讲义给出的判断依据，均为定性）：
- 需要**能垒**时：`L4 P24`「用 Norskov 04年的方法不能计算反应的能垒，一些电催化过程反应能垒很重要，这时候可能需要引入一些溶剂分子。」
- 需要**静电势/双电层/电极电势的连续调节**时：`L4 P32` 的两条缺陷 + `L4 P44` 的三个问题。
- 碱性下的 **Volmer（H2O 解离）**步骤：`L4 P21`「如果多一步考虑，要计算 Volmer（即 H2O 的解离）过程的过渡态，这多在碱性条件下需要考虑。」
- 相对地，**纯热力学台阶图 + CHE 是不需要溶剂化的**（`L4 P3` 自己就声明了这一点）。

### 3.8 常见坑与讲师处方

**K54** `L4 P9` + `D4-P19/P20` **坑 1：直接拿 DFT 算的 O2 能量去用。** 处方：用 `2G(H2O) − 2G(H2) − G(O2) = −4.92 eV` 反推 G(O2)；理由是「O2 的 DFT 计算出来的电子能量不准确，所以才要用热力学数据减」。同理 CO、N2 也要反推。→ 这是全会最有操作价值的一条：**O2 的 DFT 电子能不准确，但它由 4.92 eV 实验总反应自由能锚定，所以自由能图的闭合性优先于 O2 单点能量。**

**K55** `L4 P9` **坑 2：把液态水当气相水算。** 处方：G(H2O) 取「饱和蒸气压下的水蒸汽能量（常温下 ~0.035 bar）」，并用 `vaspkit-502-298.15-0.035-1` 显式带入温度与压力。

**K56** `L4 P24` **坑 3：以为台阶图能给出能垒。** 处方：Nørskov 04 方法不能算反应能垒；一些电催化过程能垒很重要，「这时候可能需要引入一些溶剂分子」。→ 与 K39 呼应。

**K57** `L4 P21` **坑 4：碱性条件下漏掉 Volmer 步骤的过渡态。** 处方：碱性条件下多需要考虑 Volmer（H2O 解离）的过渡态，也可以同时考虑第二步 Tafel 或 Heyrovsky 的过渡态；「通过对比两个步骤哪个是决速步，来对比设计催化剂」。

**K58** `D4-P45`、`D4-P46` **坑 5：把 `O2 + * → *O2` 当成一步电化学基元步骤。** 学员问这一步的 ΔG 怎么求，讲师答：「**O2 + * → *O2 这一步不是电化学基元步骤，不涉及 H+ + e 产生的过程，可以加到台阶图里，但是这一步不会随着 U 的变化而变化。**」→ 判据是一句话：**这一步里有没有 H+ + e− 参与；没有就说明它不含 `eU` 项、不随 U 平移。**

**K59** `D4-P15`、`D4-P16` **坑 6：把 N2/H2 的解离当成电化学基元步骤。** 讲师答：「NRR 一般都是 NNH 的机理。**N2 解离或者 H2 解离这种步骤不是电化学基元步骤，在电化学计算里没有 eU 这一项，不会受电势 U 的影响改变台阶的能量。**」→ 与 K58 同一判据。
