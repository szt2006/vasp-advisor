### 3.1 工作流、文件与语法细节

**计算流程（L1 P13）**：输入 = `INCAR` / `POSCAR` / `KPOINTS` / `POTCAR` / 提交脚本（续算再读 `CHGCAR`、`WAVECAR`）；输出 = `CHG`、`CHGCAR`、`CONTCAR`、`DOSCAR`、`EIGENVAL`、`IBZKPT`、`OSZICAR`、`OUTCAR`、`REPORT`、`vasprun.xml`、`WAVECAR`、`XDATCAR`。后处理工具：VASPKIT、P4VASP、Origin、VMD。

**POSCAR 逐行语义（L1 P14）**：标题 → 扩展系数 → 3 个晶格矢量 → 元素行 → 原子个数 → `Cartesian`/`Direct` → 坐标。讲义给的示例是「CO 分子在 8×8×8 的盒子中」，逐行内容见 §4 条目 C29（该页标题与注释有笔误）。VESTA、VASPKIT(105) 可做 CIF↔POSCAR 互转。
- **同一元素可被定义多次，以对应不同赝势（L1 P14）**。真实算例印证：`day1/GaN/POSCAR` 的元素行为 `N  Ga  H`、计数 `6  6  1`，把赝氢 H 单列为第三种类，正是为了给它配赝氢赝势。

**选择性固定原子（L1 P16）**：
1. 在 POSCAR **第 7 行与第 8 行之间**插入一行 `Selective Dynamics`；
2. 讲义强调「VASP 只认第一个字母，也就是 S 是必须的」；
3. 之后每行坐标尾部要加 **3 个** T/F，分别对应 x、y、z。

交叉核对（`day1/GaN/POSCAR_FIX` 实测）：文件第 7 行 = `6 6 1`（计数），第 8 行 = `Selective Dynamics`，第 9 行 = `Cartesian` —— **插入位置与讲义完全一致**；坐标模式写的是 `Cartesian`（首字母 C）。共 5 个原子标 `F F F`（序号 1、4、7、10、13），其余 8 个标 `T T T`。

**收敛判据与能量提取（L1 P30）**：
- `grep reached OUTCAR` 检查收敛。实测 `day1/fe2o3/OUTCAR` 同时含两种命中串：`------------------------ aborting loop because EDIFF is reached ------------------------`（每个离子步的 SCF 收敛，共 9 次）与 `reached required accuracy - stopping structural energy minimisation`（离子步收敛，1 次）—— 与讲义给的字符串**逐字一致**。
- `tail -1 OSZICAR` 或 `grep E0 OSZICAR` 取最后一个 E0。实测 `fe2o3/OSZICAR` 末行 `9 F= -.67088977E+02 E0= -.67088977E+02  d E =-.673634E-04  mag=    -0.0000` ✓。
- 讲义演示的 O2 例子：5 个 SCF 步收敛，`E(O2) = -9.86 eV`，总磁矩（自旋向上与向下电子数之差）= `2.0`。**推论**：该例用默认 `MAGMOM = NIONS*1.0 = 2*1.0`（见 L1 P45），算出的 mag = 2.0000 恰与 O2 三重态一致，说明「默认初猜也够用」是这页的隐含教学点。

**KPOINTS 文件写法（L1 P20）**：vaspkit 交互为 `1` → `102`（产生自洽计算所用 KPOINTS）→ `2`（Gamma 中心的 MP 方法）→ `0.04`（倒格子中 k 点间距，单位 2π·Å⁻¹），顺带还能生成 POTCAR 与 INCAR。

**VASP 行为细节（本次实测，讲义未提）**：OUTCAR 回显 KPOINTS 注释行时会**截断到 40 字符**。`day1/fe2o3/OUTCAR:257` 显示 `KPOINTS: KPT-Resolved Value to Generate K-Mesh: 0`，而 KPOINTS 第 1 行原文是 `KPT-Resolved Value to Generate K-Mesh: 0.040`（整行 46 字符）——`.040` 被截掉了。

### 3.2 K 点：讲义的规则 vs 算例的实际取值

**讲义给的规则**
- L1 P20：k 间距一般用 `0.04`，精确计算用 `0.03` 或 `0.02`。
- L1 P21：按「每个晶格矢量的长度 × 该方向上的 k 点数」= ka 取值，建议
  - d 区金属 ka ≈ 30 Å；普通金属 ≈ 25 Å；半导体 ≈ 20 Å；绝缘体 ≈ 15 Å。
  - 例题：绝缘体，a、b 为 5 Å、c 为 15 Å → 取 `3 3 1`。**并明确要求测试收敛性**。
- L1 P22：正交晶系下用 POSCAR 三个基矢取模再取倒数，三个倒数的比值即三方向 k 点密度比。例：`1/11.238 : 1/11.238 : 1/15.845 ≈ 1.4 : 1.4 : 1`，于是 `3 3 2`、`4 4 3`、`6 6 4`、`7 7 5` 都可以。
  - **复算**：1/11.238 = 0.08898，1/15.845 = 0.06311，比值 1.410 : 1.410 : 1 ✓ 讲义的算术无误。
- L1 P21 对上述建议的「松绑」：不必严格遵守——文献里 Science/Nature 上仍有很粗的标准；原因一是算力不够，二是催化计算关心**相对能量**，只要保持精度一致，误差往往抵消，「定性勉强能用」。

**4 个真实算例的实际写法（`day1/*/KPOINTS`，5 行格式完全相同）**

| 行 | 内容 | 说明 |
|---|---|---|
| 1 | `KPT-Resolved Value to Generate K-Mesh: 0.040` | 注释行，记录 vaspkit 的 R 值；**4/4 都是 0.040** |
| 2 | `0` | 自动生成网格 |
| 3 | `Gamma` | Gamma 中心 |
| 4 | 网格 | 见下表 |
| 5 | `0.0  0.0  0.0` | 平移 |

| 算例 | 体系 | 网格 | 对应 OUTCAR 的 NKPTS |
|---|---|---|---|
| fe2o3 | 体相 Fe2O3（Fe4O6，10 原子，刚玉型） | `6 6 6` | 32 |
| GaN | GaN(0001) slab + 赝氢（13 原子，c=29.73 Å） | `9 9 1` | 无 OUTCAR |
| mos2 | 单层 MoS2（3 原子，c=18.41 Å） | `9 9 1` | 12 |
| vdw-df2 | 同上，vdW-DF2 | `9 9 1` | 12 |

**我做的复算（推论，但有 4 个独立样本支持）**：vaspkit 的 R 值与网格数的关系为
`N_i = max(1, round( 1 / (R · d_i) ))`，其中 d_i 是垂直于第 i 个倒格矢的晶面间距（正交晶系下 d_i = |a_i|）。
- GaN：1/(3.2163×sin120°) = 0.35902 → /0.04 = 8.975 → round = **9** ✓；c 方向 1/29.7324 = 0.03363 → /0.04 = 0.841 → max(1, round) = **1** ✓
- mos2：1/(3.166×sin120°) = 0.36475 → /0.04 = 9.119 → **9** ✓；c 方向 1/18.41 = 0.05432 → /0.04 = 1.358 → **1** ✓
- fe2o3：（菱方胞）|b_i|/2π = a²sinα/V = 0.23610 → /0.04 = 5.902 → **6** ✓
- 若改用 ceil 取整，mos2 会得 10、c 方向会得 2，均与实际不符 → 只能是四舍五入。

**由此得到的关键换算（推论）**：对正交/近正交体系，`ka = |a_i|·N_i = 1/R`。于是
`R = 0.04 ↔ ka = 25 Å`（正对 L1 P21 的「普通金属 ~25 Å」）；`R = 0.03 ↔ 33.3 Å`；`R = 0.02 ↔ 50 Å`。
**推论**：讲师的实际做法是**对所有体系统一写 R = 0.040**（4/4 算例），即 ka = 25 Å，这一密度满足或超过 L1 P21 表中「半导体 20 Å / 绝缘体 15 Å」的下限，但**低于**「d 区金属 30 Å」的要求（若要满足 d 区金属应用 R = 0.03）。

### 3.3 ENCUT 与赝势：讲义规则 + 实测 ENMAX

**讲义规则（L1 P28）**：`ENCUT = POTCAR 中 ENMAX 值(400)`；**晶胞优化/弹性 > 1.3 × ENMAX**。

**实测（从 OUTCAR 读，未读 POTCAR）**：

| 算例 | 各元素 POTCAR 的 ENMAX（OUTCAR 实测） | max ENMAX | 实际 ENCUT | 是否满足 >1.3×ENMAX |
|---|---|---|---|---|
| fe2o3 | Fe 267.882 eV；O **400.000 eV** | 400.000 | **520.0 eV** | **恰好 1.30×400 = 520** ✓（且 ISIF=3 晶胞优化） |
| mos2 | S 258.689 eV；Mo 224.584 eV | 258.689 | 500.0 eV | 1.93× > 1.3×（1.3×=336.3）✓ |
| vdw-df2 | 同上 | 258.689 | 500.0 eV | 同上 ✓ |
| GaN | 无 OUTCAR，未核验 | — | **INCAR 未写 ENCUT** | 用默认真（= 最大 ENMAX）[来源待核对] |

> **最硬的一条交叉核对**：`fe2o3` 的 ENCUT = 520.0 eV 与 O 的 ENMAX = 400.000 eV 之比**精确等于 1.3**，且该算例正是 ISIF=3 的晶胞优化 —— L1 P28 的「晶胞优化/弹性 > 1.3*ENMAX」在真实算例上得到定量验证。同时它反过来印证了 L1 P28 括号里的「(400)」指的是 O 的 ENMAX。

**赝势后缀（L1 P25–P27）**
- 后缀表（L1 P25）：`_h`/`_s` = hard/soft；`_pv`/`_sv`/`_d` 含更内层电子；`_2`/`_3` 含不同价电子数；`_GW` 用于 GW；`H1.25`、`H1.5`、`H.5` 为赝氢。
- 详解（L1 P26）：标准赝势**无后缀**，最常用；`_h` 更硬（更精确，需要更高截断能）；`_s` 更软（更粗糙，需要的截断能小）；`_pv` 对 d 区过渡金属包含内层 p 轨道（`V_pv` 含 3p3d4s）；`_sv` 含内层 s 和 p（`V_sv` 含 3s3p3d4s）；`_d` 对主族 4 周期以后元素含内层 d 轨道（`Ga_d` 含 3d4s4p）。
- 选择理由（L1 P27）：手册 10.2.1 节 196 页有建议赝势；vaspkit 默认就生成建议赝势，可通过 `~/.vaspkit` 里 `RECOMMENDED_POTCAR .FALSE.` 关闭、改为生成无后缀赝势。手册建议算第一、二周期双原子化合物（H2、N2、CO、O2）时默认赝势可能不太精确，`_h` 与实验更符；**但一般仍用默认赝势，理由是 `_h` 需要太高的 ENCUT（700 eV）、计算量太大，且整个计算需要保持赝势的统一性**。
  - 交叉核对：`fe2o3` 实测 O 的标准赝势 ENMAX = 400.000 eV，与 P28 的「(400)」一致 ✓。`_h` 的 700 eV 无法从算例核验（本报告不读 POTCAR）[来源待核对]。
  - 补充（D1-P24）：答疑里学员问「0.75H 的 POTCAR 怎么得到」，讲师答「这个赝势是 vasp 赝势库里自带的，有很多。价电子数不同，带有 0.75 个电子」—— 说明赝氢的实际家族比 L1 P25 列举的三种更多。

**PAW 原理（L1 P23）**：用没有节点的赝波函数替代含节点的径向波函数（讲义以 3s 含两个节点为例），因为描述价层可以用较少的傅里叶级数项写出波函数，这才使平面波基组的计算变得实用。VASP 最常用 PAW（投影缀加平面波赝势方法）。

**POTCAR 生成（L1 P24）**：从 VASP 官网下载 `potpaw_PBE.54.tar.gz`；**按 POSCAR 中的次序**依次把用到的 POTCAR 首尾相连生成新 POTCAR；最方便是用 vaspkit 103 功能，「但是一定要清楚 POTCAR 生成原理」。
- 交叉核对：`day1/mos2/LOG` 显示 `POSCAR found type information on POSCAR  S  Mo`、`POSCAR found :  2 types and  3 ions` —— VASP 会从 POSCAR 第 6 行读元素名并要求 POTCAR 顺序与之匹配，这正是「按 POSCAR 次序拼接」的原因。

### 3.6 范德华校正：讲义配方 vs vdw-df2 算例

**DFT-D3（L1 P36）**：DFT-D 方法几乎不增加任何计算量，参数都是提前拟合好的，不同泛函参数不一样；VASP 对几种常见泛函的默认参数已设置好，使用时只需一个参数：`IVDW = 11`（DFT-D3）、`IVDW = 12`（DFT-D3BJ）。PBE(GGA=PE)、RPBE(RE)、revPBE(RP)、PBEsol(PS) 不需要额外指定参数；其他泛函需要额外设定参数。
- 答疑补充（D1-P6）：「两个差不多都可以用。11 是 D3（有时候低估 vdw），12 是 D3BJ（有时候高估 vdw）」—— 这是 L1 没有给出的**选择倾向**。

**vdW-DF（L1 P37）**：在 DFT 能量中加入一个非局域项。
- 对比 DFT-D3 的**优点**：可以体现出弱相互作用对电子结构的影响；对元素不需要经验参数；可以应用于任何元素。
- **缺点**：计算量大，「后来的 rVV10 计算量较小」。
- 使用需 `vdw_kernel.bindat` 文件（讲义给了 VASP wiki 链接）。

### 3.7 泛函与吸附能（L1 P34–P41）

- **LDA**：不写 `GGA =`，POTCAR 用 LDA 的（L1 P34）。
- **GGA**：`GGA = 91 | PE | RE | RP | PS | AM`，分别代表 PW91、PBE、RPBE、revPBE、PBEsol、AM05（L1 P34）。
- **Meta-GGA**：`METAGGA = TPSS | RTPSS | M06L | MBJL | SCAN | MS0 | MS1 | MS2`（L1 P34）。
- **杂化泛函**：`LHFCALC = .TRUE.`；HSE06 用 `LHFCALC=.TRUE. ; HFSCREEN = 0.2 ; AEXX = 0.25 ; ALGO = D ; TIME = 0.4 ; LDIAG = .TRUE. ; ISYM = 3`（L1 P34）。
- HSE 能量公式（L1 P35，PDF 把上下标打散，还原为）：
  `E_xc^HSE = a·E_x^{HF,SR}(ω) + (1−a)·E_x^{PBE,SR}(ω) + E_x^{PBE,LR}(ω) + E_c^{PBE}`
- **泛函对吸附能的影响（L1 P40–P41）**：PBE（PRL 77, 3865, 1996）原始版本往往高估吸附能；revPBE（PRL 80, 890, 1998）对原子/分子在金属表面上的吸附能做了修正；RPBE（PRB 59, 7413, 1999）类似于 revPBE，同时满足 Lieb-Oxford criterion。对比量是 Pd 晶格常数、CO 质心到表面距离、CO 吸附能（实验值 ~ -1.5 eV）。
- L1 P41：对于金属体系 PBE 基本总是高估吸附能，RPBE 有很大改善；对于更一般的体系 RPBE 也不一定绝对适用。Nørskov 等人开发了 **BEEF 泛函**（PhysRevB 85, 235149, 2012）结合 vdW 校正，对催化体系可以给出更好的能量结果，还给出 Bayesian Error。**RPA 作为 benchmark**。

### 3.8 DFT+U 与磁性（L1 P42–P47）

**DFT+U 原理（L1 P42）**
- 对 DFT 能量和波函数起作用的就是 `Ueff = U − J` 这一项。
- **Ueff 值越大 → 带隙越大，固体生成焓越正，过渡态能量越高。**
- 注意：「+U 主要对电子结构、能量改善，**对原子几何、晶体结构的影响很有限**」。
- 答疑补充（D1-P3/P4）：`CeO2` 等镧系「基本必须加，因为 f 轨道非常的收缩，电子相关效应很强」。

**VASP 参数（L1 P43）**：`LDAU` 开启 DFT+U；`LDAUTYPE` 选方法；`LDAUL` 角动量；`LDAUU` U 值；`LDAUJ` J 值；`LDAUPRINT` 输出详细程度；`LMAXMIX`「DFT+U 计算一定要设置」。示例：
```
LDAU = .TRUE.
LDAUTYPE = 2
LDAUL =   2  -1
LDAUU =  5.3 0.0
LDAUJ =  0.0 0.0
LDAUPRINT = 0
LMAXMIX = 4
```
讲义解释：给第一种元素的 d 轨道加 5.3 eV 的有效 U，给第二种元素不加 U；`LMAXMIX` 对 d 轨道混合电荷密度以加速收敛；`LDAUPRINT=0` 避免过大的输出 OUTCAR 文件。

**交叉核对（fe2o3）**：`day1/fe2o3/INCAR` 的 DFT+U 段与 L1 P46 **逐行相同**；`fe2o3/OUTCAR` 实测：
```
LDA+U is selected, type is set to LDAUTYPE =  2
  angular momentum for each species LDAUL =     2   -1
  U (eV)           for each species LDAUU =   5.3  0.0
  J (eV)           for each species LDAUJ =   0.0  0.0
  LMAXMIX     =    4 max onsite mixed and CHGCAR
```
✓ 全部生效。同时 `fe2o3/POSCAR` 第 6 行是 `Fe    O`（Fe 在前），说明 `LDAUL/LDAUU/LDAUJ` 的槽位顺序与 POSCAR 的元素顺序对应（讲义未明写，属**推论**，但被该算例支持）。

**⚠ 模板 INCAR 用的是另一套 U/J 写法（重要）**：`things to study/INCAR` 的 DFT+U 段（注释态）为
```
# LDAUL =   2  -1   -1   -1  -1
# LDAUU =  4.6 0.0  0.0 0.0 0.0
# LDAUJ =  0.4 0.0  0.0 0.0 0.0
# LDAUALPHA = 0.0 0.5
# LDAUPRINT = 2
# LMAXMIX = 4
```
按 L1 P42 的 `Ueff = U − J`，模板的 **Ueff = 4.6 − 0.4 = 4.2 eV**，而讲义 L1 P43/P46 与真实 `fe2o3` 算例的 **Ueff = 5.3 − 0.0 = 5.3 eV** —— **两者相差 1.1 eV**。引用 U 值时**必须同时说明用的是哪一套写法**（是「U 里已含 J」还是「U、J 分开写」）。此外模板用 `LDAUPRINT = 2`，而讲义 L1 P43 与真实算例都是 `0`。详见 §4 条目 C-U。

**磁性（L1 P44）** 讲义的四分类（**原文术语见 C13**）：

| 类别 | 条件 | 例 | 净磁矩 |
|---|---|---|---|
| 铁磁性 | T < Tc | Fe, Co, Ni | 有 |
| 顺磁性 | T > Tc | —— | 无 |
| 亚铁磁性 | —— | Fe3O4, Co3O4 | 有 |
| （原文写「反磁性」） | —— | Fe2O3 | 无 |

**MAGMOM 设置（L1 P45）**
- `ISPIN = 2`；`MAGMOM = [real array]`；默认值 `MAGMOM = NIONS * 1.0`。
- MAGMOM 设置的是**每个原子最初的磁矩初猜**。**只有如下两种情况程序才会使用 MAGMOM 初猜**：(1) 计算没有读取 CHGCAR，也没有从 WAVECAR 里计算初始电荷密度；(2) 读取了非自旋极化的 CHGCAR。
- 设置方式与 POSCAR 里的原子一一对应。例：POSCAR 里 Fe4O6，假设 Fe3+ 高自旋、反铁磁(AFM)排列 → `MAGMOM = 5.0  -5.0  5.0  -5.0  6*0`。
- 手册建议（原文引用）：`If one is searching for a spin polarised (ferro- or antiferromagnetic) solution, it is usually safest to start from larger local magnetic moments` → 初始磁矩可以尽量设大（比如 5.0），程序会自动优化到最合理的磁矩。
- 实操（D1-P8）：先扩包，再在 VESTA 观察原子编号，按照自己想要的磁性排列一点点写 MAGMOM。
- 交叉核对：`day1/fe2o3/POSCAR` 第 1 行 = `Fe4 O6`（4 个 Fe + 6 个 O）✓；`day1/fe2o3/INCAR` 的 `MAGMOM = 5.0 -5.0 5.0 -5.0 6*0.0` 与 L1 P46 逐字一致 ✓。

### 3.9 提速技巧与 NCORE/KPAR 的实际关系（L1 P48）

**讲义十条（原文编号缺 (6)，见 C22）**
1. 测试最优的 `NCORE`(NPAR) 值；懒得测试就直接用 `NCORE = 每个节点的核数/2`。
2. 如果是非 111 k 点计算，测试最优的 `KPAR`。
3. 如果 `PREC` 和 `ADDGRID` 导致计算速度过慢，一般用默认值。
4. 适当降低 K 点的密度，不能太少。
5. 调整计算模型需谨慎：缩小超胞的重复单元 / 缩小表面计算用的 slab 层数 / 使用更简化的模型（比如用甲基替换乙基）。
7. 适当降低 `ENCUT` 到 POTCAR 建议的 ENMAX 值，**不建议取更小的值**。
8. 体系过于复杂、原子数过多（N > 150）的半导体或绝缘体，可以用 111 k 点 + gamma 版本的 VASP，速度会大幅提升；**注：此方法不适用金属**。
9. 让老板买更好的服务器和更多机时。
10. 放弃这个体系计算，另寻它径。

**交叉核对（本次实测，讲义未给出这条定量关系）**
- `fe2o3/LOG`：`running on   64 total cores` / `distrk:  each k-point on   64 cores,    1 groups` / `distr:  one band on NCORES_PER_BAND=  16 cores,    4 groups` → KPAR=1（未设）、NCORE=16、64 = 1×16×4。

### 3.10 编译（L1 P49–P50）——只提炼通用方法

**从 `makefile.include` 提炼的通用编译要点（不含任何站点信息）**
1. 预处理宏在 `CPP_OPTIONS` 中按需打开：`-DMPI`、`-DMPI_BLOCK=…`、`-Duse_collective`、`-DscaLAPACK`、`-DCACHE_SIZE=…`、`-Davoidalloc`、`-Duse_bse_te`、`-Dtbdyn`、`-Duse_shmem`。
2. 编译选项：`FFLAGS = -assume byterecl -w`；`FREE = -free -names lowercase`；调用 `mpiifort`，链接 MKL。
3. **FFT 库有一种互斥的选择**：用 MKL 的 FFTW3 包装库（`libfftw3xf_intel.a`）**或**用 VASP 自带的 `fftw3d.o/fftmpi*.o`，两者在 `OBJECTS` 里靠注释切换，不能同时启用。
4. scaLAPACK / BLACS 与 `-DscaLAPACK` 配对使用。
5. **GPU 编译反而要关掉 scaLAPACK**：`CPP_GPU = -DCUDA_GPU -DRPROMU_CPROJ_OVERLAP -DUSE_PINNED_MEMORY -DCUFFT_MIN=28 -UscaLAPACK`；并需要按 GPU 架构指定 `-gencode=arch=compute_XX`。
6. 需要 C/C++ 编译器（`icc`/`icpc`）来编译 parser 库与部分 CUDA 代码。
7. **优化级别是效率关键**：模板中 `OFLAG = -O2 -xhost`，而讲义 L1 P50 说用 `-O3 -xhost` → 见 C-OPT。
8. **「先跑小算例再上线」这一条是本次提炼的方法学结论**：讲义的做法是「先尝试用 `bin/` 目录里的可执行文件，试试在自己的服务器上是否可以使用」——即**拿到预编译可执行文件后先做小体系试跑验证，再投入正式计算**；跨机器复用可执行文件的前提是编译器套件与 CPU 指令集一致（`-xhost` 意味着按本机指令集优化，换机器可能不通用）。

### 3.11 建模：切面、terminal、赝氢、超胞（L1 P51–P65）

**建模总览（L1 P51）**：一、正确认识表面不同的 terminal；二、悬挂键/饱和赝氢；三、晶格矢量的旋转与根号表面 Wood 标记法；三（原文重复）、异质结建模；四、负载催化剂团簇模型；五、优化模型显示效果。（编号错乱见 C21。）

**练习1：α-Al2O3(0001)（L1 P52–P55）**
- MS 操作：`Build - surface - cleave surface`，用 `0 0 1` 切出来的就是 (0001) 面，厚度 1.0 即可；调整 Top 可得到 O-terminated 或 Al-terminated。
- Al-terminated：上下对称，有不饱和 Al3+ 金属暴露，需添加悬挂基团（**金属氧化物一般都是 O 或 OH 暴露的，除非超高真空条件**）。上下不对称 → 产生表面偶极，计算时需加 `IDIPOL`、`LDIPOL` 参数消除偶极。
- 注意：移动表面 Top 时上/下表面会同时发生变化，slab 有两个表面；**无法在满足化学计量比的前提下满足上下表面都是 O 暴露**；搭建模型时要时刻记得上/下两个表面。讲义给的诊断实例是 `O/Al = 21/12`，不符合化学计量比 `O/Al = 18/12 = 2/3`。
- 悬挂键饱和：用 sketch Atom 工具给原本 Al-terminated 的表面补 OH；由于 OH 是 −1 价，为平衡电荷还需额外引入一个 H 基团，相当于引入了一个解离的 H2O 分子；这样产生的表面最符合常温大气条件下的 α-Al2O3(0001) 实际情况；最后再加真空层扩胞。

**切面四原则（L1 P57）**
1. 尽量保证化学计量比和 bulk 一样（如 Al : O = 2 : 3）。
2. 尽量保证表面能最小，也即让暴露的表面原子和实验一致；**氧化物优先让氧暴露**。
3. 是否添加基团给不饱和原子，要参考别人的文献并根据实验经验：
   - 一般**过渡金属化合物都不需要添加额外的基团**；
   - Al2O3、SiO2 等可以考虑用 −OH 饱和；
   - Si、GaN、InSe、ZnSe 等共价晶体、半导体用**赝 H** 饱和。
4. 尽量保证表面是对称的；不对称表面可加 `IDIPOL` 和 `LDIPOL` 参数消除偶极。
- 补充（D1-P34）：氧化物选 O 为暴露面「基本是这样的，但是也有很多特例，暴露金属表面都有可能」。
- 补充（D1-P56，重要局限）：若下表面用赝氢钝化而上表面不钝化，「赝氢钝化以后这样的**没法算表面能**。只能钝化前算，而且算出来的是上下表面的平均表面能」。
- 文献告诫（L1 P56）：建表面要参考前人的计算和实验文献，弄明白表面最可能怎么截断、可能会有什么吸附分子；推荐 **R. Hoffmann, Angew. Chem. Int. Ed., 2013, 52, 93-103**；并提醒「**好多计算的文章里截取的表面模型都是有问题的，自然界根本不存在的表面做催化计算**」。

**赝氢（L1 P58–P60）**
- 半导体材料（GaN、ZnSe、Si）切面后，上下表面最表层原子都是配位不饱和的，会有一个多余的 sp3 轨道没有成键，导致表面态的产生。
- 由于下表面不是我们要研究的对象，就需要把下表面用赝氢饱和，来还原体相材料的性质。
- **赝氢一般添加在原有化学键的中点位置，计算过程中固定。**

**交叉核对（GaN 算例，本次精读最精确的一处几何验证）**
`day1/GaN/POSCAR` = 6 N + 6 Ga + 1 H，c = 29.7324 Å；`POSCAR_FIX` 是加了 `Selective Dynamics` 并把坐标改为 `Cartesian` 的版本。我用 `POSCAR_FIX` 的笛卡尔坐标复算：
- 同一 (x, y) 柱内相邻 Ga–N 间距 = `8.2266577560 − 6.2524263960 = 1.9742314 Å`（即该 slab 中的 Ga–N 键长）。
- 最底层 N 的 z = `2.9866195800`；被删掉的那个 Ga 应在 `2.9866195800 − 1.9742314 = 1.0123882 Å`。
- 两点**中点** z = `1.9995039 Å`；文件中 H 的实际 z = `2.0000985 Å` —— 与中点仅差 **0.0006 Å**。
- H 到 N 的距离 = `0.9865210 Å` ≈ Ga–N 键长的一半（0.9871157 Å）。
- **结论：赝氢确实被放在「原有化学键的中点」，且沿 c 轴正下方，完全印证 L1 P58/P60 的规则** ✓✓
- H 的坐标行标记为 `F  F  F`（第 13 个原子），即**计算过程中固定** ✓ 与 L1 P58 一致；也与 D1-P46「赝氢不用优化，直接把下面几层固定住就可以了」一致 ✓
- 固定原子共 5 个（序号 1、4、7、10、13）：z 最小的两层 N（2.9866、5.6066）+ 两层 Ga（3.6324、6.2524）+ H。即**固定 4 个原子层（= 2 个 GaN 双层）+ 赝氢**，可弛豫 8 个原子层 ✓ 满足 L1 P15 的「可弛豫的原子等于或多于被固定的层数」。
- **真空层厚度 = 15.0000 Å**：slab 含 H 的 z 跨度为 `16.7325027 − 2.0000985 = 14.7324042 Å`，`c − 跨度 = 29.7324 − 14.7324042 = 14.9999958 Å` ✓ 与 L1 P76 的「把 c 矢量的长度增大 15 埃」互相支持。
- GaN 的元素顺序写成 `N  Ga  H`（N 在前），说明 POSCAR 元素顺序不必按常规习惯，只要与 POTCAR/KPOINTS 一致即可；H 单列一类正是为了配赝氢赝势 ✓ 印证 L1 P14。

**Wood 标记法（L1 P61）**
- `FCC(100)-p(1×1)` 里的 `p` 是 primitive 的意思，如果不写 p 默认是 p。
- 重构的表面结构的单胞矢量方向与未重构的表面单胞矢量方向不一致时（如 c(2×2) 与未重构单胞矢量成 45° 夹角），按 Wood 记法可表示为 `(√2 × √2)R45°`。
- `c` 是 center 的意思，代表表面 cell 的中心有一个单元；`fcc(100)-c(2×2)` 与 `fcc(100)-(√2 × √2)R45°` 两种表示方式是一样的。
- `2` 代表边长，`R` 代表旋转，`45°` 是旋转的角度。（**原文根号丢失，详见 C18**。）
- 答疑补充（D1-P17/P18）：问「wood 标记法中新形成的（重构后的）表面旋转 45° 或者 30° 怎么确定？」答「A 基矢的选择角度」—— **答复很简略，不足以据此操作** [来源待核对]。

**Redefine Lattice（L1 P62）**：可以改变晶胞的形状、方向，对于构建有形状要求、异质结材料非常有用。讲义给的三个矩阵乘法例：
- 单位矩阵 ×(a,b,c) = (a, b, c)
- `(1 1 0; 0 1 0; 0 0 1)` ×(a,b,c) = (a+b, b, c)
- `(2 0 0; 0 1 0; 0 0 1)` ×(a,b,c) = (2a, b, c)

**根号表面 Au(111)-(√3×√3)R30°（L1 P64–P65）**：用 A、B 表示 √3 表面的晶格矢量，a、b 表示 (1×1) 的，则 **A = a − b，B = 2a + b**，矩阵形式 `(1 −1 0; 2 1 0; 0 0 1)·(a,b,c) = (a−b, 2a+b, c)`。

### 3.13 异质结、显示与溶剂界面（L1 P70–P80）

**练习3：g-C3N4/TiO2 界面（Phys. Chem. Chem. Phys., 2016, 18, 31175）（L1 P70–P76）**
1. 导入 TiO2 的 anatase CIF，切 **TiO2(100)** 表面，**厚度 3 层**；在 lattice 里把 U 方向显示 4 个周期，方便调整晶格矢量。
2. `build – symmetry – redefine lattice` 里按文献调整表面晶格矢量。
3. 导入 C3N4 的 CIF（**Materials Project，mp-567885**），按文献显示 **2*4** 的晶胞。
4. 同样用 redefine lattice 按文献调整表面晶格矢量。
5. `Build - Build layers` 建立异质结：Layer 1 用 TiO2(100)，Layer 2 用 C3N4。在 matching 里查看 mismatch：**a 矢量 8.88%，b 矢量 4.21%，角度 4.60%** —— 讲义评价「这个值在异质结的构建里算是很大了，但是由于单层的二维材料可塑性往往很好，所以经过一定的变形 C3N4 可以匹配 TiO2(100) 的晶格常数」。matching 选 layer1（或 Average），build，MS 弹出提示晶格不匹配 yes 即可。
6. 删掉最上面一层 C3N4 建立真空层；`build – crystal – rebuild crystal`，把 **c 矢量的长度增大 15 埃**。注意：用这种方法建出来的 slab 可以考虑对 a、b 晶格矢量做**选择性优化**，即在水平的方向上对晶体进行优化得到更合理的结构。
- 答疑补充（D1-P26）：异质结晶胞不一样时「通过求算最小公倍数，比如 A（a=2 埃）B（a=3 埃），就把 A 扩包 3 倍，B 扩包两倍。如果夹角不一样，先通过 redefine lattice 转基矢。**不是所有的两个材料都能建立异质结的**」。
- 答疑补充（D1-P60）：横向相接（而非纵向堆叠）的异质结「非常麻烦，需要在异质结的基础上再添加一个横向的真空层，这种模型很难算」，参考 Nature Chemistry 11, 222–228 (2019)。

**MS 论文示意图（L1 P77–P79）**：① 在案例 3 基础上加一个 Fe3 团簇模型（用优化好的模型最好），display style 把 Fe 颜色调为橙色，原子半径调为 **0.8**，右键 Display Options 把背景调为白色；② 建超胞 **5 5 1**，`Edit – atom selection` 选中所有 Fe 原子调橙色；③ Display Options 里把 projection 调为 perspective（透视图），Depth cue intensity 调高；④ 右键 Lighting 勾选原子的第二高光；⑤ 调整视角截图。讲义评价：用 MS、VESTA、VMD、Origin、Illustrator 相互配合可以画出质量非常高的图，基本满足文章投稿需求。

**扩展练习：Cu/H2O 界面（L1 P80）**：用 MS 里的 `Modules-Amorphous cell` 计算任务，Construction 给水盒子做预优化；再用 `build layers` 把水盒子和 Cu 表面摞起来。

### 3.14 研究思路与文献锚点（L1 P4–P12）——「为什么这么算」

这一部分是「选什么模型、算什么量」的方法论，与参数无关但决定后续一切。

- **依实验数据搭模型（L1 P4）**：根据实验光谱（配位数、键长）、电镜照片、元素组成等数据，搭建合理的模型；配图来源 `Nat. Catal. 2018, 1, 63`。手段对应 TEM / XANES / EXAFS。
- **该忽略的就忽略（L1 P5）**：「SiO2 对催化没有影响，建模的时候可以忽略。用计算量可以承受的的模型尽量还原出实际的体系。」（原文「的的」重复，**原文排版如此**）配图来源 `Nature 2019, 565, 631-635`。
- **结构设计才是文章的关键（L1 P6）**：讲义原话——「设计合理的催化模型，是后续能量和性质计算的基础，也是科研思路的关键。因为计算方法大家都是用一样的，但是计算的设计的套路就是文章的关键所在了。」对比对象为 Nørskov 等 `Science 2005, 307, 555-558`、Holland 等 `Inorg. Chem. 2012, 51, 7546-7550` 与 `Nat. Commun. 2018, 9, 1610`。**这条解释了为什么整个第一讲有一半篇幅在讲建模。**
- **先定稳定性（L1 P7）**：表面比固体复杂得多，即使同一晶面在不同环境下组成也不同；要做稳定性分析，例如 RuO2(110) 表面在不同 O 分压下的组成（`PRB 2001, 65, 035406`；`ACS Catal. 2018, 8, 1864-1879`）。「只有稳定的体系才有后续研究的价值。」
- **基元步骤与 AIMD（L1 P8）**：吸附？反应？脱附？示例为 H2 在 Fe3 上均裂吸附、势垒 **0.08 eV**（原文写 `is homogeneously dissociated`，用词不严谨，疑为 homolytically）。AIMD 条件：**300 K、20 ps**。讲义理由：「运用从头算分子动力学（AIMD）方法，可以得到更为丰富的动态数据，对体系也会有更客观的描述。」
- **能量是基础，但必须做自由能校正（L1 P9）**：「DFT 算出来的是 0K 下的能量，还要做自由能校正，才能得到真实反应条件下的能量。」
- **把微观能量接到宏观量（L1 P10）**：表面反应热力学/动力学「是联系宏观和微观的桥梁」。示例是 NH3 合成的 TOF per site 图，参数为**压力 1–100 bar、温度 300–1000 K、H2:N2 = 3、NH3 转化率 10%**，并划分 4 个区域（Region 1 温度太低难以越过 N2 解离势垒；Region 2 温度太高 ΔG > 0；Region 3 工业区；Region 4 理想区）。
- **电子结构分析（L1 P11）**：「能够熟练的运用电子结构分析化学本质是发表高水平论文的关键技巧。」示例结论：Fe3 低电荷态（**0.59 |e|**）、高自旋极化（**10 μB**，原文作 `10 mB`，μ 在抽取中丢失）；d-p* 相互作用导致电荷从 Fe3 转移到 N2 的 p* 轨道。
- **未来方向（L1 P12）**：大数据 + 机器学习，「以上所有的计算分析都可以由程序自动完成，利用神经网路训练海量数据，对实验进行指导和预测」（`Nature Catalysis 1, 230–232 (2018)`；pymatgen 参考页）。

### 3.15 固定基矢优化：OPTCELL（L1 P32–P33 + 实测验证）

**讲义原理（L1 P32）**
- VASP 的晶胞优化（`ISIF = 3`）是允许在 **9 个自由度**上自由弛豫的。
- **如果想要固定其中几个自由度，需要用重新编译过的 VASP**：修改 `constr_cell_relax.F` 并覆盖 `./src` 的原有文件。（与 L1 P50 的「集成 OPTCELL 的 VASP .5.4.4-all」配套，见 C36。）
- `OPTCELL` 文件里是一个 **3×3 矩阵**，每个矩阵元为 0 或 1，**1 为优化、0 为不优化**，对应于 POSCAR 中的晶胞矢量 3×3 矩阵。讲义给的示例为 `100` / `110` / `000`。

**讲义实例（L1 P33，单层 MoS2）**：在 z 方向上真空层不需要优化，POSCAR 中 a、b、c 晶格矢量中所有为 0 的值也不需要优化，所以 `OPTCELL` 写成三行 `100` / `110` / `000`；同页给出了配套的 POSCAR（`MoS2`；a=(3.1659998894, 0, 0)、b=(−1.5829999447, 2.7418363326, 0)、c=(0, 0, 18.4099998474)；元素行 `S   Mo`；计数 `2    1`；`Direct`；三个分数坐标 0.413899988 / 0.586099982 / 0.500000000）。

**交叉核对（本次精读的强验证之一）**

| 项 | 讲义 L1 P33 | `day1/mos2/` | `day1/vdw-df2/` |
|---|---|---|---|
| `OPTCELL` 内容 | `100` / `110` / `000` | **完全相同**（3 行） | 完全相同 |
| `POSCAR` 文本 | 逐行给出 | **逐行相同** | 逐行相同 |
| 优化后 a（CONTCAR） | —— | 3.1822493 Å（a 变了） | 3.2806599 Å（a 变了） |
| 优化后 c（CONTCAR） | 真空方向「不需要优化」 | **严格保持 18.4099998474（未变）** | **严格保持 18.4099998474（未变）** |

→ **OPTCELL 的 `100/110/000` 确实实现了「面内 a、b 放开、c（真空方向）冻结」** ✓✓

**对比组（反向验证）**：`day1/fe2o3` **没有** OPTCELL 文件且 `ISIF = 3`，其 `CONTCAR` 的三个基矢**全部改变**，并出现非对角分量（a 的 z 分量由 0 → 0.0205958，b 的 z 分量由 0 → 0.0205958）→ 与 L1 P32「ISIF=3 在 9 个自由度上自由弛豫」完全一致 ✓

**一个实用的软件行为细节（讲义未提）**：`OPTCELL` **不会在 OUTCAR 的参数区回显**（在 `mos2`/`vdw-df2` 两个 OUTCAR 里都 grep 不到 OPTCELL）。**因此判断 OPTCELL 是否生效，只能比较 POSCAR 与 CONTCAR 的晶格矢量** —— 上面的表就是这么得到的。

### 3.16 vaspkit 固定原子的两种方法（L1 P17–P19）

**402 功能：按原子层数固定（L1 P17–P18）**
- 操作链：运行 vaspkit → 输入 `402` → `1` 选择 POSCAR → 程序先自动判断层数并列出候选阈值：
  ```
  Threshold:  0.3 layers:   5
  Threshold:  0.6 layers:   5
  Threshold:  0.9 layers:   5
  Threshold:  1.2 layers:   5
  Threshold:  1.5 layers:   5
  Please choose a threshold to separate layers->
  ```
- 例子（含五层 Au 的 Au(111) slab）：选择一个 Threshold（演示里输入 `1.0`），程序报 `Found 5 layers`，再输入要固定的层数 `2`，输出 `-->> (2) Written POSCAR_fix File!`。
- 之后「检查一下生成的 POSCAR_fix 文件，如果没有问题：`cp POSCAR_fix POSCAR`」。
- **限制（讲义明确写出）**：**「此方法只限于法矢量在 z 方向的 slab 模型。」**
- 讲义对 Threshold 的解释：「Threshold 是 vaspkit 的总层数判断标准，在不同的标准下层数会判断的不太一样」。

**403 功能：按 z 坐标固定（L1 P19）**
- 首先要弄清楚需要固定哪些原子、以及这些原子的 z 坐标（例：Au(111) 固定下两层原子）。
- 做法：**找到要固定的原子中 z 坐标最大的那个原子**，读出它的 z 坐标（讲义例子为 **0.13817**），然后固定住所有 z 坐标**小于 0.139** 的原子即可。
- 与 402 的分工：402 用于「层状清晰、沿 z 分层」的 slab；403 用于「按一个 z 阈值一刀切」的场合，不受层判断阈值影响。

## §4 冲突与错误日志

> 格式：`位置 | 原文怎么说 | 问题是什么 | 我的判断与依据`。
> **凡我不确定的都写「不确定」，不编造确定说法。** 涉及「讲义 vs 官方/常识」的条目一律**只记录、不裁定**。

### C1 · EDIFF：讲义建议值与全部算例、全部模板都不一致
- **位置**：L1 P28 vs `day1/{fe2o3,mos2,vdw-df2,GaN}/INCAR`、L1 P31/P35/P46
- **原文**：「EDIFF 结构优化/MD(1E-5)，过渡态/频率(1E-6或-7)」
- **问题**：4/4 真实算例的结构/晶胞优化都写 `EDIFF = 1E-6`（GaN 甚至是 `1E-08`），**没有任何一个用 1E-5**；讲师自己的三个 INCAR 模板（P31/P35/P46）也全部写 `1E-6`。
- **我的判断**：P28 的表格是「通用建议档」，而讲师的实际实践与其模板统一取 1E-6。建议以 **1E-6** 为准。**依据**：L1 P31 第 444 行（"结构优化INCAR参考模板"）、L1 P46 第 787 行、以及 3 个算例 OUTCAR 实测 `EDIFF = 0.1E-05`。

### C2 · ADDGRID：GaN 算例与讲义建议相反
- **位置**：L1 P28 vs `day1/GaN/INCAR` 第 7 行
- **原文**：「ADDGRID 一般结构优化(.FALSE.)，电子结构高精度(.TURE.)」
- **问题**：GaN 是纯结构优化（`ISIF=2`、`NSW=100`、`EDIFFG=-2E-02`），却写 `ADDGRID= .TRUE.`；而 mos2 / vdw-df2 的同类任务都把它注释掉（=默认 .FALSE.）。
- **我的判断**：**推论** —— GaN 的 INCAR 与其余三个算例**风格明显不同**（几乎无注释、`NELM=60`、`NELMIN=6`、`EDIFF=1E-08`、**完全没有 `ENCUT`/`SYSTEM`/`NCORE`/`KPAR`/`LORBIT`**，且其 POSCAR 标题是 `Transfer by qvasp`），应视为**来自另一条工具链/另一个来源的示例输入**，其中的参数**不宜当作讲师的推荐值**。

### C3 · NELM / NELMIN：GaN 算例偏离讲义区间
- **位置**：L1 P28 vs `day1/GaN/INCAR`
- **原文**：「NELMIN 最小SCF步数5；NELM 最大SCF步数300或300以上(500)」
- **问题**：GaN 实际 `NELM = 60`（远低于 300，也低于讲义下限）、`NELMIN = 6`（高于 5）。
- **我的判断**：同 C2，GaN 属另一来源。`NELMIN=6` 只是取值不同、不构成问题；`NELM=60` 是否够用**不确定**（该目录无 OUTCAR/LOG，无法验证是否因步数不足而中断）。

### C4 · LREAL：讲义说「表面计算(Auto)」，但真实 slab/2D 算例全用 .FALSE.
- **位置**：L1 P28 vs `day1/mos2`（`.FALSE.`）、`day1/vdw-df2`（`.FALSE.`）、`day1/GaN`（`.FALSE.`）
- **原文**：「LREAL 材料计算(.FALSE.)，表面计算(Auto)」
- **问题**：两个二维 slab 算例都没用 Auto。
- **我的判断**：**推论** —— LREAL 的取舍主要取决于**体系尺寸**而非「是不是表面」；MoS2 只有 3 个原子、GaN 13 个原子，都属于小体系，`.FALSE.` 更合理；讲义的「表面计算(Auto)」应理解为针对**原子数多的 slab**。P28 的表述缺少「体系大小」这一前提。具体门槛值本报告未在 L1 中读到 [来源待核对]。

### C5 · ISYM：讲义说「表面计算(0)」，mos2 实测 ISYM = 2
- **位置**：L1 P28 vs `day1/mos2/OUTCAR:359`（`ISYM   =      2`）
- **原文**：「ISYM, SYMPREC ISYM(2)，表面计算(0)，杂化泛函(3)」
- **问题**：mos2 是表面/二维模型，实际保留默认 2；其 INCAR 里 `#ISYM = 0` 是**注释掉**的。
- **我的判断**：**推论** —— 未被吸附物/缺陷破坏对称性时可以保留对称性以省算力，`ISYM=0` 是给「对称性降低」的场合用的。讲义把「表面计算」一刀切为 0 过粗。另注意：模板 `things to study/INCAR` 与 `INCAR(1)` 里 **`ISYM = 0` 是取消注释、生效的**，与 P28 一致，但与真实 mos2 算例不一致 —— 同一门课内部就有两种做法。

### C6 · NCORE：同一份讲义给出 3 个不同数字
- **位置**：L1 P48（每节点核数/2）vs L1 P31/P35/P46（**NCORE = 5**）vs 4 个真实 INCAR（**NCORE = 16**，GaN 未设）vs 模板 `things to study/INCAR`（**NCORE = 16**）
- **问题**：讲义幻灯片一律写 5，格式文件一律写 16，P48 给的是公式。
- **我的判断**：**不确定**（无法判定幻灯片 5 是否与某台机器的核数匹配）。可确定的是：LOG 显示作业用 64 核，若单节点 32 核则 16 = 32/2 与 P48 相符；若单节点 64 核则应为 32、与 16 不符。**文件中没有节点核数信息** [来源待核对]。

### C7 · NSW：P29 说 500，模板与算例一律 300
- **位置**：L1 P29（「NSW 最大离子步数500」）vs L1 P31（`NSW = 300`）、P35（`NSW = 0`）、P46（`NSW = 300`）vs `day1/{fe2o3,mos2,vdw-df2}`（300）、`GaN`（100）
- **我的判断**：P29 的 500 更像「上限建议」而非「推荐值」，但这与同门课模板的 300 并列时会让读者困惑。属表述含糊，**不是硬错误**。真实算例站在 300 一边。
